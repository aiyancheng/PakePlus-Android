一、验光单基本符号解读

验光单是眼镜配制的"处方"，上面记录了顾客眼睛的屈光状态。作为门店员工，您必须能够快速、准确地解读验光单上的每一个符号和数值，才能为顾客提供专业的配镜建议。

1. 球镜度数（Sphere / S）
表示近视或远视的度数。"+"表示远视，"-"表示近视。例如：-3.50表示350度近视；+2.00表示200度远视。数值越大，度数越高。

2. 柱镜度数（Cylinder / C）
表示散光的度数。"+"或"-"表示散光的性质（顺规或逆规）。例如：-1.25表示125度散光。散光通常伴随近视或远视出现。

3. 轴位（Axis / A）
表示散光的方向，范围是0-180度。轴位本身没有"好坏"之分，但必须准确，否则会导致视物变形。例如：Ax 180表示散光轴位在180度方向。

4. 瞳距（PD / Pupillary Distance）
表示两眼瞳孔中心之间的距离，单位是毫米（mm）。瞳距分为远用瞳距和近用瞳距，配镜时必须使用对应的瞳距值。

专业提示：当顾客拿到医院或眼镜店的验光单时，第一步就是确认这是"处方"还是"验光结果"——有些验光单只是检查结果，不能直接作为配镜处方使用。

二、常见验光单格式对比

不同机构（医院、眼镜店、眼科诊所）的验光单格式可能不同，但核心信息是一致的。以下是三种常见格式：

- L / OS：左眼（Oculus Sinister，拉丁语"左眼"）

三、特殊符号与附加信息

除了基本符号外，验光单上可能还会出现以下特殊符号或附加信息：

1. 矫正视力（VA / Visual Acuity）
表示戴镜后的最佳视力。例如：VA 1.0表示戴镜后视力达到1.0。如果VA低于0.8，需要检查是否有眼部疾病。

2. 瞳高（PH / Pupil Height）
用于渐进多焦点镜片，表示瞳孔中心到镜框下缘的距离。测量不准确会导致渐进通道位置偏移，影响佩戴舒适度。

3. 棱镜（Prism）
用于矫正斜视或双眼视功能异常。格式为"△Base方向"，例如：△Base In 2表示2个棱镜度基底向内。

4. 下加光（ADD / Addition）
用于老花眼，表示近用附加度数。例如：ADD +2.00表示近用度数比远用度数高+2.00D。

5. 备注栏

注意：验光单上的"备注"栏可能包含重要信息，如"建议散瞳验光"、"定期复查"、"排除圆锥角膜"等。这些信息直接关系到配镜方案，必须仔细阅读并告知顾客。
📝 今日小结
  • 验光单四大核心：球镜（S）、柱镜（C）、轴位（A）、瞳距（PD）
  • 左右眼标识：R/OD（右眼）、L/OS（左眼）、OU（双眼）
  • 特殊符号：VA（矫正视力）、PH（瞳高）、Prism（棱镜）、ADD（下加光）
  • 验光单≠配镜处方：需确认是否为最终处方，而非仅仅是验光结果
  • 备注栏重要：包含医生或验光师的重要建议，必须关注
