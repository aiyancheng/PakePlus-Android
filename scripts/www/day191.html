一、散瞳验光的基本概念

散瞳验光是使用睫状肌麻痹药物（如阿托品、环喷托酯）使瞳孔散大、调节麻痹，从而获得真实屈光状态的检查方法。

1. 散瞳验光的目的
消除调节：麻痹睫状肌，消除调节痉挛（假性近视）
检查眼底：瞳孔散大后便于观察眼底（晶状体、玻璃体、视网膜）
获得真性屈光度：区分真性近视与假性近视，获得准确的配镜处方

2. 常用散瞳药物

药物名称 作用时间 恢复时间 适用人群
托吡卡胺
(Tropicamide)		 20-30分钟 4-6小时 成人、大龄儿童
环喷托酯
(Cyclopentolate)		 30-60分钟 24-48小时 儿童、青少年
阿托品
(Atropine)		 3-7天 7-14天 婴幼儿、顽固假性近视
专业提示：散瞳验光必须在医疗机构由眼科医生或视光师操作，眼镜门店不得自行散瞳验光！

二、散瞳验光的适应证

以下情况需要进行散瞳验光：

1. 儿童青少年首次验光
原因：儿童调节力强，容易出现假性近视
方法：使用环喷托酯或阿托品散瞳
频率：每6-12个月复查一次

2. 调节痉挛（假性近视）
原因：长时间近距离用眼导致睫状肌持续收缩
表现：电脑验光度数比实际深，主观验光不稳定
处理：散瞳验光区分真假近视

3. 屈光度数不稳定
原因：度数在短期内（1-3个月）变化>0.50D
可能：假性近视、圆锥角膜、眼部疾病
处理：散瞳验光 + 眼底检查

4. 弱视治疗监测
原因：弱视治疗需要准确屈光矫正
方法：每3-6个月散瞳验光一次
目的：调整配镜处方，确保最佳矫正

5. 内斜视检查
原因：内斜视常与调节有关
方法：阿托品散瞳后检查
目的：获得真实屈光状态，指导手术或配镜

三、散瞳验光的禁忌证

以下情况禁止或谨慎进行散瞳验光：

绝对禁忌证（禁止散瞳）
1. 闭角型青光眼：瞳孔散大可诱发急性青光眼发作（眼压骤升、头痛、恶心）
2. 对散瞳药物过敏：可出现眼痛、头痛、恶心、皮疹
3. 眼压不明：未测量眼压前，不能排除青光眼

相对禁忌证（谨慎散瞳）
1. 妊娠期：药物可能通过胎盘影响胎儿
2. 心血管疾病：药物可能引起心动过速
3. 高龄（>70岁）：瞳孔散大后可能诱发青光眼
4. 认知障碍：无法配合散瞳后注意事项

⚠️ 重要提醒：散瞳验光前必须询问病史、测量眼压、检查前房深度！如有禁忌证，禁止散瞳！

四、散瞳验光后的注意事项

散瞳后瞳孔散大、调节麻痹，顾客需要注意以下事项：

1. 避免强光刺激
原因：瞳孔散大后，光线直接进入眼内，会畏光、流泪
处理：戴墨镜或遮阳帽，避免阳光直射

2. 避免近距离用眼
原因：调节麻痹后，看近处模糊（不能聚焦）
处理：不能开车、操作机器、阅读细小文字

3. 注意药物反应
原因：散瞳药物可能引起全身反应（心动过速、口干、发热）
处理：如出现眼痛、头痛、恶心，立即就医

4. 定期复查
原因：散瞳效果消失后，需要复查确定最终配镜处方
处理：按医嘱时间复查（通常1-2周后）

专业提示：散瞳验光后的配镜处方需要1-2周后才能确定（等瞳孔和调节恢复）。这期间可给顾客备用的旧眼镜或平光眼镜。
📝 今日小结
  • 散瞳验光目的：消除调节、检查眼底、获得真性屈光度
  • 常用药物：托吡卡胺（4-6小时）、环喷托酯（24-48小时）、阿托品（7-14天）
  • 适应证：儿童首次验光、调节痉挛、屈光不稳定、弱视监测、内斜视
  • 禁忌证：闭角型青光眼（绝对禁忌）、过敏、眼压不明
  • 散瞳后注意事项：避免强光、避免近距离用眼、注意药物反应、定期复查
  • 散瞳验光≠配镜处方！需结合主观试戴和顾客需求确定最终处方

        参考答案：

        一、散瞳前准备（必须完成）
        1. 询问病史：青光眼、药物过敏、心血管病、妊娠/哺乳
        2. 测量眼压：非接触式眼压计，排除青光眼
        3. 检查前房深度：裂隙灯或手电筒，排除闭角型青光眼
        4. 签署知情同意书：说明散瞳后注意事项

        关键要点：如有禁忌证（闭角型青光眼、过敏、眼压高），禁止散瞳！
        注意事项：必须问病史和测眼压，不能省略

        二、散瞳操作（滴眼药）
        1. 病人仰卧或坐立，头后仰
        2. 分开上下眼睑，药液滴入下穹窿（不要滴在角膜上）
        3. 闭眼按压泪囊区3-5分钟（减少全身吸收，防止并发症）
        4. 每5-10分钟滴一次，共2-3次

        关键要点：按压泪囊区很重要！不按压可能导致心动过速等全身反应
        注意事项：滴药时不要让瓶口接触眼睛，避免污染

        三、散瞳后检查（等待药物起效）
        1. 等待时间：托吡卡胺20分钟，环喷托酯30-60分钟，阿托品3-7天
        2. 先查眼底：利用散瞳窗口期检查晶状体、玻璃体、视网膜
        3. 再查屈光：电脑验光 + 视网膜检影（客观验光）
        4. 记录结果：标注"散瞳下"（如"散瞳下 R: -2.50/-0.75×180"）

        关键要点：必须先查眼底再查屈光！如果先查屈光，瞳孔可能开始缩小
        注意事项：散瞳下只能做客观验光，不能做主观验光（调节被麻痹）

        四、散瞳后护理（告知顾客）
        1. 避免强光：戴墨镜或遮阳帽（瞳孔散大后畏光）
        2. 避免近距离用眼：不能开车、操作机器（调节麻痹后看不清近处）
        3. 注意药物反应：眼痛、头痛、恶心 → 立即就医
        4. 定期复查：按医嘱时间复查（通常1-2周后）

        关键要点：必须书面告知注意事项！最好给顾客一张"散瞳后注意事项"卡片
        注意事项：散瞳持续时间因药物而异（托吡卡胺4-6小时，环喷托酯24-48小时，阿托品7-14天）

        五、配镜处方确定（1-2周后）
        1. 等瞳孔和调节恢复：通常1-2周（托吡卡胺）或3-4周（环喷托酯）
        2. 主观试戴：让顾客试戴散瞳验光处方，评估舒适度
        3. 调整处方：根据试戴反应、顾客需求、年龄因素调整
        4. 确定最终处方：散瞳验光结果 + 主观试戴 + 顾客需求 = 最终处方

        关键要点：散瞳验光结果≠配镜处方！必须结合主观试戴
        注意事项：这期间可给顾客备用的旧眼镜或平光眼镜
