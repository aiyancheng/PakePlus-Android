爱眼城眼镜 · 渐进眼镜取镜服务标准流程

常规取镜十步 + 渐进专项 · 验配差异 · 适应期指导 · 独立专册
核心原则：先适应、后评价 ｜ 中心对准、姿势要对 ｜ 常规十步做扎实，渐进专项再叠加
一、适用对象与定位 本册在《取镜流程》十步基础上做渐进专项扩展，两册配套使用

📌 本册适用于

顾客所购镜片为 渐进多焦点（含成人渐进、青少年近视防控离焦渐进类）时的取镜交付环节。

执行人：接待 / 营业员主导，验光师配合复核中心对位与度数。

⛔ 本册不适用于

单光镜片——按《取镜流程》常规十步执行即可。

若顾客为 初次配戴渐进且有明显不适应史，须先由验光师评估能否取镜。

🎯 交付目标

让顾客当天就能正常使用：看得清远、看得清近、走路不踩空。

把"适应期投诉"预防在柜台内，降低返工与退货率。

为什么渐进要单独一册？渐进镜片一副镜片上有远、中、近多个焦点，通道与像散区对 镜框高度、瞳孔中心位置、镜眼距、前倾角 极其敏感。取镜时"戴上就走"是渐进售后投诉的头号来源——同样的十步，渐进每一步都要多问一句、多量一次、多讲一段。
二、与常规取镜的核心差异 同样十步，渐进这 6 处必须区别对待

常规单光 / 双光取镜

  • 镜片仅一个焦点，戴上即清晰，无需通道对位
  • 镜框高度、瞳孔位置要求宽松，稍偏不影响使用
  • 试戴以"清晰、舒适"为主，无系统适应期指导
  • 交代保养 7 条即可，无专项用眼姿势讲解
  • 核对项：度数 / 型号 / 装配（3 项）
  • 一般可当天完成，无需二次随访

渐进渐进多焦点取镜

  • 远 / 中 / 近多焦点，须确认瞳孔对准远用区
  • 镜框高度须满足通道需求（一般≥28mm 才可下单）​
  • 必须做适应期专项指导（头动为主、眼动为辅）
  • 必须讲用眼姿势：看远抬头、看近低头看通道
  • 核对项增加：通道高度 / 单眼瞳距 / 前倾角 / 镜眼距（7 项）
  • 建议 7～15 天主动回访一次，确认适应情况
一句话记住差异：常规取镜解决"戴得上、看得清"；渐进取镜还要解决 "用得对、适应快"——多出来的时间，全花在中心对位、姿势指导和适应期说明上。

01
接待

迎宾接待

目标：三秒之内被看见、被回应，确认顾客为渐进取镜 停留 ≤ 15 秒

动作标准动作

  • 顾客进门 3 秒内起身迎接，半弯腰 15° 致意
  • 确认来意时，同步在系统核对该单是否为渐进镜片
  • 若为渐进，提前预留取镜台（需坐下、有镜子的位置）
  • 不得让顾客站着等待，不得让顾客自行寻找柜台
渐进要点：渐进取镜耗时约为常规的 2 倍，接待时即要调低顾客预期节奏——"渐进要慢慢调，别着急"，避免顾客因等待而不耐烦。

话术标准话术

  • "您好，欢迎光临爱眼城眼镜，请问有什么可以帮您的？"
  • "您是来取渐进眼镜的吧？这边请，我陪您过去，坐下慢慢试。"
  • "渐进眼镜要花点时间帮您调到位，大概十几分钟，您先坐。"
  • 话术要点：明确告知"需要时间"，把等待说成"为您调到位"
02
引座

引座倒水

目标：让顾客坐下、喝上水，进入可安静试戴的状态 必做动作

动作标准动作

  • 引导至取镜台侧位，主动拉出凳子，护住凳面防磕碰
  • 奉茶水位约半杯，杯耳朝顾客右手侧
  • 提醒顾客把随身包放视线可达处，勿挂凳背
  • 若顾客为初次配渐进，此时即可轻声预告适应过程
  • 顾客落座后再转身取镜，无空时由就近同事接力
渐进要点：渐进试戴需要顾客多次抬头、低头、走动，务必安排在有站立空间、有镜子、光线充足的取镜台，不要在狭窄角落。

话术标准话术

  • "先生/小姐，您好！请坐，我去给您倒杯水。"
  • "渐进眼镜刚戴会有个适应过程，一会儿我教您怎么看远看近。"
  • 话术要点：先照顾"坐"与"等"，提前植入"适应"概念，降低后面对"晃"的抵触
03
核单

核单取镜

目标：一次取对、件件不落，且确认是渐进镜片实物 核对 7 项

动作标准动作

  • 双手接单，核对顾客姓名 / 手机尾号 / 单号 / 门店四项一致
  • 按单号定位取镜，先看单、后开格
  • 验明实物为渐进镜片：镜片有远用区→通道→近用区的渐变标识
  • 核对镜片包装袋标注：渐进品种 / 通道长度 / 折射率 / 加光 ADD
  • 确认加工单标注的通道高度与单眼瞳距已按渐进要求定制
  • 赠品（镜布 / 镜盒 / 保修凭证）一件不落当面点清
核对项渐进特别关注
镜片品种渐进（非单光）
加光 ADD与处方一致，左右可不同
通道长度短通道 / 标准通道，与镜框高度匹配
单眼瞳距渐进按单眼瞳距加工，不能用双眼均值
通道高度瞳孔中心至镜框下缘，≥18mm 为宜

话术标准话术

  • "麻烦问一下，您预留的手机尾号是 XXXX，对吗？"
  • "我按单号核对一下渐进品种和加光，您稍等一分钟。"
  • 取到后复述："这副就是您选的渐进镜片，加光 XX，镜片包装也给您留着。"
  • 话术要点：边点边报，将"渐进"字样说出，强化顾客"这确实是渐进的确认感"
04
检查

成镜检查

目标：交付前完成自检，尤其确认渐进加工标记与中心位置 渐进加查 2 项

动作标准动作（三查一看 + 渐进两看）

  • 反面查：放取镜板上，左右耳弯点均不翘起
  • 正面查：镜腿末端不翘起
  • 折叠查：镜腿折叠重叠、不交叉，桩头无松动异响
  • 一看：对光看镜片有无划痕、崩边、气泡、装配缝隙
  • 渐进看一：核对镜片上的临时标记（隐形渐变标识）是否清晰可辨
  • 渐进看二：用水准仪 / 目测确认远用区光学中心与瞳孔高度对应，左右一致
  • 检查全程用专用镜布托底，不直接捏拿镜片
渐进要点：渐进镜片一旦装配时光学中心点错位，戴上去会产生"晕、晃、看近发糊"，且无法靠后天调校补救。此步必须由验光师或有资质的加工人员确认中心标记，异常立即返工，不得取镜交付。

话术标准话术

  • "我先帮您做个交付前检查，看看镜片装配和中心点，一分钟就好。"
  • 通过："检查好了，镜架平整、渐进中心位对准了，您放心戴。"
  • "渐进镜片对中心位置要求很高，这一步我们一定帮您核对到位。"
  • 话术要点：把"检查"说成为顾客把关，同时传递"渐进很讲究"的专业感
05
对位

试戴对位 ★渐进专项

目标：确认瞳孔对准远用区，戴姿正确，为适应期打好基础 渐进核心步骤

动作标准动作（对位四步）

  • 引导坐下，镜子摆正、与视线等高，双手打开镜框
  • 递交时捏桩头、开口朝顾客，请顾客双手接镜腿
  • 第一步 · 看远对位：让顾客平视正前方，确认瞳孔落在远用区（镜框上 1/3 附近）
  • 第二步 · 看近对位：让顾客低头看近处文字，确认视线自然进入近用区（镜框下 1/3）
  • 第三步 · 通道居中：确认双眼中线对准渐进通道，不偏内、不偏外
  • 第四步 · 角度复核：量镜眼距、前倾角（8°～15°）、镜框高度四项是否达标
  • 看"三平"：镜框高低平、前后平、左右平
渐进要点：渐进对位是"一次做对、终身受益"的关键。中心差 1～2mm，顾客就会觉得"看近歪""走路晕"。此步务必边调边请顾客上下看，让顾客自己确认"远清晰、近也清晰"。

话术标准话术

  • 递镜："您双手接一下镜腿，先轻轻戴上。"
  • 对位："您平视前方，看远处那个目标——对，眼睛正好落在镜片上方的远用区。"
  • 看近："现在低头看这张单子上的字，用镜片下方看，是不是清楚了？"
  • 适应预告："渐进要慢慢适应，头动为主、眼动为辅，我教您方法。"
  • 话术要点：先说动作、再问感受，让顾客亲手验证远/近都清晰
06
微调

渐进微调 ★渐进专项

目标：按顾客真实感受当场调到位，确保中心不偏移 当场解决

动作标准动作

  • 按反馈逐项调：镜腿外扩内收、鼻托上下左右、倾斜角
  • 调整镜眼距：渐进镜眼距过大会放大像散区，须调至12～14mm
  • 调整前倾角至 8°～15°，过小看远费力、过大看近别扭
  • 调校用专业调校钳，垫布防刮伤，力度轻缓、小幅多次
  • 每调一次请顾客重新佩戴 + 抬头看远 + 低头看近 + 走两步
  • 确因度数或中心问题无法当场解决，当场记录并承诺返店时间，不得含糊
渐进要点：渐进微调要区分"镜架问题"与"适应问题"——戴得晃、看地面前方有变形，多为正常适应现象，不必反复调架；但若看远不清晰、看近错位、双眼单眼不一致，则多为中心或度数问题，须请验光师复核。

话术标准话术

  • "刚刚看您戴的时候镜眼距有点大，我帮您调近一点，渐进这样更清晰。"
  • "两侧鼻托我做个微调，戴久了才不会往下滑。"
  • 区分现象："刚戴有点晃是正常的，那是渐进的像散区；如果您看远一直发虚，我再帮您复核度数。"
  • 复验："您再抬头看远、低头看近试试，这次远和近都清楚了吗？"
  • 话术要点：先说现象、再说原因、后说处理，让顾客把"晃"和"不清晰"分开判断
07
指导

适应期使用指导 ★渐进专项

目标：教会顾客正确用眼方式，把适应期投诉降到最低 本册重点

动作标准动作（三段指导 + 必讲 5 条）

  • 三段式演示：①看远——平视前方；②看中——看电脑屏幕，视线微降；③看近——低头看书报，视线入下方近用区
  • 强调头动为主、眼动为辅：换视物距离时，转头而不是只转眼球
  • 告知像散区位置（镜片两侧），避免用余光从两侧看东西
  • 交代适应期与禁忌（见下表），重点条目让顾客复述一遍
  • 建议先室内、后室外，先静坐、后走动，不要一出门就骑车/开车
必讲要点说明与标准
适应期一般 3～7 天，个别需 2 周；越少换来换去越快适应
上下楼下楼低头看台阶最易踩空，务必扶扶手、慢行
驾驶适应期内尽量不要开车；确需驾驶先确认看远清晰、侧视不晕
用眼姿势看远平视、看近低头；不躺着看书、不仰头看手机
旧镜处理建议集中佩戴新镜，不要新旧频繁交替

话术标准话术

  • 演示："我教您三个方向：平视看远，微低头看电脑，再低头看书，视线自然就进入对应的区域。"
  • 方法："换着看东西的时候，转头比转眼球更好用，头跟着视线走。"
  • 下楼："刚戴渐进下楼梯要慢一点、扶一下扶手，低头用下方区域看台阶。"
  • 禁忌："适应期尽量别开车，等哪天您觉得远近都顺了再开，安全第一。"
  • 心态："一般三五天就适应了，别着急；实在不舒服随时回来，我们帮您看。"
  • 话术要点：把"晕"说成"正常适应"，同时给出可执行的方法，顾客才敢坚持戴
08
交代

交代事项 ★渐进加强

目标：保养 + 随访双交代，建立适应期跟踪 随访 + 保养

动作标准动作

  • 保养 7 条逐条手上演示（双手摘戴、凸面朝上、先折左腿、清水冲 + 专用布擦、避高温、定期回店调校、小问题早处理）
  • 留存临时渐变标记：告知镜片上的临时标记可用清水轻擦或用专业笔复描，便于日后复核中心
  • 在服务卡上标注渐进镜片型号、加光、取镜日期
  • 约定适应期随访：写入 7～15 天主动回访计划，登记顾客联系方式
  • 邀请顾客扫码关注门店服务号，便于适应提醒与售后沟通
  • 确认顾客记住 1～2 条关键项后再进入下一步
渐进要点：渐进镜片的保养与单光略有不同——不要用超声波清洗机长时间高频清洗（部分膜层与标记受影响），不要干擦以免损伤渐变膜层。同时随访不能省：7～15 天主动回访是发现"适应不良"的黄金窗口。

话术标准话术

  • 保养："镜片脏了用清水冲、专用镜布吸干，千万别干擦、别用衣角，渐进的膜层怕划。"
  • 标记："镜片上这两点淡淡的标记别刻意擦掉，是渐进的中心标记，方便以后我们帮您复核。"
  • 随访："一周左右我会给您打个电话，问问适应得怎么样，有任何不舒服随时回店。"
  • 避高温："渐进也一样怕高温，别放车内仪表台、暖气边，膜层会花。"
  • 话术要点：把"保养 + 回访"说成持续服务，让顾客感到"买了还有人在管"
09
结款

转介绍 · 包装 · 结款

目标：礼貌请托转介绍，规范包装与尾款收取 三项收尾

动作标准动作

  • 包装：双手捏袋口两端递交；协助收好旧镜
  • 收款：当面复述金额，确认支付成功再放行，核实尾款与优惠一致
  • 会员信息、积分、渐进服务记录当日录入系统
  • 主动递交发票 / 收据 / 保修凭证，装箱前清点件数
  • 转介绍请托放在结款之后，服务满意时提出成功率最高
渐进要点：结款前再次确认顾客当下无不适（远清晰、近清晰、无明显头晕）。若顾客仍表示不适，先别急着结款放行，请验光师复核，避免"带病交付"埋下退货隐患。

话术标准话术

  • 确认："现在看远看近都还舒服吗？没问题我们再做收尾。"
  • 包装："您的眼镜是先戴着走，还是我帮您包起来？"
  • 尾款："您这边还有 XX 元尾款，请问现金还是微信支付？"
  • 凭证："发票和保修卡都在袋子里，适应期有问题随时找我们。"
  • 转介绍："您对我们服务还满意吗？身边朋友要配眼镜，麻烦帮我们推荐一下。"
10
礼送

礼送离店

目标：以礼貌收尾，把顾客送出视线 最后一公里

动作标准动作

  • 送顾客至门口，侧身让出路、主动拉门
  • 目送顾客离店 3 米以上，直至走出视线，中途不转身、不看手机
  • 顾客走后再整理取镜台、复位镜架与调校工具
  • 若有同行者，一并致意送别
渐进要点：送别时再叮嘱一句"上下楼梯慢一点"——这是渐进顾客离店后最容易出事、也最容易怪到门店的场景。

话术标准话术

  • "谢谢光临，请慢走！上下楼梯慢一点，扶好扶手。"
  • "眼镜戴得不舒服，随时回来，我们免费帮您调。"
  • "一周内我会电话问您适应情况，欢迎下次光临！"
四、渐进的四项特殊要求 不满足即不得取镜交付
1镜框高度要求

渐进需要足够垂直空间容纳远用区 + 通道 + 近用区，镜框高度一般需 ≥ 28～30mm，通道有效高度 ≥ 18mm。镜框过矮会导致通道被切、远近区域不足。

2中心对位要求

渐进按单眼瞳距加工，且远用区光学中心须对准瞳孔。取镜时须确认瞳孔落在远用区、通道居中，左右对称，偏差应控制在 ±1mm 内。

3角度与距离要求

镜眼距 12～14mm、前倾角 8°～15°。镜眼距过大或前倾角不当，会放大像散、加剧"晃感"，必须用调校钳微调到标准范围。

4适应期服务要求

渐进必须提供适应期专项指导 + 7～15 天主动回访。首次配戴者、高加光者（ADD≥2.00）、高度数者，随访更要主动、及时。

红线提醒：以下任一情形，不得按常规流程取镜交付，须请验光师复核或返工——① 镜片临时标记缺失、中心无法确认；② 镜框高度不足致通道被切；③ 顾客戴上后看远持续不清晰或双眼单眼明显不一致；④ 顾客为初次配渐进且戴后出现明显头晕、恶心。宁可延后交付，也不带问题出门。
五、常见问题处理 渐进取镜现场高频问答，照着答即可
刚戴上觉得有点晕、走路有点晃，正常吗？
属正常适应现象。渐进镜片两侧有像散区，视线扫过时会有轻微变形感，一般 3～7 天逐渐适应。请顾客：① 换视物距离时转头代替转眼球；② 上下楼梯慢行、扶扶手；③ 尽量持续佩戴、不要新旧镜频繁交替。若 2 周后仍明显不适，回店由验光师复核。
看远很清楚，但看近有点糊 / 对不上，怎么处理？
先区分两种情况：① 若顾客低头看近时没有用镜片下方的近用区，是使用姿势问题——当场演示"低头看书"的正确姿势即可；② 若姿势正确仍看近不清，可能是通道高度或加光/瞳距加工偏差，须请验光师复核处方与镜片中心，不得简单归结为"适应期"敷衍顾客。
顾客说"我朋友戴渐进头晕得厉害，我不敢戴"，怎么打消顾虑？
用"差异 + 方法 + 兜底"三段回应："渐进和单光确实不同，所以我们会帮您把中心点、镜框高度都调到位；我再教您转头看的方法；真适应不了，我们按公司政策帮您处理，不会让您吃亏。"把"风险"讲清、把"方法"给足、把"兜底"说明白，顾客才敢尝试。
适应期内顾客要求退货，怎么办？
先请验光师复查：核对度数、单眼瞳距、通道高度、镜片中心标记是否符合加工标准。属加工/度数问题——按门店保修政策免费返工；属尚未适应——加强指导并约定再观察 1 周。全程留痕记录（复查数据、沟通结果），并请主管 / 店长介入，不独自承诺退换。
镜片上的临时标记需要擦掉吗？
那是渐进的中心参考标记，是日后复核中心位置的依据，不必刻意擦除；日常佩戴用清水 + 专用镜布即可，它会随使用自然变淡。若顾客觉得影响美观，可告知其可用清水轻擦，但建议保留到完全适应之后。
顾客同时买了单光和渐进，取镜有什么不同？
两副分开交付、分开指导。单光按《取镜流程》常规十步即可；渐进按本册执行，两副不要同时上脸试戴，避免顾客混淆"哪副晕"。建议先交付单光，再单独完成渐进的适应期指导。
六、执行规范 · 质量控制
✓四个"必须"
  1. 必须交付前确认渐进中心对位（临时标记 + 远用区）
  2. 必须完成试戴对位四步（看远 / 看近 / 通道居中 / 角度复核）
  3. 必须做适应期指导（头动为主 + 上下楼 / 驾驶禁忌）
  4. 必须登记 7～15 天主动随访计划
✕四个"不得"
  1. 不得以"适应期"为名，掩盖看不清、看近错位等真实问题
  2. 不得在中心标记缺失 / 无法确认时取镜交付
  3. 不得让顾客"戴上就走"，跳过对位与适应指导
  4. 不得省略适应期随访，让顾客"买了就没人管"
⏱时间标准

迎宾接待 ≤ 15 秒 → 引座倒水 ≤ 1 分钟 → 核对取镜 ≤ 2 分钟 → 成镜检查 1～2 分钟 → 试戴对位 + 微调 6～10 分钟 → 适应指导 + 交代 4～6 分钟 → 结款礼送 2～3 分钟。

全程控制在 15～25 分钟（渐进约为常规的 2 倍，属正常）。

!常见失误提醒
  1. 跳过对位直接交付，顾客看近错位却不知情
  2. 不讲适应期禁忌，顾客下楼踩空、开车受惊后归咎门店
  3. 把"加工中心偏差"误判为"正常适应"，延误返工
  4. 未留存随访计划，适应不良无法及时发现
  5. 结款前未再确认舒适度，带问题出门埋下退货隐患
