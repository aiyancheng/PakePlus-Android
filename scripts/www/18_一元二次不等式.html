一元二次不等式

大于取两边、小于取中间——前提是先「化正」再看有没有根。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

「x²−2x−3 > 0 的解集是什么？」如果你还在纠结要不要因式分解、要不要分情况，那就把图像请出来：不等式 > 0 就是在问抛物线哪一段在 x 轴上方。

这一讲把口算口诀背后的真正条件讲清楚——因为那句「大于取两边」是有前提的，用错了会全盘皆输。

壹从原理上讲透

一、把不等式翻译成图像问题

ax² + bx + c > 0 的解，就是使抛物线 y = ax²+bx+c 落在 x 轴上方的那些 x。

ax² + bx + c < 0 的解，就是曲线落在 x 轴下方的那些 x。等号 < 0 与 = 0 的差别，只是是否包含交点。

二、口诀成立的条件

先化正：若 a < 0，两边同乘 −1，不等号必须反向。例如 −x²+2x+3 ≥ 0 化为 x²−2x−3 ≤ 0。

再看 Δ：设两根为 x₁ < x₂。

a > 0，Δ > 0
>0 取两边：x < x₁ 或 x > x₂；<0 取中间：x₁ < x < x₂
a > 0，Δ = 0
>0 取除顶点外全体：x ≠ x₁；<0 无解
a > 0，Δ < 0
>0 解集为全体实数；<0 无解
a < 0
先化正，再套上面三行

三、为什么是这样

a>0 开口向上：中间那段（两根之间）曲线在轴的下面，两侧（两根之外）在上面。这就是「大于取两边、小于取中间」的图像依据。

如果 Δ<0 呢？此时整条曲线都在 x 轴同侧：开口向上则全在上方（>0 恒成立），向下则全在下方。这就是第 20 讲恒成立问题的雏形。

执行顺序一定不能乱：先化正 → 再算 Δ 求根 → 最后按口诀写解集。跳过「化正」直接套口诀，是这一讲最致命的错误。

等号处理
≥ 或 ≤ 时，两根点要包含进解集

图像依据：开口向上时，两根之间为负、两根之外为正。

严格不等号用开区间，含等号用闭区间并包含端点。

肆解题步骤：拿到题怎么下手

  1. 化正：把二次项系数变为正（乘 −1 则变号），统一讨论。
  2. 算 Δ 并求根：解 ax²+bx+c=0 得 x₁、x₂（注意按大小排列）。
  3. 画图定位：脑中画出开口向上的抛物线，标出两零点。
  4. 按口诀写解集：>0 两边、<0 中间；注意 ≥、≤ 时包含端点。
  5. 特殊情况：Δ≤0 时回到第 20 讲的恒成立结论，别硬套口诀。

伍例题精讲

例1解不等式 x² − 2x − 3 > 0。
展开完整解析

思路：a=1 已为正，直接求根再按口诀写。

  1. 已化正：a = 1 > 0。
  2. 求根：x² − 2x − 3 = 0 → (x − 3)(x + 1) = 0 → x₁ = −1，x₂ = 3。
  3. 开口向上，>0 取两边：x < −1 或 x > 3。
  4. 检验：取 x=4 代入 16−8−3=5>0 ✓；取 x=0 代入 −3<0 ✗（应在中间，符合）。
答：解集为 x < −1 或 x > 3（即 (−∞,−1)∪(3,+∞)）。
例2 · 必须先化正解不等式 −x² + 2x + 3 ≥ 0。
展开完整解析

思路：a=−1<0，第一步必须化正，否则口诀会把方向弄反。

  1. 化正：两边乘 −1，不等号反向 → x² − 2x − 3 ≤ 0。
  2. 求根：x₁ = −1，x₂ = 3（与例 1 同一根）。
  3. 现在是 ≤0，开口向上应取中间：−1 ≤ x ≤ 3。
  4. 注意含等号，端点 −1 与 3 都要包含进去。
  5. 检验：原式取 x=0 得 3 ≥ 0 ✓；取 x=4 得 −16+8+3 = −5 < 0 ✗（应排除）✓。
答：解集为 −1 ≤ x ≤ 3（即 [−1, 3]）。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 忘了化正：直接对 a<0 的式子套「大于取两边」，方向会完全相反，这是本讲头号错误。
  • 不等号没跟着反向：乘负数时 >= 都要翻转。
  • 等号端点没包含：题目是 ≥/≤ 时，解集里两根必须带上等号。
  • Δ<0 时仍硬套口诀：此时没有两根，应回到「恒成立/恒不成立」的判断。

柒它在生活里长什么样

🏀 从课本走到现实

  • 盈亏分析：利润函数 >0 的区间就是盈利区间，两个零点是盈亏平衡点。
  • 安全区间：拱桥高度必须大于某个值的水平范围，正是「大于取两边」的实际映射。
  • 投篮的可用角度：出手角度落在哪段区间球才能入筐，本质上就是一个不等式解集。

捌本节小结

✍️ 记住这几条就够了

  • 先化正（注意变号）→ 再求根 → 最后套口诀。
  • a>0 且有两个根：>0 取两边、<0 取中间。
  • Δ=0 时口诀退化：>0 排除顶点，<0 无解。
  • Δ<0 时看整体位置，交给第 20 讲的恒成立判断。
