一、镜片保养指导

镜片是眼镜的核心部件，正确的保养方法能延长使用寿命，保持清晰视觉。

1. 清洗方法
正确步骤：先用清水冲洗掉灰尘→滴少量中性洗洁精→指腹轻轻揉搓→清水冲洗干净→用镜布吸干水分（不要来回擦拭）。切忌用衣服、纸巾干擦镜片！

2. 避免高温
镜片不耐高温，不要放在汽车仪表盘、暖气片附近、桑拿房等高温环境。高温会导致镜片膜层爆裂、镜框变形。

3. 防刮伤
镜片应朝上方放置（不要镜片朝下），存放时放入镜盒。不要用手指触摸镜片表面，指纹中的油脂会损伤镀膜。

4. 镀膜保护
现代镜片多为多层镀膜，避免使用酒精、丙酮等有机溶剂擦拭，会破坏镀膜。使用专用镜片清洁剂或中性洗洁精。

专业提示：教顾客一个简单的记忆口诀——"水洗、剂洗、吸干、盒装"，四步保养法让镜片持久清晰。

二、镜框保养指导

镜框保养不当会导致变形、断裂、褪色，影响佩戴效果和使用寿命。

1. 日常清洁
用中性洗洁精和温水清洗镜框，特别是鼻托和镜腿连接处容易积聚污垢。清洗后用软布擦干。

2. 避免重压
镜框不能承受重压，不要放在裤子后口袋（坐下会压坏）、不要单手摘戴（会导致镜框变形）。

3. 螺丝紧固
定期检查镜腿螺丝是否松动，如有松动及时紧固。门店应提供免费的螺丝紧固服务。

4. 不同材质镜框的保养
金属镜框：避免汗液长期腐蚀，定期清洗；板材镜框：避免高温和有机溶剂；钛合金镜框：轻便耐用，但避免剧烈弯曲。

三、隐形眼镜保养指导

隐形眼镜直接接触角膜，保养不当会导致眼部感染，必须严格遵循护理流程。

1. 洗手
佩戴和取下隐形眼镜前，必须用肥皂和流动水彻底洗手，用无絮毛巾擦干。切忌用脏手接触隐形眼镜！

2. 使用专用护理液
使用隐形眼镜专用护理液清洗和浸泡，不要用自来水、生理盐水代替。护理液开封后3个月内必须使用完毕。

3. 清洗方法
将隐形眼镜放在掌心，滴几滴护理液，用食指轻轻揉搓10-20秒，正反面都要清洗，然后用护理液冲洗干净。

4. 储存方法
隐形眼镜必须浸泡在新鲜护理液中，不要重复使用旧护理液。镜盒每周清洗一次，每3个月更换新镜盒。

警告：绝对不要用自来水清洗或浸泡隐形眼镜！自来水中可能含有阿米巴原虫，会导致严重的角膜感染，甚至失明。这是隐形眼镜佩戴者必须知道的安全知识。

四、保养指导的沟通话术

向顾客传授保养知识时，要使用通俗易懂的语言，并让顾客现场练习。

1. 镜片保养话术
"镜片保养很简单，记住四步：水洗、剂洗、吸干、盒装。千万不要用衣服擦镜片，会刮花镜片。如果镜片脏了，先用水冲掉灰尘，再用洗洁精清洗。"

2. 镜框保养话术
"镜框最怕两件事：重压和单手摘戴。不要放在裤子后口袋，坐下会压坏。摘戴时要双手操作，避免镜框变形。"

3. 隐形眼镜保养话术
"隐形眼镜保养最重要的就是：洗手、护理液、揉搓、新鲜液体。绝对不能用自来水！护理液开封3个月必须扔掉，镜盒每3个月换新的。"

4. 让顾客现场练习
"来，您现在试着清洗一下镜片，我看看您的方法对不对。"通过现场练习，确保顾客真正掌握保养方法。

📝 今日小结
  • 镜片保养：水洗→剂洗→吸干→盒装，切忌干擦和高温，禁用有机溶剂
  • 镜框保养：避免重压和单手摘戴，定期紧固螺丝，不同材质区别对待
  • 隐形眼镜保养：洗手→护理液→揉搓→新鲜液体，绝对不用自来水，镜盒3个月更换
  • 沟通要点：用通俗语言+现场练习，确保顾客真正掌握保养方法
