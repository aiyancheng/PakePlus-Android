符号多结论判断

开口、对称轴、截距，四步逐个推：多结论题逐个判真伪。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

中考数学里有一类让人头皮发麻的题：给一张抛物线示意图，下面列出 abc>0、2a+b<0、a+b+c>0、4a−2b+c<0……问正确的有几个。看似复杂，其实每一条都能从图上直接读出来，只是需要一套固定的翻译规则。

这一讲就给你这套规则：看图四步走 + 特殊点代入法，把每一个怪式子翻译成图上的某个位置。

壹从原理上讲透

一、看图四步：把图像翻译成参数

① 开口方向
向上 → a>0；向下 → a<0
② 对称轴位置
x = −b/(2a)：在 y 轴左边 ⟹ ab>0（同号）；在右边 ⟹ ab<0（异号）。口诀：左同右异
③ 与 y 轴交点
交点在正半轴 → c>0；在原点 → c=0；在负半轴 → c<0
④ 与 x 轴交点个数
两个 → Δ>0；一个（顶点在轴上）→ Δ=0；没有 → Δ<0

二、特殊点代入法：翻译那些奇怪的式子

核心工具：f(x) = ax² + bx + c。把特定的 x 代入，式子就变成了图上某个点的高度：

f(1) = a + b + c
图上 x=1 处的点在 x 轴上方则 >0，下方则 <0
f(−1) = a − b + c
图上 x=−1 处的点的正负
f(2) = 4a + 2b + c
图上 x=2 处的点的正负
f(−2) = 4a − 2b + c
图上 x=−2 处的点的正负

再配合对称轴 −b/(2a) 的范围，还能推出 2a+b、2a−b 这类式子的符号。例如：

若 1 < −b/(2a) < 2（轴在 1 与 2 之间），且 a>0，则乘 2a 得 2a < −b < 4a，于是 2a+b < 0 且 4a+b > 0。

统一心法：任何关于 a、b、c 的线性组合，想办法凑成 f(某个 x) 或与轴的位置不等式。凑不成再看是否能用 Δ 或两根关系。

贰图像里的逻辑

叁核心结论（要背的）

开口
向上 a>0；向下 a<0
对称轴位置
左同右异：轴在左 ⟹ ab>0；轴在右 ⟹ ab<0
截距
与 y 轴交点纵坐标就是 c
Δ
看图与 x 轴交点个数：2 个 >0、1 个 =0、0 个 <0
特殊点
f(1)=a+b+c，f(−1)=a−b+c，f(2)=4a+2b+c，f(−2)=4a−2b+c

多结论题的做法：把每条式子翻译成图上一个「位置」或「特殊点」，逐条打勾打叉。

遇到 2a+b 这类，用对称轴不等式两边同乘 2a（注意 a 的正负决定是否变号）。

肆解题步骤：拿到题怎么下手

  1. 看图四件套：a 的符号、轴的位置、c 的符号、Δ 的符号，先把这四个基础量确定。
  2. 翻译每条结论：能凑成 f(x) 的，把对应 x 的位置在图上找出来，看点在轴上方还是下方。
  3. 处理 2a±b：写成轴的不等式再变形；乘除负数时记得变号。
  4. 数个数：逐条判定后统计正确的条数，选出对应选项。
  5. 复查：特别检查是否因为乘了负的 a 而忘了变号。

伍例题精讲

例1如图是 y = ax² + bx + c 的图象：开口向下，对称轴在 y 轴右侧，与 y 轴交于正半轴，与 x 轴有两个交点。判断：①abc 的符号；②a+b+c 的符号；③Δ 的符号。
展开完整解析

思路：逐项翻译：a 看开口、ab 看轴的位置、c 看截距、Δ 看交点个数。

  1. 开口向下 → a < 0。
  2. 对称轴在 y 轴右侧 → 由「左同右异」得 ab < 0，因 a<0 所以 b > 0；或直接由 x=−b/2a>0 推出。
  3. 与 y 轴交于正半轴 → c > 0。所以 abc = (−)(+)(+) < 0。
  4. 与 x 轴有两个交点 → Δ > 0。
  5. a+b+c = f(1)，要看图上 x=1 处的点是否在 x 轴上方：轴在右侧且有两个交点，通常 x=1 处仍在上方（对应 f(1)>0）；具体以图中 x=1 标注点的位置为准。
答：①abc < 0　②a+b+c = f(1)，符号由图中 x=1 处点的位置决定　③Δ > 0。
例2 · 参数组合已知 y = ax² + bx + c 的图象开口向上，且对称轴满足 1 < −b/(2a) < 2，判断 2a + b 与 4a + b 的符号。
展开完整解析

思路：把对称轴的不等式变形，注意乘以 2a 时 a>0 不变号。

  1. 已知 1 < −b/(2a) < 2，且开口向上即 a > 0，所以 2a > 0。
  2. 不等式各边同乘正数 2a，方向不变：2a < −b < 4a。
  3. 由 2a < −b 移项得 2a + b < 0。
  4. 由 −b < 4a 移项得 4a + b > 0。
  5. 检验：取 a=1、b=−3，则轴 x=1.5 在 (1,2) 内；2a+b=−1<0 ✓，4a+b=1>0 ✓。
答：2a + b < 0，4a + b > 0。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 「左同右异」记反：轴在 y 轴左边时 a、b 同号。可以用 −b/2a < 0 ⟹ b/a > 0 现场推导。
  • 乘负值不变号：由对称轴不等式变形时，若 a<0，乘 2a 必须翻转不等号方向。
  • 把 c 当成顶点纵坐标：c 是与 y 轴交点的纵坐标，不是顶点纵坐标。
  • 多结论题只判了三条就选：务必逐条看完，常见于「正确的有几个」这类设问。

柒它在生活里长什么样

🏀 从课本走到现实

  • 看图说话的训练：这类题训练的是「把符号翻译成位置」的能力，与读工程图纸、读股票 K 线图异曲同工。
  • 数据解读：拿到一张趋势图，先判断开口（趋势加速还是减速），再看轴（拐点位置），最后看截距（初始值）。
  • 篮球录像分析：从弧线形状反推出手参数，正是「由图推参数」的现实版本。

捌本节小结

✍️ 记住这几条就够了

  • 看图四件套：开口定 a、轴的左右定 ab、截距定 c、交点个数定 Δ。
  • 特殊点代入：f(1)=a+b+c、f(−1)=a−b+c、f(2)、f(−2)。
  • 2a±b 类用对称轴不等式变形，乘负号要变号。
  • 多结论题逐条打勾，别遗漏。
