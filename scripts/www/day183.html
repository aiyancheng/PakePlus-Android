一、屈光度的基本概念

屈光度（Diopter, D）是衡量透镜屈光能力的单位，表示透镜使光线聚焦的能力。屈光度越高，透镜的屈光力越强。

1. 屈光度的定义
1屈光度（1D）= 焦距为1米的透镜的屈光力。
公式：D = 1/f（f为焦距，单位：米）。
例如：焦距0.5米的透镜，屈光度为 1/0.5 = 2D。

2. 正负屈光度的含义
正屈光度（+）：凸透镜，使光线汇聚，用于矫正远视、老花。
负屈光度（-）：凹透镜，使光线发散，用于矫正近视。

3. 屈光度的精度
验光处方通常精确到0.25D（1/4屈光度）。
例如：+1.00D、+1.25D、+1.50D、+1.75D、+2.00D等。
更精确的验光可到0.12D（1/8屈光度），但较少用。

专业提示：屈光度是验光处方的基础。理解球镜、柱镜、轴位的概念，是正确解读验光单的第一步。

二、球镜（Sphere, S）

球镜代表均匀的屈光力，用于矫正近视或远视。球镜度数在所有经线上相同。

1. 球镜的符号含义

符号 含义 矫正问题 透镜类型
+（正） 远视（Hyperopia） 看近不清楚 凸透镜（中间厚）
-（负） 近视（Myopia） 看远不清楚 凹透镜（中间薄）
0或±0.25内 正视（Emmetropia） 视力正常 平光镜片

2. 球镜度数范围
轻度：-3.00D ～ +3.00D
中度：-3.25D ～ -6.00D / +3.25D ～ +6.00D
高度：-6.25D以上 / +6.25D以上

3. 球镜在处方中的表示
示例：S = -2.50D（近视250度）
示例：S = +1.75D（远视175度）
示例：S = 0.00D（正视，无屈光不正）

三、柱镜（Cylinder, C）

柱镜代表不均匀的屈光力，用于矫正散光。柱镜度数仅在特定经线上存在。

1. 柱镜的符号含义
正柱镜（+C）：用于远视散光，较少用（老式处方）。
负柱镜（-C）：用于近视散光，现代处方常用格式。
注：+C和-C可以等值转换，只是表示方式不同。

2. 柱镜度数范围
轻度散光：-0.25D ～ -1.00D
中度散光：-1.25D ～ -2.00D
高度散光：-2.25D以上

3. 柱镜在处方中的表示
示例：C = -0.75D（散光75度）
示例：C = -1.50D（散光150度）
示例：C = 0.00D（无散光）

注意：柱镜度数必须为负值（现代处方格式）或正值（老式处方格式），但不能混合。转换公式：+C = -C + 球镜调整。

四、轴位（Axis, A）

轴位表示散光的方向，范围0°～180°，用于确定柱镜的矫正方向。

1. 轴位的定义
轴位是散光最弱经线的方向（与柱镜力量方向垂直）。
例如：轴位180°表示散光力量在90°方向（垂直方向）。

2. 轴位的重要性
轴位错误会导致矫正不足或过度矫正，影响视力清晰度。
轴位误差应控制在±5°以内，否则顾客会感到不适。

3. 轴位在处方中的表示
示例：A = 180°（散光轴位在180°方向）
示例：A = 90°（散光轴位在90°方向）
示例：A = 45°（散光轴位在45°方向，斜轴散光）

4. 常见轴位类型

轴位范围 散光类型 常见人群 矫正难度
180°±10° 顺规散光 大多数人 容易
90°±10° 逆规散光 老年人较多 较难
45°或135°±10° 斜轴散光 较少 最难

五、处方示例与解读

完整的验光处方包含球镜（S）、柱镜（C）、轴位（A）三个参数。

示例1：单纯近视
S = -2.50D, C = 0.00D, A = 0°
解读：近视250度，无散光。

示例2：近视+散光
S = -3.00D, C = -1.00D, A = 180°
解读：近视300度，散光100度，轴位180°（顺规散光）。

示例3：远视+散光
S = +2.00D, C = -0.75D, A = 90°
解读：远视200度，散光75度，轴位90°（逆规散光）。

示例4：复合散光
S = -1.00D, C = -2.50D, A = 45°
解读：近视100度，高度散光250度，轴位45°（斜轴散光，矫正较困难）。

专业提示：解读处方时，先关注球镜度数（确定近视/远视程度），再看柱镜度数（确定散光程度），最后看轴位（确定散光方向）。三个参数缺一不可。

📝 本日学习小结

1. 屈光度：衡量透镜屈光能力的单位，D = 1/f

2. 球镜（S）：矫正近视（-）或远视（+），度数范围-6.25D～+6.25D

3. 柱镜（C）：矫正散光，现代处方用负柱镜（-C），度数范围-0.25D～高度

4. 轴位（A）：散光方向，0°～180°，误差应≤±5°

5. 处方解读：S+C+A三参数缺一不可，先球镜再柱镜最后轴位

        二、问答题

        4. 请解读以下验光处方：右眼 S=-4.00D, C=-1.50D, A=90°；左眼 S=-3.50D, C=-1.25D, A=85°。说明顾客的屈光状态。
        参考答案：
        右眼：S=-4.00D（近视400度），C=-1.50D（散光150度），A=90°（逆规散光）。解读：中度近视+中度逆规散光。
