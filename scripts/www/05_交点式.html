交点式

已知两个交点，交点式最快；交点中点就是对称轴。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

第 2 讲提过交点式 y=a(x−x₁)(x−x₂)，但只用它求解析式太可惜了。这个形式本身藏着大量信息：两个交点往那儿一摆，对称轴、弦长、根的和积全都能直接读出来。

更重要的是，它是连接「函数」与「方程」的桥：ax²+bx+c=0 的两根，正好是抛物线与 x 轴交点的横坐标。这一讲把这座桥走通。

壹从原理上讲透

一、交点式从哪来

设抛物线与 x 轴交于 (x₁,0)、(x₂,0)，说明 x₁、x₂ 是方程 ax²+bx+c=0 的两个根。由因式定理，二次三项式可以分解为 ax²+bx+c = a(x−x₁)(x−x₂)，于是函数式写成：

y = a(x − x₁)(x − x₂)

把它展开核对：a[x² − (x₁+x₂)x + x₁x₂] = ax² − a(x₁+x₂)x + a·x₁x₂，与原式比对即得韦达定理 x₁+x₂ = −b/a、x₁x₂ = c/a。也就是说，交点式与韦达定理是同一件事的两种说法。

二、交点式自带的信息

两个交点
(x₁, 0) 与 (x₂, 0)，即方程的两根
对称轴
x = (x₁ + x₂)/2　（两交点的中点）
弦长
|x₁ − x₂| = √Δ/|a|　（第 15 讲会专门证明）
顶点横坐标
同样是 (x₁+x₂)/2，代入可求顶点纵坐标

为什么对称轴是两交点中点？因为抛物线关于对称轴对称，而两个零点高度相同（都是 0），所以它们必然关于对称轴对称，对称轴就落在它们正中间。这个结论非常好用，看到两个交点就当白捡了一条对称轴。

使用前提：抛物线与 x 轴必须有交点，即 Δ ≥ 0。若 Δ < 0，则不能写出实数范围内的交点式——这本身就是一条重要的判断题（见第 10、14 讲）。

贰图像里的逻辑

叁核心结论（要背的）

交点式
y = a(x − x₁)(x − x₂)，其中 x₁、x₂ 为两根
对称轴
x = (x₁ + x₂)/2 = −b/(2a)
与韦达的关系
x₁ + x₂ = −b/a，x₁x₂ = c/a
弦长
|x₁ − x₂| = √Δ / |a|
使用前提
Δ ≥ 0（与 x 轴确有交点）

看到「与 x 轴交于 A、B 两点」这类条件，第一反应就是交点式 + 白捡对称轴。

若两交点重合（Δ=0），交点式退化为 y=a(x−x₁)²，顶点恰好在 x 轴上。

肆解题步骤：拿到题怎么下手

  1. 确认可用：先判断抛物线与 x 轴是否有交点（Δ ≥ 0 或图上看得出来）。
  2. 设式：设 y = a(x − x₁)(x − x₂)，把两个交点横坐标填进去。
  3. 求 a：代入第三个已知点（通常是与 y 轴的交点或顶点）。
  4. 展开：得到一般式 y = ax² + bx + c，顺势读出 b、c。
  5. 顺手取用：对称轴 = 两交点中点，弦长 = 两点距离，需要时直接用。

伍例题精讲

例1抛物线与 x 轴交于 A(−2,0)、B(4,0)，且与 y 轴交于点 (0,−8)，求解析式、对称轴和顶点。
展开完整解析

思路：两个交点已知，第三个条件是与 y 轴交点，正好用来求 a。

  1. 设 y = a(x + 2)(x − 4)。
  2. 代入 (0,−8)：−8 = a·2·(−4) = −8a → a = 1。
  3. 所以 y = (x+2)(x−4) = x² − 2x − 8。
  4. 对称轴是两交点中点：x = (−2 + 4)/2 = 1。
  5. 顶点纵坐标：f(1) = 1 − 2 − 8 = −9，顶点 (1, −9)。
答：y = x² − 2x − 8；对称轴 x = 1；顶点 (1, −9)。
例2 · 逆用交点式已知抛物线 y = x² + bx + c 与 x 轴两交点的横坐标之和为 4、乘积为 −5，求 b、c。
展开完整解析

思路：两根的和与积已经给出，直接使用韦达关系即可。

  1. 设两根为 x₁、x₂，则二次式为 x² − (x₁+x₂)x + x₁x₂。
  2. 与 x² + bx + c 对比：−(x₁+x₂) = b 且 x₁x₂ = c。
  3. 代入 x₁+x₂ = 4 → b = −4；x₁x₂ = −5 → c = −5。
  4. 检验：y = x²−4x−5 = (x−5)(x+1)，两交点横坐标 5 与 −1，和为 4、积为 −5 ✓。
答：b = −4，c = −5。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 符号写反：交点横坐标是 −2 时要写成 (x + 2)，写成 (x − 2) 就把交点放到了 +2。
  • 忽略 Δ ≥ 0 前提：题目若说「与 x 轴没有交点」，交点式这条路直接封死。
  • 把对称轴当成两交点的平均数忘了除以 2：对称轴是中点，必须取平均。
  • 交点式与一般式互化时漏乘 a：a(x−x₁)(x−x₂) 展开后常数项是 a·x₁x₂，别忘了乘 a。

柒它在生活里长什么样

🏀 从课本走到现实

  • 拱桥跨度：桥拱与水面（x 轴）的两个交点相距就是桥梁跨度，中点就是桥拱最高点所在的竖直位置。
  • 喷泉水柱：喷嘴与落水点的水平距离就是水柱跨度，中点正上方是最高点。
  • 投篮落点：球出手点到落筐点的水平距离确定后，中点位置就是最高点出现的位置。

捌本节小结

✍️ 记住这几条就够了

  • y = a(x−x₁)(x−x₂) 是已知两交点时的最优起手式。
  • 两交点的中点就是对称轴，看到两个交点等于白捡一条轴。
  • 交点式与韦达定理同源：x₁+x₂=−b/a、x₁x₂=c/a。
  • 使用的前提是 Δ ≥ 0；Δ = 0 时退化为 a(x−x₁)²。
