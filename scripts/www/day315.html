学习内容

一、为什么要做流失预警

流失预警的核心思想是"防患于未然"——在会员真正流失之前，通过行为信号识别出"有流失风险"的会员，然后主动介入，避免流失发生。这比"流失后再挽回"成本低5-10倍，成功率高3-5倍。

1. 流失的代价
一个会员流失，直接损失是其年均消费额 × 预期留存年数。间接损失更大：该会员可能不会再来，也可能向朋友说"这家店不行"，造成口碑损失。更重要的是，流失会员的"坑"需要新会员来填——获客成本通常是留存成本的5-10倍。

2. 预警 vs 挽回
预警是"在会员还在你店里时发现问题"，挽回是"会员已经走了再请回来"。预警的成功率通常在40-60%，挽回的成功率只有10-20%。所以，预警比挽回重要得多。

专业提示：最好的流失预警系统是"店长+店员的直觉"——当你感觉"这位顾客最近不太对劲"时，往往已经出现了早期信号。把直觉系统化，就是预警模型。

二、流失前的行为信号

会员流失不是"突然发生"的，而是一个渐进过程。以下是流失前的典型行为信号：

1. 到店频次下降（Frequency Drop）
这是最直观的信号。如果会员历史平均45天到店一次，但最近已经90天没来，就是强预警信号。关键：要对比"历史平均"而非"固定周期"——每个会员的复购周期不同，不能用同一个标准衡量所有人。

2. 消费金额下降（Monetary Decline）
会员还在消费，但客单价明显下降。例如：以前每次配镜都选1500元以上的镜片，最近一次只选了500元的；或者以前会配多副眼镜（近视镜+太阳镜），最近只配了一副。含义：会员可能对价格更敏感了，或者对你的产品/服务不满意了。

3. 互动参与度下降（Engagement Drop）
会员收到短信/微信不回复了，以前会参加会员活动，现在不来了，微信群里也不说话了。数据表现：短信打开率下降、微信群消息已读不回、活动邀请接受率下降。含义：会员的"情感连接"在减弱。

4. 投诉或负面反馈（Complaint/Negative Feedback）
会员提出投诉，或者私下对朋友说"这家店XXX不好"。危险信号：有投诉的会员，如果问题没有得到满意解决，流失概率高达70%。正确做法：投诉是"最后的沟通机会"——处理好，会员会更忠诚；处理不好，直接流失。

5. 生活状态变化（Life Event Change）
会员搬家了、换工作了、孩子长大了（不再需要青少年近视防控产品）、退休了（收入变化）。如何发现：通过聊天、社交媒体、会员资料更新来捕捉。生活状态变化往往意味着需求变化，如果不及时调整策略，会员会流向更"懂他"的竞争对手。

三、建立流失预警模型

预警模型就是"把 intuition（直觉）变成 algorithm（算法）"。一个简单的预警模型可以包含以下维度：

1. RFM模型改编版
传统RFM是：Recency（最近消费时间）、Frequency（消费频次）、Monetary（消费金额）。改编为眼镜门店场景：
- R（Recency）：最近一次到店/消费时间，天数越大风险越高
- F（Frequency）：过去12个月到店次数，次数越少风险越高
- M（Monetary）：过去12个月消费总额，金额越低风险越高
评分方法：每个维度1-5分，总分3-15分。12-15分=低风险，8-11分=中风险，3-7分=高风险。

2. 行为信号加分项
在RFM基础上，加入行为信号作为"加分项"：
- 有未解决投诉：+2分风险
- 互动参与度下降：+1分风险
- 生活状态变化（如搬家）：+1分风险
- 竞争对手有促销活动（通过会员聊天获知）：+1分风险

3. 预警触发机制
当会员风险总分达到"中风险"阈值时，系统自动触发预警，推送给店长或客服主管。触发后24小时内必须有人跟进——打电话或发微信，了解会员近况，提供关怀或优惠。

注意：预警不是"系统的事"，而是"人的事"！很多门店装了预警系统，但预警推送后没人跟进，等于白装。预警系统只是工具，关键是"收到预警后有人立即行动"。

四、预警后的行动策略

收到预警后，不能"一刀切"地群发优惠短信，而要根据预警原因采取针对性行动。

场景A：到店频次下降（可能是忘记复查）
行动：打电话说"您好，我是XX眼镜的小李，您配镜快一年了，建议来店免费复查视力+清洗眼镜，这周六您有空吗？"
要点：以"服务"为理由，而非"推销"。

场景B：消费金额下降（可能是价格敏感）
行动：发送"老顾客专享优惠"短信，强调"性价比"和"专属感"。或者邀请到店，当面了解需求变化，推荐更适合的产品组合。
要点：不要只发短信，要有人工跟进。

场景C：互动参与度下降（可能是情感疏离）
行动：在微信群里@他，问他"最近眼睛怎么样？有什么我们可以帮忙的吗？"或者私信他，发送一篇他可能感兴趣的护眼文章。
要点：重建"人与人的连接"，而不只是"品牌与顾客的关系"。

场景D：有投诉未解决（紧急！）
行动：店长亲自打电话，道歉+提出解决方案，必要时邀请到店当面沟通。
要点：24小时内必须响应，不能拖延。

📝 今日小结
  • 流失预警核心：防患于未然，预警成功率40-60% >> 挽回成功率10-20%
  • 五大预警信号：到店频次下降 / 消费金额下降 / 互动参与度下降 / 投诉未解决 / 生活状态变化
  • RFM改编模型：R（最近到店）+F（频次）+M（金额），总分3-15分，12+低风险/8-11中风险/3-7高风险
  • 预警后行动：根据原因采取针对性行动，不能一刀切群发短信
  • 预警系统关键：有人跟进！24小时内必须行动，否则系统白装
