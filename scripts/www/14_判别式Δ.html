判别式Δ

函数方程本同源，Δ 定交点个数：几何意义是顶点与 x 轴的距离。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

为什么偏偏是 b²−4ac 这个怪式子决定有没有根？它不是凭空规定的，而是配方过程中自然出现的一项。理解了它的出身，你就不会记错公式，也知道 Δ=0 意味着什么。

这一讲把 Δ 的来历、几何意义、以及它在含参题里怎么用，一次性讲透。

壹从原理上讲透

一、Δ 是配方配出来的

解方程 ax² + bx + c = 0（a≠0），两边除以 a 并配方：

x² + (b/a)x + c/a = 0 → (x + b/2a)² = (b² − 4ac) / 4a² = Δ / 4a²

左边是一个完全平方，永远 ≥ 0。右边分母 4a² > 0 恒正，所以能不能解出实数 x，完全取决于分子 Δ 的正负：

Δ > 0
右边 > 0 → 可以开平方得到两个不同解 → 与 x 轴两个交点
Δ = 0
右边 = 0 → x = −b/2a 一个解（重根）→ 顶点恰好落在 x 轴上
Δ < 0
右边 < 0 → 平方不可能为负 → 无实数解 → 与 x 轴无交点

二、Δ 的几何意义：顶点高度

顶点纵坐标 k = (4ac − b²)/4a = −Δ/(4a)。于是：

a > 0 且 Δ > 0
k = −Δ/4a < 0 → 顶点在 x 轴下方 → 必穿过两次
任意 a，Δ = 0
k = 0 → 顶点正好在 x 轴上 → 相切
a > 0 且 Δ < 0
k > 0 → 顶点在 x 轴上方 → 完全悬空

看到了吗：Δ 的正负，本质上说的是顶点相对于 x 轴的位置。这就是为什么「算 Δ」能解决一大类「能不能」的问题。

判别式只回答「有没有」「有几个」，不回答根具体是多少。想知道根的大小分布（都比 3 大、都在某个区间里），需要第 24~26 讲的「卡点三条件」，别指望 Δ 一个人搞定。

贰图像里的逻辑

叁核心结论（要背的）

Δ = b² − 4ac
来自配方过程中被开方的一项
Δ > 0
两个不同实根 / 两个交点
Δ = 0
两个相等实根（重根）/ 顶点在 x 轴上
Δ ≥ 0
有实根（含重根），常用于「有公共点」类题
Δ < 0
无实根 / 无交点

几何记忆法：k = −Δ/(4a)——Δ 说的是顶点在 x 轴的哪一侧。

「有公共点」⟹ Δ ≥ 0；「有两个公共点」⟹ Δ > 0，一字之差别丢了等号。

肆解题步骤：拿到题怎么下手

  1. 明确问的是什么：有没有根（Δ≥0）还是两个不同根（Δ>0）。
  2. 抄 a、b、c（含符号），代入 b² − 4ac，建议分两步写下 −4ac 的值。
  3. 列不等式：按题意写 Δ>0 / Δ=0 / Δ<0 / Δ≥0。
  4. 解含参不等式：注意二次项系数是否为 0 的讨论（若题目说是二次函数则 ¬）。
  5. 回头看图检验：把求得的参数代回，判断顶点在轴的哪一侧。

伍例题精讲

例1判断 y = 2x² − 3x + 4 与 x 轴是否有交点。
展开完整解析

思路：把 a、b、c 抄清楚，注意 c 为正、a 为正。

  1. a = 2，b = −3，c = 4。
  2. Δ = (−3)² − 4·2·4 = 9 − 32 = −23。
  3. Δ < 0 → 方程无实数解 → 与 x 轴没有交点。
  4. 几何验证：顶点纵坐标 k = −Δ/(4a) = 23/8 > 0，开口向上，顶点在 x 轴上方，自然碰不到 x 轴 ✓。
答：Δ = −23 < 0，与 x 轴没有交点。
例2 · 含参已知二次函数 y = x² − 2x + m 的图象与 x 轴有公共点，求 m 的取值范围。
展开完整解析

思路：「有公共点」包含相切的情形，用 Δ ≥ 0。

  1. a = 1，b = −2，c = m。
  2. Δ = 4 − 4·1·m = 4 − 4m。
  3. 「有公共点」⟹ Δ ≥ 0 → 4 − 4m ≥ 0 → m ≤ 1。
  4. 当 m = 1 时 Δ = 0，图象与 x 轴相切于 x = 1，也算「有公共点」✓。
  5. 几何验证：顶点纵坐标 k = 1 − 2 + m = m − 1 ≤ 0，即顶点不高于 x 轴 ✓。
答：m ≤ 1。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 「有公共点」与「有两个公共点」不分：前者 Δ ≥ 0，后者 Δ > 0。
  • 符号算错：−4ac 在 a、c 异号时会变成加号，务必分步写。
  • 忘讨论二次项系数为 0：含参时若 a 可能为 0，就不是二次函数了，需单独讨论。
  • 以为 Δ 能管根的位置：想知道根是否大于某数，Δ 不够用，必须上第 24~26 讲的三条件。

柒它在生活里长什么样

🏀 从课本走到现实

  • 投篮能否入筐：Δ<0 意味着球的轨迹整条都在篮筐高度之上，永远进不去。
  • 桥梁是否需要支撑：桥拱与水面的关系，Δ 决定是否真的「落水」。
  • 盈亏平衡点：利润模型的 Δ<0 表示永远不亏损（恒在零以上），这正是第 20 讲恒成立问题。

捌本节小结

✍️ 记住这几条就够了

  • Δ = b² − 4ac 来自配方后被开方的一项，几何意义是顶点在 x 轴的哪一侧。
  • Δ>0 两根、Δ=0 重根（顶点在轴上）、Δ<0 无根。
  • k = −Δ/(4a)，把判别式与顶点高度统一起来。
  • 「有公共点」用 ≥，「有两个公共点」用 >。
