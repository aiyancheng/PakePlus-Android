一、什么是单光镜片

单光镜片（Single Vision Lens）是最基础、最常见的镜片类型。它的特点是整个镜片只有一个焦距，即镜片上每个点的度数完全相同。

无论顾客看远、看近还是看中距离，通过单光镜片看到的物体都是以同一个度数矫正的。这也是为什么单光镜片被称为"单光"——单一光学焦点。

门店话术提示：当顾客问"什么是单光镜片"时，可以简单回答："就是整个镜片度数一样的眼镜，最常见，也最便宜。"

二、单光镜片的核心特点

1. 结构简单，技术成熟
单光镜片的设计和制造工艺最为成熟，质量稳定，价格相对低廉。对于大多数视力问题，单光镜片都能很好地解决。

2. 视野清晰，无畸变区
与渐进多焦点镜片不同，单光镜片没有"模糊区"或"畸变区"。顾客通过镜片任何位置看出去，度数都是一致的，适应期极短，甚至无需适应。

3. 可选折射率范围广
从1.50到1.74，各种折射率的单光镜片都有丰富选择，可以满足不同度数、不同预算顾客的需求。

4. 镀膜兼容性好
单光镜片可以搭配各种镀膜：增透膜（减反射）、疏水膜（防水防油）、防静电膜、防蓝光膜等，几乎没有任何技术限制。

三、单光镜片的适用人群

1. 单纯近视或远视人群
这是单光镜片最大的适用群体。年轻近视患者（40岁以下）通常远视力需要矫正，近视力正常，一副单光近视镜即可满足需求。

2. 散光人群
单光镜片同样可以矫正散光（通过柱面设计）。散光度数在-2.00D以内的，单光镜片矫正效果极佳。

3. 儿童青少年
18岁以下人群，由于晶状体调节能力极强，不适合使用渐进镜片（可能导致调节功能退化）。单光镜片是儿童青少年配镜的标准选择。

4. 老花初期（仅看近用）
部分老花初期顾客，如果只需要一副"老花镜"专门用来看书看手机，也可以选择单光正镜片（老花镜）。

重要提醒：40岁以上人群如果出现"看远清楚、看近模糊"，说明已经出现老花。此时如果配单光远用镜片，看近时仍需摘眼镜或另外配一副老花镜，不够方便。这类顾客更适合渐进多焦点镜片。

四、单光镜片 vs 渐进镜片：如何为顾客选择

对比维度 单光镜片 渐进镜片
适用年龄 全年龄 40岁以上
视野 全视野清晰 两侧有畸变区
适应期 几乎无 1-2周
价格 低-中 中-高
看远+看近 需两副眼镜 一副搞定
📝 今日小结
  • 单光镜片 = 整个镜片只有一个焦距，最简单、最常见、最便宜
  • 适用人群：单纯近视/远视、散光、儿童青少年、老花初期（仅看近）
  • 优势：视野无畸变、适应期短、价格低、镀膜选择多
  • 局限：40岁以上老花人群需要两副眼镜（远用+近用），不如渐进方便
