老花眼检查：ADD精确测定

模块七：特殊人群配镜 · 第34周
培训进度 231/365
📚
学习内容

一、什么是ADD及其临床意义

ADD（Addition，近附加度数）是指为满足近距离用眼需求，在远用矫正度数基础上额外增加的凸透镜度数。ADD的精确测定是渐进多焦点眼镜和双光眼镜验配中最关键的环节。

1. ADD错误的后果

  • ADD过高：近用清晰但视野范围缩小，睫状肌无放松余地，容易视疲劳；渐进通道变短，适应困难
  • ADD不足：近用不清晰，顾客会不自觉地"伸长脖子"或将阅读物拿得更远，同样产生疲劳
  • ADD不对称：左右眼ADD不同（除非有特殊原因）会导致渐进镜片两侧不一致，严重影响舒适度

2. 保留一半调节幅度的原则

ADD计算公式：ADD = 所需调节力 - 保留调节力（1/2调节幅度）

例如：顾客40cm工作距离需要+2.50D调节力，调节幅度为+3.00D，保留一半即1.50D，则ADD = 2.50 - 1.50 = +1.00D。这样顾客可以舒适地看近，又不会让睫状肌完全"闲置"。

二、ADD测定的四种方法

方法一：年龄法（初步估算）

年龄预估ADD年龄预估ADD
45-49岁+0.75 ~ +1.25D55-59岁+1.50 ~ +2.00D
50-54岁+1.00 ~ +1.50D60-65岁+2.00 ~ +2.50D

年龄法仅作初步参考，不可作为最终处方的依据。

方法二：融合交叉柱镜法（FCC）——推荐首选

  1. 顾客佩戴远用全矫处方，双眼同时视
  2. 在综合验光仪上设置±0.50D交叉柱镜（负轴90°）
  3. 在40cm处投射十字网格视标
  4. 降低室内照明至昏暗（降低景深、暴露真实调节需求）
  5. 询问顾客：横线和竖线哪组更清晰/黑？
  6. 若横线更清晰→加正镜（+0.25D/次）；竖线更清晰→加负镜；调整直到两组线一样清晰
  7. 最终加入的正镜度数即为初步ADD

方法三：负镜法（测量调节幅度后计算）

  1. 远用全矫下，40cm处放置近视力表
  2. 双眼逐渐增加负镜（-0.25D/次）直到视标持续模糊
  3. 总负镜度数（绝对值）= 调节幅度
  4. ADD = 1/工作距离(m) - 1/2调节幅度

方法四：推近法（最直接、需要试戴验证）

  1. 远用全矫下，手持近视力表从远处慢慢推向顾客
  2. 记录视标开始模糊的位置（模糊点），计算调节幅度
  3. 根据工作距离计算ADD
临床建议：先用年龄法获得初步估算范围，再用FCC法精确测定，最后务必进行实际试戴验证。任何理论公式都不能替代顾客的真实反馈！

三、ADD测定的影响因素

  • 工作距离：这是最大的变量。看手机（25-30cm）、看书（30-35cm）、看电脑（50-60cm）、打麻将（60-70cm），不同的工作距离需要的ADD差达+1.00D以上。一定要问清楚顾客最主要的近距离用眼场景和距离。
  • 远用矫正状态：如果远用存在欠矫（尤其是远视欠矫），会影响ADD的基础值。必须在远用全矫下测定ADD。
  • 照明条件：昏暗环境下瞳孔放大、景深减小，调节需求更大。FCC法要求在暗室进行正是基于此原理。
  • 瞳孔大小：老年人瞳孔偏小，景深增大，有时ADD可以减少+0.25D。但瞳孔过于小时（如使用毛果芸香碱类药物），不应减少ADD。
  • 验光距离：部分综合验光仪的近用杆可能有细微误差，每年校准一次。

四、ADD试戴验证：不可或缺的环节

无论用何种方法测得的ADD，都必须进行试戴验证，这是确保处方准确性的最后一道关口。

试戴验证步骤：

  1. 在试镜架上放入远用度数+测定ADD
  2. 给顾客真实的阅读材料（报纸、手机、菜单、药品说明书等）
  3. 让顾客使用自然的阅读姿势和距离
  4. 观察：顾客能舒适阅读多长时间？（至少5分钟）
  5. 测试：上下浮动±0.25D，对比清晰度和舒适度
  6. 确认：顾客感觉"这个距离刚好"而不是"用了很大力气才能看清楚"
重要提醒：对于初次佩戴渐进镜片的顾客，如果ADD计算结果偏高，可适当降低+0.25D作为"适应期ADD"，待顾客适应后再调整为标准ADD。突然给足ADD可能导致适应困难、放弃佩戴。
📝 今日小结
  • ADD是近附加度数，直接影响渐进/双光镜片的舒适度和视觉效果
  • 核心原则：保留一半调节幅度，既满足近用清晰又不让睫状肌闲置
  • FCC法（融合交叉柱镜）是推荐首选的精确测定方法
  • 工作距离是最大变量——看手机vs看电脑的ADD可差+1.00D以上
  • 必须试戴验证！用真实阅读材料让顾客在自然姿势下体验，±0.25D微调
