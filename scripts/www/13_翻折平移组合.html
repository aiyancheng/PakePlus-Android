翻折平移组合

先翻折后平移，按序作图不乱套：关于谁对称就改谁。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

把 y=x² 沿 x 轴翻个面，它就变成了开口向下的 y=−x²；沿 y 轴翻一次，看起来却没变化（因为它本来就左右对称）。翻折比平移多了一个「变号」的动作，一旦和平移组合起来，顺序就变得致命。

本讲把翻折的规则讲清，并给出组合题的固定操作顺序。

壹从原理上讲透

一、三种对称变换的代数写法

设原函数为 y = f(x)：

关于 x 轴对称
点的变换 (x, y) → (x, −y)，新式：y = −f(x)
关于 y 轴对称
点的变换 (x, y) → (−x, y)，新式：y = f(−x)
关于原点对称
点的变换 (x, y) → (−x, −y)，新式：y = −f(−x)

二、对二次函数具体会发生什么

以 f(x) = ax² + bx + c 为例：

关于 x 轴翻折
y = −ax² − bx − c：a、b、c 全部变号，开口反向
关于 y 轴翻折
y = ax² − bx + c：只有 b 变号，开口方向与宽窄都不变
关于原点对称
y = −ax² + bx − c：a、c 变号，b 不变

为什么关于 y 轴翻折只改 b？因为 a(−x)² = ax² 完全没变，b(−x) = −bx 变号，而常数项不受 x 影响。这也是对称轴从 −b/2a 变成 b/2a（关于 y 轴镜像）的代数印证。

三、组合顺序为什么重要

「先关于 x 轴翻折，再向右平移 2」与「先向右平移 2，再关于 x 轴翻折」结果不同吗？动手算一下：

前者：y=−f(x) → 右移 2 → y = −f(x−2)；后者：f(x−2) → 翻折 → y = −f(x−2)。咦，居然相同！

但「先向上平移 3 再关于 x 轴翻折」得到 −(f(x)+3) = −f(x)−3；「先翻折再上移 3」得到 −f(x)+3，两者相差 6。所以纵向操作与翻折交换顺序会改变结果，必须严格按题序。

安全口诀：先把题目动作按顺序翻译成「对 x 的操作」与「对整式的操作」，每一步只改一处；做完用顶点位置验证（翻折会改变顶点纵坐标的符号，纵向平移会改变纵坐标，横向平移改横坐标）。

贰图像里的逻辑

叁核心结论（要背的）

关于 x 轴
y = −f(x)：a、b、c 全变号，开口反向
关于 y 轴
y = f(−x)：只有 b 变号，开口与宽窄不变
关于原点
y = −f(−x)：a、c 变号，b 不变
组合顺序
横向平移与翻折可交换；纵向平移与翻折不可交换

判断做对没有，最实用的检查是 追踪顶点：翻折改纵坐标符号，横向平移改横坐标，纵向平移改纵坐标。

翻折不改变 |a|，所以开口的宽窄始终不变（与第 11 讲呼应）。

肆解题步骤：拿到题怎么下手

  1. 明确变换序列：把题目里每个动作按顺序编号。
  2. 逐个作用：每一步只用一条规则（改 x / 改整式 / 整体变号），别一次做两件事。
  3. 化简并配方：每步之后化到顶点式，看清当前顶点在哪。
  4. 追踪顶点自检：把顶点按同样的方式变换一遍，与解析式结果对照。
  5. 展开成题目要求的形式。

伍例题精讲

例1把抛物线 y = 2x² − 4x + 1 分别关于 x 轴、y 轴作对称，写出两种情况下的新解析式。
展开完整解析

思路：先配方看清顶点，再套「关于谁对称就改谁」的规则。

  1. 配方：y = 2(x² − 2x) + 1 = 2(x − 1)² − 1，原顶点 (1, −1)。
  2. 关于 x 轴对称：整个函数值变号 → y = −(2x² − 4x + 1) = −2x² + 4x − 1，顶点变成 (1, 1)。
  3. 关于 y 轴对称：把 x 换成 −x → y = 2(−x)² − 4(−x) + 1 = 2x² + 4x + 1，顶点变成 (−1, −1)。
  4. 检查：关于 x 轴后开口向下（a 由 2 变 −2）；关于 y 轴后 a 仍是 2、宽窄不变 ✓。
答：关于 x 轴对称 → y = −2x² + 4x − 1；关于 y 轴对称 → y = 2x² + 4x + 1。
例2 · 组合操作把 y = (x − 1)² + 2 先关于 x 轴作对称，再向右平移 2 个单位，求最终解析式。
展开完整解析

思路：两步顺序执行，每步都用顶点追踪法自检。

  1. 原顶点 (1, 2)，a = 1，开口向上。
  2. 第一步——关于 x 轴对称：y = −(x − 1)² − 2，顶点移到 (1, −2)，开口向下。
  3. 第二步——向右平移 2：把式中的 x 换成 x − 2 → y = −(x − 2 − 1)² − 2 = −(x − 3)² − 2。
  4. 顶点追踪：(1, −2) 右移 2 → (3, −2)，与解析式一致 ✓。
  5. 展开：−(x² − 6x + 9) − 2 = −x² + 6x − 11。
答：最终解析式为 y = −(x−3)² − 2（展开式 y = −x² + 6x − 11）。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 关于 y 轴翻折时忘了只有 b 变号：写成全盘变号就错了（2(−x)² = 2x² 不变）。
  • 纵向平移与翻折交换顺序：−f(x)+3 与 −(f(x)+3) 不是一回事，必须按题序。
  • 把「关于 x 轴」和「关于顶点所在的水平线」混淆：关于 x 轴对称是对 y=0 这条线翻折。
  • 做完不追踪顶点：组合变换题里，顶点追踪是唯一快速可靠的自检手段。

柒它在生活里长什么样

🏀 从课本走到现实

  • 照镜子：左右镜像只改变左右方向（类比关于 y 轴），上下颠倒（关于 x 轴）会改变整体朝向。
  • 模具翻转：把同一个碗状模具倒扣，得到的形状宽窄一样、朝向相反。
  • 桥梁倒影：水面上的倒影就是关于水平线的翻折，宽度不变、方向相反。

捌本节小结

✍️ 记住这几条就够了

  • 关于 x 轴改整式符号、关于 y 轴改 x 符号。
  • 关于 y 轴翻折时只有 b 变号，开口方向与宽窄都不变。
  • 组合变换必须按序执行；横向平移可与翻折交换，纵向不行。
  • 用「追踪顶点」做自检：符号变没变、位置挪没挪，一目了然。
