解集反推开口

解集两头开 ⟹ 开口朝上；解集在中间 ⟹ 开口朝下。端点就是两根。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

第 18 讲是「已知不等式求它解集」，这一讲把箭头反过来：已知解集，反推参数。这类题在选择题里几乎必考，而且做起来比正向题更快——因为解集的端点直接告诉你方程的两根。

只要抓住一句：不等式解集的两个端点，就是对应方程的两个根，剩下的就只剩判断开口方向了。

壹从原理上讲透

一、为什么端点就是根

不等式 ax²+bx+c > 0 的解集端点，正是函数值等于 0 的位置，也就是方程 ax²+bx+c=0 的两根。无论 >0 还是 <0，端点一定来自零点。

所以第一步永远是：把解集的两个端点抄下来，当成两根 x₁、x₂。

二、开口方向怎么定

判断依据是「解集落在两根的哪一侧」：

解集在两根之外（两头开）
说明曲线在两侧高于 x 轴 → 开口向上 → a > 0
解集在两根之间（取中间）
说明曲线在中间高于 x 轴 → 开口向下 → a < 0

再结合不等号方向复核一遍：

>0 的解集两头开
a > 0（与第 18 讲「大于取两边」一致）
<0 的解集两头开
a < 0（因为方向反了，取两边说明开口向下）
>0 的解集在中间
a < 0
<0 的解集在中间
a > 0

三、拿到两根之后能做什么

把式子写成 a(x−x₁)(x−x₂) 展开，与 ax²+bx+c 比对，即可得到 b、c 与 a 的比例关系（也就是第 5 讲的逆用韦达）：

x₁ + x₂ = −b/a，x₁x₂ = c/a

注意：三个系数只能确定到比例（b:a:c），因为把整个不等式两边同乘一个正数，解集不变。所以答案通常写成「b = −2a」这种含 a 的关系式，或得到 a、b、c 的连比。

肆解题步骤：拿到题怎么下手

  1. 读端点：把解集的两个端点记下来，设为 x₁ < x₂。
  2. 定开口：判断解集是「两头开」还是「夹中间」，结合不等号方向推出 a 的符号。
  3. 写交点式：ax²+bx+c = a(x−x₁)(x−x₂)。
  4. 展开比对：得到 −a(x₁+x₂) = b、a·x₁x₂ = c 两个关系。
  5. 作答：用含 a 的式子表示 b、c，或写出 a:b:c 的连比。

伍例题精讲

例1已知不等式 ax² + bx + c > 0 的解集为 x < −1 或 x > 3，判断 a 的符号，并写出 b、c 与 a 的关系。
展开完整解析

思路：端点 −1 与 3 就是两根；解集两头开说明开口向上。

  1. 端点 = 两根：x₁ = −1，x₂ = 3。
  2. 解集是「两头开」，且不等号为 >0 ⟹ 开口向上 ⟹ a > 0。
  3. 写交点式：ax²+bx+c = a(x+1)(x−3) = a(x² − 2x − 3)。
  4. 比对系数：b = −2a，c = −3a。
  5. 复核：因 a>0，故 b<0、c<0；取 x=0 代入原不等式得 c>0？注意这里 c=−3a<0，原式为 ax²+bx+c 在 x=0 时等于 c<0，而 0 不在解集内（0 在 −1 与 3 之间）✓。
答：a > 0，b = −2a，c = −3a（即 a:b:c = 1:(−2):(−3)）。
例2 · 不等号陷阱已知不等式 ax² + bx + c < 0 的解集为 x < −1 或 x > 3，判断 a 的符号并写出 b、c 与 a 的关系。
展开完整解析

思路：同样是「两头开」，但这次不等号是 <0，结论要反过来。

  1. 端点仍是两根：x₁ = −1，x₂ = 3。
  2. 解集「两头开」，按第 18 讲口诀这是 >0 的形状；现在却是 <0 ⟹ 说明开口向下 ⟹ a < 0。
  3. 仍写 ax²+bx+c = a(x+1)(x−3) = a(x² − 2x − 3)，所以 b = −2a、c = −3a（关系不变）。
  4. 但这一回 a<0，故 b = −2a > 0、c = −3a > 0。
  5. 复核：取 x=0，原式值 = c > 0，而题目要 <0 的解集，0 确实不在解集内 ✓。
答：a < 0，b = −2a（正值），c = −3a（正值）。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 只看解集形状不看不等号：同样是两头开，>0 得 a>0，<0 得 a<0，必须两者结合。
  • 把端点当成 b、c：端点是根，要用韦达关系转换，不是直接抄成系数。
  • 忘记只能定比例：答案写成具体数值通常不对，应写成含 a 的关系式或连比。
  • 不复核：随手取一个点代入原式，五秒钟能发现方向错误。

柒它在生活里长什么样

🏀 从课本走到现实

  • 反推设计参数：已知产品合格区间（解集），反推设计参数（系数），是工程逆向设计的常态。
  • 由结果反推规则：知道哪些价格区间有利润，就能倒推出成本结构参数的比例关系。
  • 侦探式思维：结果藏着原因的痕迹，这与生活的归因分析是同一种思路。
