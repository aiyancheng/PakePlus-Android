学习内容

一、棱镜的光学原理

棱镜（Prism）是一种三棱柱形光学元件，光线通过棱镜时会向底部方向折射（弯曲），影像看起来会向顶部方向偏移。这一特性被用于矫正斜视、隐斜及双眼视功能异常。

棱镜度（Prism Diopter，Δ）
棱镜度是衡量棱镜偏折能力的单位：
1Δ（1棱镜度）= 在1米距离处使光线偏折1厘米

棱镜方向的描述方式

  • 底向内（Base In，BI）：棱镜底部朝向鼻侧，使影像向颞侧偏移，用于矫正外斜
  • 底向外（Base Out，BO）：棱镜底部朝向颞侧，使影像向鼻侧偏移，用于矫正内斜、辅助集合不足
  • 底向上（Base Up，BU）：棱镜底部向上，用于矫正垂直斜视
  • 底向下（Base Down，BD）：棱镜底部向下，用于矫正垂直斜视
记忆口诀：光线向底偏，像偏向顶端。底向内→像向外（颞侧），底向外→像向内（鼻侧）。矫正斜视的原理是"把两眼的像对齐，让大脑融合成单一图像"。

二、棱镜的临床应用

1. 斜视的棱镜矫正

  • 外斜视（眼球向外偏）：加 Base In（底向内）棱镜
  • 内斜视（眼球向内偏）：加 Base Out（底向外）棱镜
  • 上斜视（眼球向上偏）：患眼加 Base Down（底向下）
  • 下斜视（眼球向下偏）：患眼加 Base Up（底向上）

2. 隐斜的棱镜矫正
隐斜（Phoria）是融合控制下的斜视倾向，轻度不需处理；若引起视疲劳、头痛、复视，可用棱镜矫正。

3. 棱镜处方书写格式

  • 格式：度数 + 方向，例如 "2Δ BI"（2棱镜度底向内）
  • 完整处方示例：OD: -3.00DS / -1.00DC × 180° · 1.5Δ BO
  • 双眼棱镜可分别写，也可在两眼之间平分（如总量4Δ BI，每眼各2Δ BI）
斜视类型 棱镜方向 作用原理
外斜视 Base In（BI） 将像移回内侧，减少外偏需求
内斜视 Base Out（BO） 将像移回外侧，减少内偏需求
上斜视 Base Down（BD） 将像下移，补偿眼球上偏
集合不足 Base Out（BO）低量 减少近距集合需求，缓解视疲劳
重要提醒：棱镜处方必须由眼科医生或验光师开具，门店员工不可自行添加棱镜。顾客如有复视、头晕、眼位异常，应转介至专科诊断，不能擅自配棱镜镜片。

三、无意棱镜效应与控制

除处方棱镜外，镜片度数和瞳距偏差也会产生"无意棱镜效应"，影响双眼视觉平衡。

普伦蒂斯法则（Prentice's Rule）
棱镜量（Δ）= 镜片度数（D）× 偏心距离（cm）

  • 例：-5.00D 镜片，光学中心偏差3mm（0.3cm）→ 棱镜量 = 5 × 0.3 = 1.5Δ
  • 高度数镜片对PD和光学中心的偏差极为敏感
  • 双眼无意棱镜不平衡会导致双眼融合困难、头晕、视疲劳

控制措施

  • 精确测量和使用单眼PD，减少水平偏心
  • 镜架调整到位（不歪斜），避免垂直棱镜不平衡
  • 高度数镜片（±4.00D以上）加工精度要求±1mm以内
实际应用：顾客换新眼镜后头晕，在排除度数错误后，要检查镜架是否歪斜（造成垂直棱镜不平衡），以及PD是否有偏差（造成水平棱镜效应）。调整镜架有时可以消除不适症状。
📝 今日小结
  • 棱镜使光线偏向底部，影像偏向顶部；单位棱镜度Δ
  • BI矫正外斜，BO矫正内斜，BU/BD矫正垂直斜视
  • 棱镜处方必须由专业人员开具，门店不可自行添加
  • 普伦蒂斯法则：无意棱镜 = 度数(D) × 偏心(cm)；高度数配镜精度要求高
