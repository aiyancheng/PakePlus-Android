平移·顶点平移法

顶点先行，图像跟着走：先搬顶点再写顶点式，比替换 x 更稳。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

第 1 讲讲了「替换 x」的平移做法。它很顺手，但遇上连续多次平移、或需要倒推原图像时就容易乱。

更稳的做法是「顶点平移法」：既然平移不改变形状（a 不变），那么整幅图像的移动完全等价于顶点这一个点的移动。搬一个点，比搬整个式子省心多了。

壹从原理上讲透

一、为什么可以只搬顶点

抛物线的三个要素是：顶点位置（决定在哪）、对称轴（由顶点横坐标决定）、开口参数 a（决定形状）。平移只改变第一个，所以：

平移 = 顶点坐标改变 + a 不变

既然顶点式 y = a(x−h)² + k 里 h、k 就是顶点坐标，我们只要算出新的 (h,k)，把 a 抄下来，新解析式就写完了。

二、正向与反向

正向平移
原顶点 → 按题目要求位移 → 新顶点 → 写新式
反向还原
新顶点 → 按相反方向位移 → 原顶点 → 写原式
复合平移
把所有位移合起来一次性作用在顶点上（左加右减、上加下减）

反向还原是这类题的常见问法：已知平移后的式子，求原来的。只要把位移方向反过来走就行。

顶点平移法与替换法是等价的，你可以用另一个来验证。建议：正向简单平移用替换法，多次平移或反向问题用顶点平移法。

贰图像里的逻辑

叁核心结论（要背的）

核心等式
平移后的式子 = a(x − h新)² + k新，a 抄原值
顶点位移
右移 m：h+m；上移 k：纵坐标 +k（左、下取负）
反向还原
把位移全部反过来作用在「平移后」的顶点上
等价旧法
替换法：左右改 x（左加右减），上下改尾巴

a 是平移过程中的不变量，写新式时直接抄下来。

多步平移时先把所有位移合成一次总位移，避免中间过程累积误差。

肆解题步骤：拿到题怎么下手

  1. 求原顶点：把原式配方成 y=a(x−h)²+k，读出 (h,k) 和 a。
  2. 算新顶点：把所有平移动作合并（右为 +，上为 +），直接加到 (h,k) 上。
  3. 写新式：y = a(x − h新)² + k新，a 用原值。
  4. 反向题反向做：已知新式求原式时，位移取相反方向。
  5. 展开与检验：把结果展开成一般式，并用「原图某点平移后应落在新图上」验证。

伍例题精讲

例1把 y = 2x² − 8x + 5 向右平移 3 个单位、再向上平移 2 个单位，求新解析式。
展开完整解析

思路：先配方拿到顶点，再一次性平移它。

  1. 配方：y = 2(x² − 4x) + 5 = 2(x − 2)² − 3，原顶点 (2, −3)，a = 2。
  2. 合并位移：右移 3 → 横坐标 2+3 = 5；上移 2 → 纵坐标 −3+2 = −1。
  3. 新顶点 (5, −1)，a 仍为 2 → y = 2(x − 5)² − 1。
  4. 展开：2(x² − 10x + 25) − 1 = 2x² − 20x + 49。
  5. 替换法验证：原式右移 3 → 2(x−3−2)²−3 = 2(x−5)²−3，再上移 2 → 2(x−5)²−1 ✓。
答：y = 2(x−5)² − 1（展开式 y = 2x² − 20x + 49）。
例2 · 反向还原某抛物线向左平移 2 个单位、再向上平移 3 个单位后得到 y = 2x² + 4x + 5，求原来的抛物线。
展开完整解析

思路：先把结果配成顶点式拿到「平移后的顶点」，再把位移倒过来走回去。

  1. 配方新式：y = 2(x² + 2x) + 5 = 2(x + 1)² + 3，平移后的顶点为 (−1, 3)，a = 2。
  2. 倒推位移：原来被「左移 2、上移 3」，还原就要「右移 2、下移 3」。
  3. 原顶点：横坐标 −1 + 2 = 1；纵坐标 3 − 3 = 0。
  4. 所以原式为 y = 2(x − 1)² + 0 = 2(x − 1)² = 2x² − 4x + 2。
  5. 验证：把它左移 2 → 2(x+2−1)² = 2(x+1)²，再上移 3 → 2(x+1)²+3 = 2x²+4x+5 ✓。
答：原来的抛物线为 y = 2(x−1)² = 2x² − 4x + 2。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 还原时方向搞反：题目说左移，还原必须右移；用一个简单的点检验就能发现。
  • 中间过程多次配方：正确做法是一次性把总位移加到顶点上，不要每步展开再配方。
  • 把 a 改了：平移不改变形状，a 必须原样复制。
  • 顶点式括号写反：新顶点 (5,−1) 应写成 2(x−5)²−1，写成 (x+5) 就把顶点放到了 −5。

柒它在生活里长什么样

🏀 从课本走到现实

  • 小区规划：把一栋标准户型的图纸整体挪到小区另一个位置，户型（a）不变，只有坐标变。
  • 喷泉机组迁移：整套喷水形状不变，只需改变喷嘴安装坐标。
  • 动画制作中的关键帧：物体形状不变，只让锚点（顶点）沿轨迹移动。

捌本节小结

✍️ 记住这几条就够了

  • 平移 = 顶点搬家 + a 不变。
  • 正向简单平移用替换法，多次平移和反向问题用顶点平移法。
  • 还原类题目把位移全部取反再走一遍。
  • 算完用另一个方法交叉验证，答案几乎不会错。
