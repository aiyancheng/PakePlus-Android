一、球镜度数的基本概念

球镜度数（Spherical Power，缩写 S 或 SPH）是验光处方中最核心的参数之一，表示镜片对光线的聚散能力。单位为屈光度（Diopter，简写 D），俗称"度"（1D = 100度）。

1. 正球镜（凸透镜，+号）
正号表示聚光镜片，光线通过后向中心汇聚。主要用于矫正：

  • 远视（Hyperopia）：眼球轴距偏短，平行光线聚焦在视网膜后方，需要正球镜将焦点前移至视网膜
  • 老花眼（Presbyopia）：晶状体调节力减退，近距阅读时需要正球镜补充调节力
  • 矫正后的 ADD 部分：渐进镜片的近用区同样使用正度数附加

2. 负球镜（凹透镜，-号）
负号表示发散镜片，光线通过后向四周扩散。主要用于：

  • 近视（Myopia）：眼球轴距偏长，平行光线聚焦在视网膜前方，需要负球镜将焦点后移至视网膜
  • 近视度数越深，负球镜度数越大，绝对值越高（如 -6.00D = 600度近视）
门店话术：当顾客问"正数和负数什么意思"，可以说："负号是近视，表示需要凹镜片帮助光线在眼睛里'聚焦更远'；正号是远视或老花，需要凸镜片帮助光线'聚焦更近'。就像用放大镜和反向镜看东西的原理一样。"

二、球镜度数的书写规范

专业验光处方中球镜度数有严格的书写和读取规范：

处方写法 含义 俗称
-3.00 DS 纯近视300度 300度近视
+2.00 DS 纯远视200度 200度远视
-4.50 DS 近视450度 450度近视
Plano（PL） 球镜为零（无近远视） 平光镜（可能有散光）
-1.00 DC（仅散光） 球镜为零，仅有散光 纯散光100度

步进值（Step）：通常以 0.25D（25度）为最小步进，某些场景使用 0.12D（近似 12.5度）。处方中常见 0.25、0.50、0.75、1.00…… 的递增或递减。

注意：顾客自述度数和验光处方数值有时不一致（例如顾客说"500度近视"但实际处方是 -4.75DS）。核实处方原件，不能仅凭顾客口述配镜，以免度数偏差影响佩戴效果。

三、球镜度数对镜片外观的影响

不同球镜度数直接影响镜片的外观厚薄，这也是销售推荐折射率的重要依据：

1. 负球镜（近视镜片）
凹透镜中间薄、边缘厚。度数越高（绝对值越大），边缘越厚。例如：

  • -2.00D：边缘厚度约 2–3mm（普通框架可接受）
  • -5.00D：边缘厚度约 5–8mm（建议选高折射率 1.60+）
  • -8.00D：边缘厚度约 10mm+（强烈建议 1.67 或 1.74）

2. 正球镜（远视/老花镜片）
凸透镜中间厚、边缘薄。度数越高，中间越厚，镜片越重。例如：

  • +2.00D：中心厚度约 4–6mm
  • +4.00D：中心厚度约 7–10mm（建议高折射率减重）

3. 瞳距与中心厚薄的关系
瞳距越小（镜框越宽），近视镜片边缘越厚；选框时应优先考虑镜框宽度，小框更有利于减薄近视镜片边缘。

销售技巧：当顾客度数高时，主动展示不同折射率的样片厚度对比，视觉冲击力远大于言语描述。搭配一句话："相同度数下，1.74镜片的厚度只有1.56的一半左右，佩戴美观度差异非常明显。"

四、等效球镜度数（SE）的计算

等效球镜度数（Spherical Equivalent，SE）是将散光转化为等效近视/远视的计算方法，常用于：

  • 近视防控研究中评估近视程度
  • OK镜、离焦镜等近视防控产品的适配评估
  • 多焦软镜处方转化

计算公式：SE = 球镜度数 + 1/2 × 柱镜度数

举例：处方为 -3.00DS/-1.00DC × 180°

SE = -3.00 + (-1.00) / 2 = -3.00 - 0.50 = -3.50D

注意：等效球镜只用于评估总体屈光状态，不能直接作为配镜处方使用！门店配镜必须使用完整处方（球镜 + 柱镜 + 轴位），不能用 SE 代替。
📝 今日小结
  • 负球镜（-）矫正近视，正球镜（+）矫正远视/老花，单位为屈光度（D），1D=100度
  • 书写规范：以 0.25D 为步进，Plano（PL）表示球镜为零
  • 度数越高，镜片越厚：近视中间薄边缘厚，远视中间厚边缘薄
  • 等效球镜 SE = 球镜 + 1/2 柱镜，仅用于评估，不可替代配镜处方
  • 核实处方原件，不依赖顾客口述度数配镜
