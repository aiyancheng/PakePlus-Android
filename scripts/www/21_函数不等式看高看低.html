函数不等式·看高看低

图像在上函数值就大：先求交点，再看两段谁在上面。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

比较 y₁ 与 y₂ 谁大，硬解不等式当然能做，但看图像只需三秒：谁的图像在上面，谁的 y 就大。这条朴素的道理，在函数题里能省下大量计算。

本讲把这条思路固化成一个固定流程：先求交点分出若干区间，再在每个区间里看谁在上。

壹从原理上讲透

一、为什么「看高低」等价于「解不等式」

在同一个 x 处，上图像的 y 值更大。所以 y₁ > y₂ 的解集，就是 y₁ 图像压在 y₂ 上方的那段 x 范围。

两图相交的地方正好是 y₁ = y₂，也就是解集的端点——这和第 19 讲「端点就是根」完全同源。

二、标准流程

① 联立求交点
解 y₁ = y₂，得到分界点
② 分段
这些分界点把 x 轴切成若干区间
③ 取点试值
每个区间取一个代表点，代入比较谁大
④ 写解集
把 y₁ > y₂ 的区间合并起来（注意端点取不取）

三、差值法（代数版，用于需要书写过程时）

把不等式移项成 y₁ − y₂ > 0，得到一个新函数 g(x) = y₁ − y₂，再解 g(x) > 0。若 y₁ 是二次、y₂ 是一次，则 g 仍是二次函数，回到第 18 讲的解法。

两种方法可以互检：先看图定方向，再用差值法写过程，既快又规范。

图像法的真正威力在于：即使式子计算很复杂（含参、带根式），只要能在草图上判断「谁的尾巴更高」，就能写出解集的大致形状，作为验算。

叁核心结论（要背的）

核心原则
同一 x 处，图像在上者函数值大
解集端点
交点的横坐标（即 y₁=y₂ 的解）
图像流程
求交点 → 分段 → 每段的 Company → 写解集

先看图定性，再用差值法写过程，速度与规范兼得。

端点是否取到，取决于原不等式是否带等号。

肆解题步骤：拿到题怎么下手

  1. 标注两个函数：明确哪个是 y₁、哪个是 y₂，别看反。
  2. 联立求交点：解方程 y₁ = y₂。
  3. 画草图分段：按交点把 x 轴分段，标出每段谁在上。
  4. 读解集：把 y₁ 在上的段挑出来，注意是否含等号。
  5. 代数复核：移项后解 y₁ − y₂ > 0，验证结果一致。

伍例题精讲

例1求使 y₁ = −x² + 2x + 3 的函数值大于 y₂ = x + 1 的 x 的取值范围。
展开完整解析

思路：先求两图交点，再看哪段抛物线在上面。

  1. 联立：−x² + 2x + 3 = x + 1 → −x² + x + 2 = 0 → x² − x − 2 = 0 → (x − 2)(x + 1) = 0，交点 x = −1 与 2。
  2. 开口向下的抛物线在两根之间位于直线上方，故 y₁ > y₂ 对应 −1 < x < 2。
  3. 代数复核：移项 −x²+x+2 > 0 → x²−x−2 < 0 → −1 < x < 2 ✓。
  4. 取点验证：x=0 时 y₁=3、y₂=1，确实 y₁ > y₂ ✓。
答：−1 < x < 2。
例2 · 两侧型求使 y₁ = x² 的函数值大于 y₂ = 2x + 3 的 x 的取值范围。
展开完整解析

思路：这一次的答案是两侧而不是中间，注意开口方向不同导致的差异。

  1. 联立：x² = 2x + 3 → x² − 2x − 3 = 0 → (x − 3)(x + 1) = 0，交点 x = −1 与 3。
  2. 开口向上的抛物线增长更快，所以在两根之外位于直线上方。
  3. 故 x² > 2x + 3 的解集为 x < −1 或 x > 3。
  4. 取点验证：x=0 时 0 < 3 ✓（中间确实是小于）；x=4 时 16 > 11 ✓。
答：x < −1 或 x > 3。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 看图看反：先确认题目问的是 y₁>y₂ 还是 y₂>y₁，别把解集取反。
  • 交点求错：这一步错了后面全错，务必回代检验。
  • 端点取舍：严格不等号时不包含交点，带等号时才包含。
  • 只写图像结论没有过程：大题要求书写，用移项后的不等式补上过程即可。

柒它在生活里长什么样

🏀 从课本走到现实

  • 两条收益曲线：交点就是「谁更划算」的分水岭，交点之前选 A、之后选 B。
  • 会员 vs 单次付费：两种计费方式的图像相交点决定哪个更省钱。
  • 车速与安全距离：两条曲线的上下关系决定某个速度区段是否安全。

捌本节小结

✍️ 记住这几条就够了

  • 图像在上，函数值就大，这是所有函数不等式的通用原则。
  • 流程：联立求交点 → 分段 → 看高低 → 写解集。
  • 解集端点一定是两图的交点横坐标。
  • 书写大题时用「移项成 g(x)>0」补全过程。
