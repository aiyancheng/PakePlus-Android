根的正负判断

和定正负方向、积定同号异号：判根正负不用解方程。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

「这两个根是同号还是异号？都正还是都负？」——这种问题完全不必解方程。韦达定理早就给好了两条自动化规则：两根的和管方向，积管同异。

本讲把这套规则完整列出，并补上一个必须养成的习惯：用韦达之前先看 Δ（没有实根就别谈根的正负）。

壹从原理上讲透

一、韦达定理（第 5 讲已导出）

对于 ax²+bx+c=0（a≠0），两根 x₁、x₂ 满足：x₁ + x₂ = −b/a，x₁x₂ = c/a。

二、两条核心规则

积 < 0
两数异号 ⟹ 一正一负（此时 Δ 自动 > 0，无需额外检查）
积 > 0 且 和 > 0
同号且为正 ⟹ 两根都为正
积 > 0 且 和 < 0
同号且为负 ⟹ 两根都为负
积 = 0
至少一根为 0（即 c = 0）

为什么「积 < 0」时 Δ 一定 > 0？因为 ac < 0 ⟹ Δ = b² − 4ac = b² + 正数 > 0，天然有根 ✓。这条小结论在选择题里很好用。

三、完整判定表（别忘了 Δ）

两根同为正
Δ ≥ 0 且 x₁+x₂ > 0 且 x₁x₂ > 0
两根同为负
Δ ≥ 0 且 x₁+x₂ < 0 且 x₁x₂ > 0
一正一负
x₁x₂ < 0（Δ 自动满足）
有一根为 0
c = 0
先 Δ 后韦达：韦达关系描述的是「如果有根，根满足什么关系」。没有实根时谈正负毫无意义，所以第一步永远是确认 Δ ≥ 0。

记忆抓手：积定同异、和定正负。

−b/a 是两根之和、c/a 是两根之积，别记反。

肆解题步骤：拿到题怎么下手

  1. 先算 Δ：确认 Δ ≥ 0（有实根才有得谈）。
  2. 算和积：x₁+x₂ = −b/a、x₁x₂ = c/a。
  3. 看积：积 < 0 → 一正一负，直接收工。
  4. 看和：积 > 0 时再看和的符号，确定两根同正还是同负。
  5. 含参题：把条件翻译成不等式组求解，最后与 Δ 条件取交集。

伍例题精讲

例1判断方程 x² − 5x + 6 = 0 两根的正负情况。
展开完整解析

思路：先确认有根，再用和、积判断。

  1. Δ = 25 − 24 = 1 > 0，确有两个实根。
  2. 和：x₁+x₂ = −(−5)/1 = 5 > 0；积：x₁x₂ = 6/1 = 6 > 0。
  3. 积 > 0 说明两根同号；和 > 0 说明同为正 → 两根都是正数。
  4. 验证：方程解为 x=2 与 x=3，均为正 ✓。
答：两根同为正数（实际为 2 与 3）。
例2 · 韦达+Δ矛盾已知方程 x² − 2x + m = 0 的两根 α、β 满足 α² + β² − αβ < 0，求 m 的取值范围。
展开完整解析

思路：先把含两根的式子翻译成 m 的式子，再用 Δ 兜底检查是否自洽。

  1. 由韦达：α+β = 2，αβ = m。
  2. 变形：α² + β² − αβ = (α+β)² − 3αβ = 4 − 3m。
  3. 要求 4 − 3m < 0 → m > 4/3。
  4. 兜底检查：必须有实根 ⟹ Δ = 4 − 4m ≥ 0 → m ≤ 1。
  5. m > 4/3 与 m ≤ 1 互相矛盾，故满足条件的 m 不存在。
  6. 考场上遇到两个工具推出矛盾范围，立刻停笔写「无解」，不要硬凑。
答：不存在这样的 m（本题无解）。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 不检查 Δ 就用韦达：无实根时和积关系形式上仍成立，但「根的正负」没有意义。
  • 把 −b/a 记成 b/a：和是 −b/a，两个负号要留意。
  • 只判积不判和：积 > 0 只能说明同号，正负还得看和。
  • 忽略 c=0 的零根情形：有一根为 0 时积为 0，不属于上面任何一类。

柒它在生活里长什么样

🏀 从课本走到现实

  • 盈亏的两个平衡点：两个零点同为正才意味着「现实的、未来的」平衡点，落在负数时间上无意义。
  • 药物浓度模型：方程两根代表两次过阈值的时刻，必须都为正才有实际意义。
  • 投篮的落点：两根表示球到达某高度的两个时刻，两者都正则均为未来时刻。

捌本节小结

✍️ 记住这几条就够了

  • 积定同异、和定正负，先看 Δ 再套韦达。
  • 积 < 0 ⟹ 一正一负（且 Δ 自动 > 0）。
  • 两根同号的情形必须同时看积 > 0 与和的符号。
  • 含参题若两个条件推出的范围互相矛盾，答案是「无解」。
和定正负方向　积定同号异号 先看Δ兜底再做　矛盾就是无解解
