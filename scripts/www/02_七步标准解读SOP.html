模块 02 · 七步标准解读 SOP

这是整套方案的主心骨。门店的每一次正式报告解读，都必须按"①检查数据梳理 → ②异常值识别 → ③异常原因 → ④异常影响 → ⑤解决方案 → ⑥科普宣教 → ⑦案例佐证"七个环节依次完成。每一步都有明确的输入、动作、输出和完成标准。顺序不能颠倒——因为顾客只有在"听懂原因"之后，才会接受"方案"；只有"听过方案"，科普和案例才有落脚点。

时间弹性原则：常规配镜总时长控制在 8-12 分钟；青少年建档/复查 15-20 分钟；中老年首次眼健康 15-25 分钟。时间不够时，砍⑥⑦，不能砍②③④；尤其②（异常识别）绝不能省——宁可少说，也不能漏掉重要提示。遇到需转诊的情况，前半程可以直接切入，把重心放在"是什么、为什么要到爱眼城眼科、怎么去"。

第①步 · 检查数据梳理

① 检查数据梳理：先看全，再开口

建议 1-2 分钟
输入
本次检查生成的全部原始数据：电脑验光/主觉验光结果、眼轴与角膜曲率（生物测量）、眼压（非接触/接触）、裂隙灯记录、眼底照相、角膜地形图、双眼视功能检查（调节/聚散/隐斜/立体视）、泪膜相关检查；以及顾客既往档案（历史度数、历史眼轴、既往配镜史、手术史、全身病与用药史、家族史）。
动作
1. 查完整性：用"五必有清单"核对——①视力（裸眼+矫正）②客观+主觉验光③眼轴/曲率（儿童青少年必查）④眼压（成人必查）⑤眼前节+眼底（成人必查）。缺失项标注"本次未查"。
2. 查真实性：检查数据是否符合生理逻辑（如眼轴 21mm 却高度近视、左右眼数据是否录反、单眼多次测量差异是否过大）。发现可疑立即重测，不用可疑数据做解读。
3. 查连续性：调出上次记录，列出本次与上次的差值（度数变化、眼轴年化增长、矫正视力变化）。没有历史数据的首次到店顾客，本次即为基线。
4. 查基本背景：年龄、职业/学业阶段、用眼时长、戴镜习惯、家族史、全身病（高血压、糖尿病）、既往手术与外伤。
5. 在《解读记录表》上端 "数据梳理" 区勾选已完成项，留出空白处填写关键差值。
输出
①一份"数据齐全可用的检查报告"；②本次 vs 上次的差值清单（至少包含：等效球镜变化、矫正视力变化、眼轴年化增长）；③标注出的缺失项/可疑项（安排补测或复查）。
完成标准
五必有清单核对完毕、无疑似录错数据、差值已算出；记录表"数据梳理区"无空格。
常见错误
只拿最新一张报告开讲，不调历史；把电脑验光单当最终度数讲；数据明显异常仍照念不误；儿童没有眼轴数据就下"控制得不错"的结论。
这一步的开场白（让顾客知道你在认真比对，而不是随手念单子）："我先调一下您上次的数据对比一下——上次是 3 月做的，眼轴 23.62，这次…… 好，三个月长了 0.15。"

顾客最常问的一句话是："不就是验个光、配副眼镜吗？"第①步梳理数据时，视光师必须能一句话说清这次一共做了哪几类检查——这既是让顾客明白自己花钱买到了什么，也是把后面的解读建立在一套完整数据上。爱眼城的检查按四大板块组织，覆盖"眼睛好不好用、度数准不准、眼轴有没有长、两只眼睛配不配合"四个层面，常规门店流程往往只做其中一部分。

板块一 ｜ 眼部基本功能检查

检查目的

确认视力水平与眼部基础健康状态，把"看不清"先分清楚：是度数问题，还是眼睛本身的问题；同时筛查需要到爱眼城眼科就诊的眼病风险。

具体项目

裸眼视力与矫正视力（远/近）、针孔视力、非接触眼压、裂隙灯眼前节检查（角膜·前房·晶状体）、眼底照相、泪膜破裂时间与泪液分泌检查、色觉、瞳孔对光反应、眼位与眼球运动初筛。
差异点：多数常规配镜流程以"电脑验光 + 视力表"为主，眼压、裂隙灯、眼底照相常常不做或需另行安排。我们把这三项纳入成人基础检查的常规项，报告里能直接看到眼压数值与眼底图像，发现异常当场提示转诊，不靠主观经验判断。

板块二 ｜ 屈光度数的确定

检查目的

得出既能看清、又戴得住的配镜度数——目标不是"把 1.0 看出来"，而是看得清、看得久、戴着舒服。

具体项目

客观验光（电脑验光 / 检影验光）→ 主觉验光（雾视放松、红绿平衡、交叉柱镜散光轴位与度数精调、双眼平衡）→ 试戴与行走适应 → 老视近附加（ADD）测定 → 主导眼、瞳距与瞳高测量；儿童及调节不稳定者按规范做散瞳（睫状肌麻痹）验光。
差异点：常见做法是在电脑验光单上直接加减度数，省略雾视与红绿平衡，容易出现"过矫"（度数给高、看近更累）。我们坚持客观 + 主觉双轨：必做雾视放松调节、必做试戴适应、散光用交叉柱镜精调轴位；儿童散瞳前后均留记录，可对比。

板块三 ｜ 眼轴等生理参数检查

检查目的

把"度数"这个结果，追溯到"眼轴长度"这个原因——用于判断近视进展速度、评估眼底风险，也让控制手段的效果可以被量化。

具体项目

眼轴长度（AL）、角膜曲率（K1/K2）、前房深度、晶状体厚度、角膜直径（WTW）、轴率比（AL/CR）、角膜地形图（角膜形态与散光分布）、角膜厚度（按需）。
差异点：多数机构只测度数不测眼轴，家长无从判断防控手段到底有没有用。我们把眼轴列为儿童青少年必查项并建立连续档案，每次复查给出"年化增长量"，用数据说话；角膜地形图用于分清散光来源、筛查角膜形态异常征象。

板块四 ｜ 双眼聚焦与协调功能检查

检查目的

排查"度数配足了还是不舒服"的那一类问题——看近易疲劳、阅读串行跳行、注意力不集中、偶尔重影、长时间用眼后头痛。

具体项目

调节幅度、调节灵敏度（Flipper）、调节反应与调节滞后、远近隐斜、AC/A 比值、正负相对集合、集合近点（NPC）、融像范围、立体视（Titmus / Worth 四点）。
差异点：常规配镜基本不做双眼视功能检查，于是"度数没问题但看书就是累"往往无解。我们把视功能作为青少年与视疲劳人群的常规评估项，异常者给出训练或转诊建议，并在训练前后用同一组指标复测对比。

现场怎么用（三句话讲完，不背稿）

通用开场："我们这次一共做了四类检查：先看眼睛本身好不好，再把度数验准，然后量眼轴看有没有变化，最后看两只眼睛配合得好不好。所以我等下讲的不只是一个度数。"
对家长："很多地方验完度数就配镜了。我们多了眼轴和双眼视功能这两块——度数是结果，眼轴才是原因，只看度数判断不了控制得好不好。"
对视疲劳的成人："您度数其实不高，但看书容易累，问题多半出在两只眼睛的配合上。这部分一般验光不查，我们这次给您查了。"
讲优势的三条纪律（避免夸大与贬低）：
① 说事实，不贬低同行。统一说"多数常规配镜流程"，不点名任何机构，不说"别人都不专业""医院都不如我们"。
② 说项目，不说疗效。只讲"我们查了什么、为什么查"，不得说"查了就能治""查了就不会近视""我们比医院检查更准"。
③ 讲清设备定位。门店设备用于筛查与配镜参考，眼科设备用于诊断；顾客有疑似眼病时，明确提示到爱眼城眼科就诊，不拿门店检查替代医疗检查。
与第①步的衔接：梳理数据时，视光师要能在记录表上逐板块打勾——本次做了哪几个板块、缺哪一板块需补查。四个板块齐全，才叫"数据够用"；缺板块而下的结论，一律标注"本次未查，仅供参考"。

第②步 · 异常值识别

② 异常值识别：这一步是整套 SOP 的安全阀

建议 1-2 分钟
输入
第①步整理好的数据 + 差值；《指标参考区间与异常判定表》（模块03）、《异常值对照表》（模块04）。
动作
1. 全项扫描：按"视力—屈光—眼轴曲率—眼压—眼前节—眼底—双眼视—干眼"的次序，逐项对照模块03判定表，给每项打上四个档位之一：正常 / 关注 / 异常 / 建议就医。
2. 排序取舍：把结果按"重要且顾客在意"排序，本次只选定 2-3 项作为重点讲解项，其余正常项口头一句带过（"其他指标都在正常范围，放心"）。
3. 红线筛查：对照模块12《必须转诊清单》，只要命中任一项，立即启动转诊提醒动作（口头提示 + 书面提示 + 记录 + 72 小时回访），此时解读转为"就医导向"模式，不再推方案。
4. 填写《解读记录表》"异常项登记"栏：逐项写明指标名、数值、判定档位。
输出
①一份带档位标注的检查报告（可用荧光笔在给顾客那份上做记号）；②本次讲哪 2-3 项的决定；③是否触发转诊提醒的结论。
完成标准
本次实际检查的所有项目均已查表判定（不是凭印象）；异常项已在顾客报告上可视标记；红线项已按转诊流程处理。
常见错误
只看度数不看眼轴；只讲"近视加深"却漏掉眼压 24mmHg；把"关注"档说成"正常"安抚顾客；看到眼底异常提示却"怕顾客跑掉"而隐瞒。
红线提示：眼压>21mmHg、双眼眼压差>5mmHg、杯盘比（C/D）>0.6 或双眼差>0.2、角膜曲率>47D 或双眼差>1D、晶体明显混浊、视网膜出血/渗出/裂孔/脱离迹象、突发视力下降、视野缺损、眼红剧痛、糖尿病/高血压患者眼底改变——以上任一情况，必须先走转诊提醒，详见模块12。

第③步 · 异常原因

③ 异常原因：把"怎么会这样"讲成顾客能理解的故事

建议 2-3 分钟
输入
第②步确定的重点讲解项；《异常值对照表》（模块04）中的"可能原因"列；顾客的年龄、职业/学业、用眼习惯、家族史。
动作
1. 归因三问：对每一个异常项，问自己——这个数值变化，是眼球结构带来的（如眼轴变长、角膜变陡、晶体混浊）？还是用眼/习惯带来的（如长时间近距离、户外活动少、睡眠不足、揉眼）？还是发育/年龄带来的（如远视储备消耗、老视）？
2. 选择最贴切的一两条：原因最多讲两条，讲多了顾客记不住；选择时优先"与顾客生活直接相关"的那条（"您孩子每天写作业到 10 点"胜过"调节滞后"）。
3. 用比喻翻译：把每个专业原因配一个生活化说法（见下表）。
4. 口径克制：原因讲"可能"和"常见"，不下定论。例："这种情况最常见的原因是……"，而不是"就是因为……"。
输出
顾客能用自己话说出的 1-2 条原因；顾客点头认同（"是这样，我确实……"）。
完成标准
顾客复述原因无困难；视光师未使用未经解释的术语；未出现"一定是/肯定是"等绝对化归因。
常见错误
讲机制讲成生理课；把所有可能原因一股脑倒出来；使用"你肯定是因为玩手机"等指责式归因。

角膜曲率偏陡"黑眼珠前面那层透明的'窗户玻璃'弧度更弯一些，所以光折射得更多。"散光、圆锥角膜筛查

第④步 · 异常影响

④ 异常影响：讲清"和我有什么关系"，但不制造恐慌

建议 1-2 分钟
输入
第③步确定的原因；《异常值对照表》"潜在影响"列；顾客的生活场景（学习、驾驶、运动、职业用眼）。
动作
1. 场景化影响：把影响落到顾客的真实生活里——"上课看黑板要眯眼""开车看不清路牌""看手机二十分钟就头晕"，而不是抽象地讲"会加深"。
2. 时间维度：说明"现在是什么程度、继续下去大概会怎样变化"，用"趋势"而不是"必然结果"表述。
3. 分层提醒：对"关注"档只说"先留意"；对"异常"档说明"需要处理"；对"建议就医"档明确"这一步我们先不配镜，先让医生看"。
4. 语气控制：用关心式而不是威胁式。允许说"如果不注意，可能会……"，禁止说"再这样下去你就瞎了""肯定会发展成……"。
输出
顾客理解"这个情况对自己的实际影响"，并产生"该做点什么"的意愿。
完成标准
影响描述具体（可对应到生活场景）；未出现恐吓、绝对化、宿命论表述；情绪平稳的顾客未被吓到。
常见错误
过度恐吓导致顾客焦虑反感；只说"会加深"说不出后果与生活的关联；对可逆/不可逆的表述越界（如断言"高度近视一定视网膜脱离"）。
推荐句式："这个情况现在是轻中度，还不用太担心。但如果按现在这个速度往下走，明年可能就有 xxx 的变化，所以我们现在开始管是最划算的时候。"——给出希望，是这一步最重要的任务。

第⑤步 · 解决方案

⑤ 解决方案：分层给选择，让顾客自己拍板

建议 3-5 分钟
输入
前四步的结论；《异常值对照表》"应对对策"列；门店可提供产品/服务项目清单；顾客预算与时间；是否命中医嘱/转诊。
动作
1. 三层结构：每次方案都按三层表述——
  • 必做项（基础）：不带损益也必须做。如：足矫配镜、定期复查、调整用眼时长。（通常成本最低，顾客最容易答应）
  • 建议项（核心）：针对本次异常的关键干预。如：离焦镜片/角膜塑形镜评估、渐进镜、视觉训练、干眼护理。
  • 可选项（加分）：锦上添花的。如：防蓝光（按需）、偏光镜、护眼灯具。
2. 每项说明三件事：做什么 / 为什么对您有用 / 大概要花多少时间和费用（费用必须透明）。
3. 给出默认值：新人最容易在这里卡住。可用"像您这种情况，我们一般建议先用 X，三个月后再看效果决定要不要加 Y"的方式给台阶。
4. 医嘱优先：凡已有医疗机构的诊断或医嘱，门店方案不得与之冲突，只做配镜层面的配合执行。
5. 写入《方案建议书》，明确复查时间点。
输出
一份分层、可选、带时间节点的《个性化处理方案建议书》；顾客明确的下一步动作（含复查日期）。
完成标准
顾客能说出"我接下来先做什么"；必做项已获得顾客口头确认；复查日期已写入记录表与系统提醒。
常见错误
一上来就推最贵的产品；只讲产品不讲行为调整；把"建议"说成"必须"；承诺疗效（"保证降度""戴了就不涨"）——属合规红线。
禁止出现的表述："这个镜片能治好近视""保证度数不涨""戴上这个就不用复查了""别的牌子没用，只有这个有效"（贬低同行）。替代说法见模块06与模块12。

第⑥步 · 科普宣教

⑥ 科普宣教：给一条今晚就能开始做的事

建议 2-3 分钟
输入
模块08《科普知识点清单》；顾客人群属性（儿童青少年/成人/中老年）；本次发现的异常类型。
动作
1. 只讲 2-3 条：从清单中挑选与本次异常最相关的 2-3 条，讲透比讲多重要。
2. 每条配一个动作：知识 + 行动。"每天户外活动 2 小时"→"您家孩子放学后可以先在小区里玩 30 分钟再写作业。"
3. 纠正一个误区：主动点破一个常见误解，专业感立刻提升（"很多人以为度数涨了换眼镜就行，其实……"）。
4. 交付物：有条件时提供一张对应的科普小卡/单页，让顾客带回家贴在书桌或给家人看。
输出
顾客记住 1-2 条可执行的生活调整；带走的科普材料（可选）。
完成标准
每条知识点 2 句话内讲完；至少一条是"当天可执行"；无"保证""治愈"类措辞。
常见错误
一口气讲十几条；讲的都是书上的大道理没法落地；把科普讲成产品广告。
儿童三条、成人两条、中老年两条（速用版）：
儿童：①每天户外 2 小时（最关键）；②读写"一尺一拳一寸"+ 每 30 分钟看远 20 秒以上；③晚上 9-10 点前睡，熄灯后不看手机。
成人：①近距离工作每 30-40 分钟休息 5 分钟（20-20-20）；②主动眨眼睛、有意识湿润；屏幕略低于视线水平。
中老年：①每年一次眼底与眼压检查（即使没不舒服）；②控制好血压血糖，比任何保健都管用。

第⑦步 · 案例佐证

⑦ 案例佐证：用别人的真实经历，压下最后一点犹豫

建议 1-2 分钟
输入
模块09《案例库》；本次顾客的同类属性（年龄相近、问题相似、处境相近）。
动作
1. 选同类：优先选"年龄相仿 + 问题相同 + 起点相近"的案例，相似度越高越有说服力。
2. 六段式讲述：背景 → 发现 → 解释 → 行动 → 结果 → 启示（详见模块09），总时长控制在 60-90 秒。
3. 数据要具体但不必精确："眼轴三个月长了 0.2，后来半年长了 0.1"比"效果不错"有效十倍。
4. 合规：隐去姓名、只说"有一个孩子/一位顾客"，不得出现疗效承诺，不得出现具体价格折扣或诱导性表述。
输出
顾客产生"同样情况有人做过了、我也可以"的心理认同；为方案接受做最后推动。
完成标准
案例真实、同类、可感知；讲述≤90秒；无承诺、无夸大、无贬低。
常见错误
讲的例子和顾客完全不是一类人；编造数据；讲完案例不回到顾客自身（缺"启示"段）。
标准收尾（案例讲完必用）："我讲这个不是说他一定和您完全一样，每个人的情况不同。我是想说——这种情况是可以管的，而且开始得越早越主动。我们就按刚才说的先做三个月，三个月后用数据看效果，好吗？"

七步之后：收尾动作（必做 4 件）

  1. 请顾客复述："您能不能用您自己的话，跟我讲一下今天主要说了哪两件事？"——能复述出来，才算真正听懂（顾客理解度的现场检验）。
  2. 填写《顾客报告解读记录表》：当场填，不补填。写完用平板或纸质签字。
  3. 交付《方案建议书》：顾客带走一份，门店留存一份；同时把复查日期录入系统，生成提醒任务。
  4. 约定下一次复习：明确日期（不说是"有空再来"，要给具体时间，"12 月 20 日左右"），并说明复查的意义（看趋势，不是为收费）。
两人配合时的分工：一人主讲解读（视光师），一人在旁记录并适时补充生活化提问（验光师/眼保健师）。记录人负责：把顾客的原话（如"孩子每天写作业到十点半"）记下来，这是后续跟进和异议处理的素材。
