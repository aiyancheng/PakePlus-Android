一、回访服务的重要性

回访是眼镜门店客户服务的重要环节，通过主动回访了解顾客佩戴情况，及时解决问题，提升客户满意度和复购率。

1. 回访服务的核心价值
回访能及时发现顾客佩戴问题（如不适应、头晕、压痛），提供解决方案，避免问题扩大导致投诉或流失。同时，回访能增强顾客粘性，促进复购和转介绍。

2. 回访的黄金时间点
配镜后3天、7天、30天是三个关键回访时间点。3天了解初步适应情况，7天确认完全适应，30天提醒定期检查和保养。

3. 回访的基本原则
"主动、及时、专业、温暖"。主动联系而非等顾客来找你，及时解决问题，展现专业知识，传递温暖关怀。

专业提示：回访时不要只说"您好，眼镜戴着怎么样？"而要具体询问："镜片清晰度如何？镜框会不会下滑？有没有头晕或不舒服？"这样能获得更有价值的信息。

二、3天回访：初步适应确认

配镜后3天是第一个关键回访点，主要确认顾客是否初步适应新眼镜。

1. 回访目的
确认顾客初步适应情况，发现并及时解决佩戴问题（如头晕、视物变形、压痛），避免问题积累导致顾客不满。

2. 回访内容
询问：镜片清晰度？有无头晕？镜框是否舒适？有无压痛？是否需要调整？同时提醒：如有任何问题随时联系或回店调整。

3. 常见问题处理
如顾客反映头晕：询问是持续头晕还是偶尔头晕？持续头晕可能需要复查验光数据，偶尔头晕可能是正常适应过程。如压痛：邀请回店免费调整。

4. 回访话术
"张先生/女士，我是XX眼镜的小李。您3天前配的眼镜戴着还适应吗？清晰度怎么样？有没有头晕或不舒服？镜框会不会下滑？如果有任何问题，随时联系我或回来调整，这是免费的服务。"

三、7天回访：完全适应确认

配镜后7天是第二个关键回访点，主要确认顾客是否完全适应新眼镜。

1. 回访目的
确认顾客已完全适应新眼镜，无任何不适。同时了解顾客对眼镜的整体满意度，收集反馈意见。

2. 回访内容
询问：现在完全适应了吗？看远、看中、看近都清晰舒适吗？镜框佩戴一天会不会累？有没有朋友夸您的新眼镜？同时提醒：眼镜保养方法和免费调整服务。

3. 满意度收集
如果顾客表示满意，可以顺势询问："您对我们的服务还满意吗？有没有朋友也需要配眼镜？如果您推荐朋友来，我们有推荐有礼活动。"

4. 未完全适应的处理
如顾客仍不适应，必须邀请回店复查，找出问题原因（验光数据？镜片类型？镜框调整？），并提供解决方案。

注意：如果7天回访时顾客仍反映有明显不适（如持续头晕、视物不清），这不再是"正常适应过程"，必须立即邀请回店全面检查，找出根本原因并解决。

四、30天回访：定期保养提醒

配镜后30天是第三个关键回访点，主要提醒顾客定期保养和检查。

1. 回访目的
提醒顾客定期保养眼镜（清洗、紧固螺丝、调整），增强顾客粘性，为后续复购或转介绍铺垫。

2. 回访内容
询问：眼镜佩戴一个月了，还舒适吗？螺丝有没有松动？镜框需要清洗或调整吗？提醒：可以回店免费清洗、紧固螺丝、调整镜框。

3. 增值服务推介
可以顺势介绍：我们现在有会员升级活动/新品上市/节日促销，邀请顾客回店了解。但不要过于推销，以服务为主。

4. 长期关系维护
30天回访是建立长期关系的开始。告知顾客：以后每半年可以回店免费检查视力、清洗眼镜、调整镜框，我们一直都在。

📝 今日小结
  • 回访三时间点：3天（初步适应）、7天（完全适应）、30天（保养提醒），每个都有明确目的
  • 3天回访重点：发现头晕、压痛等问题，及时解决，避免积累成投诉
  • 7天回访重点：确认完全适应，收集满意度，适时请求转介绍
  • 30天回访重点：提醒保养，增强粘性，建立长期关系，为复购铺垫
