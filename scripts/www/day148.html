学习内容

一、取镜指导的重要性

取镜是顾客配镜体验的最后一个环节，也是最重要的环节之一。良好的取镜指导能让顾客快速适应新眼镜，提升满意度和口碑。

1. 取镜指导的目标
确保顾客正确佩戴新眼镜，了解保养方法，能够快速适应，并建立对门店的专业信任。

2. 不适应新眼镜的常见原因
度数变化、镜片类型变化（如首次配渐进片）、镜框形状变化、光学中心位置变化等都可能导致不适应。

3. 取镜指导的时机
在门店当场指导，让顾客试戴并确认舒适度。对于特殊镜片（渐进、变色等），需要更详细的指导。

专业提示：取镜时让顾客在门店内走动5-10分钟，确认无头晕、视物变形等不适后再让顾客离开。这能大幅减少后续投诉。

二、佩戴适应训练步骤

系统的适应训练能帮助顾客快速适应新眼镜，减少不适感。

1. 初步试戴检查
让顾客戴上新眼镜，检查：镜框是否下滑、鼻托是否舒适、镜腿是否夹头、视线是否清晰。

2. 远视力适应训练
让顾客看远处物体（如门店外的车、远处的标志），确认远距离视力清晰。如有模糊，检查是否度数不准确或镜片质量问题。

3. 中距离适应训练
让顾客看1-2米处的物体（如电脑屏幕、他人面部），确认中距离视力舒适。渐进片用户需要特别训练中距离视线。

4. 近距离适应训练
让顾客看30-40cm处的物体（如手机、书本），确认近距离阅读清晰不费力。老花镜和渐进片用户需要重点训练。

5. 行走适应训练
让顾客戴着新眼镜在门店内走动，上下楼梯，确认行走时视线稳定，无头晕或地面不平感。

三、特殊镜片的取镜指导

不同类型的镜片需要针对性的取镜指导，确保顾客能正确使用。

1. 渐进多焦点镜片
指导顾客：看远用镜片上方，看中用镜片中部，看近用镜片下方。转动头部而非眼球，避免通过镜片边缘看东西。适应期通常需要3-7天。

2. 变色镜片
告知顾客：变色需要时间（通常30秒-2分钟），恢复透明也需要时间。车内变色效果较弱（因为车窗玻璃阻隔UV）。

3. 偏光镜片
告知顾客：看手机或导航屏幕可能会有彩虹纹或变黑，这是正常现象（因为偏光片与屏幕偏振方向垂直）。

4. 防蓝光镜片
告知顾客：镜片可能微微泛黄或泛绿，这是防蓝光镀膜的正常颜色，不影响视觉效果。

注意：渐进片顾客取镜时，务必让顾客通过镜片不同区域看东西，确认每个区域都清晰。如果顾客无法通过镜片下方看清近处，可能是镜框调整不当或配镜参数错误，需要立即处理。

四、取镜时的沟通话术

专业的沟通话术能提升顾客信任度，并减少后续问题。

1. 开场白
"王先生/女士，您的眼镜已经做好了。让我帮您试戴一下，确认舒适度和清晰度。"

2. 检查舒适度
"镜框会不会下滑？鼻托这里舒服吗？镜腿会不会夹头？如果有任何不舒服，我现在帮您调整。"

3. 指导适应
"您先在这里走动一下，看看远处、近处，确认都清晰。如果是第一次戴这种镜片，可能需要2-3天适应，这是正常的。"

4. 保养指导
"这是眼镜的保养卡，上面有清洗和保养方法。如果有任何问题，随时联系我们或回来调整，这是免费的服务。"

5. 结束语
"祝您佩戴舒适！如果有任何问题，随时微信联系我们。记得3天后我们会回访，到时候再了解一下您的适应情况。"

📝 今日小结
  • 取镜指导目标：确保正确佩戴、快速适应、建立信任，当场解决问题
  • 适应训练五步：试戴检查→远视力→中距离→近距离→行走训练，每一步都要确认
  • 特殊镜片指导：渐进片（转头不看边缘）、变色片（变色需时间）、偏光片（看屏幕有彩虹纹）
  • 沟通话术要点：专业开场→检查舒适度→指导适应→保养指导→温馨结束，全程微笑服务
