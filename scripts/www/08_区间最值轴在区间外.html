区间最值·轴在区间外

轴在区间外：整段单调，最值全在端点，靠「谁离轴近」判断。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

第 3 讲处理了轴在区间里面的情形。如果轴在区间外面呢？这时整个区间落在抛物线的一侧，函数在这段上干脆就是单调的——顶点根本不在考虑范围内。

典型场景：某商品销量只能在 0~50 件之间，但理论最优销量是 80 件。此时区间里的最值出现在边界上，这就是本讲要解决的问题。

壹从原理上讲透

一、轴在区间外意味着什么

回忆单调性：a>0 时，x < h（轴左侧）函数递减，x > h（轴右侧）函数递增。

如果整个区间 [m,n] 都在轴的左边（n < h），那么区间上函数全程递减 → 左端点最大、右端点最小。

如果整个区间都在轴的右边（m > h），函数全程递增 → 左端点最小、右端点最大。

a>0，区间在轴左侧
递减：max = f(m)，min = f(n)
a>0，区间在轴右侧
递增：min = f(m)，max = f(n)
a<0，区间在轴左侧
递增：min = f(m)，max = f(n)
a<0，区间在轴右侧
递减：max = f(m)，min = f(n)

二、一句话统一记忆

其实不用背四行表格，记住第 7 讲的结论就行：开口向上时离轴越远值越大，开口向下时离轴越远值越小。轴在区间外，哪个端点离轴更远，答案就落在哪个端点：

轴在外，两端点；远离轴的端点取「远离中心的那个最值」

具体来说：a>0 时离轴远的端点取最大值，离轴近的端点取最小值；a<0 则相反。

注意轴恰好落在端点的情形：m = h 或 n = h。这时顶点就在区间的边界上，属于两种模型的交界：用「轴在内」的公式算也行（顶点值就是端点值），结果一致，不必纠结。

解题核心：先看轴在区间的哪一侧，再看开口方向。

完全不需要画完整图像，只需比较 |端点 − h| 与开口方向即可。

肆解题步骤：拿到题怎么下手

  1. 求轴：算出 h = −b/(2a)，明确判断 h 与 [m,n] 的位置关系。
  2. 确认在外：n < h 或 m > h，本讲模型成立。
  3. 看开口：确定 a 的正负。
  4. 两端点求值：把 x=m 与 x=n 分别代入算出函数值（此时不必算顶点）。
  5. 定最值：按表格或「离轴远近 + 开口方向」给出最大与最小，并检查区间开闭。

伍例题精讲

例1求 y = x² − 2x − 3 在 −2 ≤ x ≤ 0 上的最大值与最小值。
展开完整解析

思路：先求轴，看它在区间的左边还是右边。

  1. 对称轴 x = 1，而区间是 [−2, 0]，显然 n = 0 < 1，轴在区间右侧之外。
  2. a=1>0 开口向上，且区间在轴的左侧 → 这一段单调递减。
  3. 所以左端点取最大、右端点取最小。
  4. f(−2) = 4 + 4 − 3 = 5（最大值），f(0) = −3（最小值）。
  5. 验证：顶点 x=1 处值 −4 虽最小，但不在区间内，不予考虑 ✓。
答：最大值为 5（x=−2），最小值为 −3（x=0）。
例2 · 应用题某商品利润 y（元）与降价幅度 x（元）满足 y = −2x² + 20x + 300，其中 0 ≤ x ≤ 4。求最大利润。
展开完整解析

思路：开口向下，理论最优点在 x=5，超出了允许的降价范围 0~4。

  1. 对称轴 x = −20/(2·(−2)) = 5，而区间上限是 4，所以轴在区间右侧之外。
  2. a=−2<0 开口向下，区间在轴左侧 → 这一段单调递增（离顶点越近值越大）。
  3. 离轴 5 更近的端点是 x=4（距离 1），所以最大值在 x=4。
  4. y(4) = −32 + 80 + 300 = 348。
  5. 最小值在 x=0：y(0) = 300。若不限 x≤4，理论最大是 x=5 处的 350，但规则不允许 ✓。
答：最大利润为 348 元（降价 4 元时取得）。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 没判断就说「顶点是最值」：顶点不在区间内时它是无效的，必须先判位置。
  • 单调方向搞反：开口向上的左侧是递减不是递增，建议背口诀「上：左减右增；下：左增右减」。
  • 忽略端点开闭：开区间时最值可能取不到，需要写「无最大值/最小值」。
  • 应用题忘记取整与实际限制：如 x 必须为整数或正数，要在最值点附近取合法值再比较。

柒它在生活里长什么样

🏀 从课本走到现实

  • 限价政策：理论最优定价超出允许浮动区间时，最优解一定落在区间边界。
  • 田径起跑：给定的跑道长度区间与实际最优策略不匹配时，只能取区间端点。
  • 投篮距离：只能在 3~6 米出手，但最优距离是 8 米，实际只能在边界 6 米处做到最好。

捌本节小结

✍️ 记住这几条就够了

  • 轴在区间外 ⟹ 区间上单调 ⟹ 最值必在端点。
  • 判 combinations：a>0 时「左减右增」，a<0 时「左增右减」。
  • 用「离轴远近 + 开口方向」统一记忆，不必死背四行表格。
  • 顶点不在区间内就不参与竞争；顶点恰在端点时两套模型结论一致。
