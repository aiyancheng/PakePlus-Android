联立方程判交点

把 y = t 代入，交点问题就变成方程的根问题：看顶点高度即可。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

第 14 讲讲的是与 x 轴（y=0）的交点。但如果把这条水平线往上挪到 y=5，交点还存在吗？存在几个？你会发现：所有水平线与抛物线的交点问题，本质都是同一个套路。

这一讲把「函数」与「方程」彻底打通：求交点就是解方程，判个数就是算 Δ。后面第 17 讲的斜线交点，只是把 y=t 换成 y=kx+b。

壹从原理上讲透

一、交点 ⟺ 方程的解

抛物线 y = ax²+bx+c 与水平直线 y = t 的交点，必须同时满足两个式子，于是：

ax² + bx + c = t ⟹ ax² + bx + (c − t) = 0

这是一个新的一元二次方程，它的每一个解 x 就对应一个交点的横坐标。判别式：

Δ(t) = b² − 4a(c − t) = b² − 4ac + 4at = Δ₀ + 4at

二、可以完全不用算：看图说话

其实这里有个更省事的角度。把抛物线上下平移 t（等价于水平线下移），顶点高度变了而已。设原顶点纵坐标为 k：

a > 0（开口向上）
t > k → 两个交点；t = k → 一个（顶点）；t < k → 无交点
a < 0（开口向下）
t < k → 两个交点；t = k → 一个（顶点）；t > k → 无交点

一句话：开口向上时，水平线要在顶点「之上」才有交点；开口向下时在顶点「之下」。这比列式子快得多，还不容易算错。

这条思路与第 14 讲完全一致：与 x 轴的交点不过是 t=0 的特例。所以第 14 讲其实可以看成本讲的推论。

求交点 ⟹ 联立 ⟹ 解方程 ⟹ 数判别式，这是贯穿后面几讲的总思路。

能看图就别算：先求顶点纵坐标 k，直接比较 t 与 k。

肆解题步骤：拿到题怎么下手

  1. 明确对象：抛物线 y=ax²+bx+c 与直线 y=t（或两个函数之一为常数的情况）。
  2. 优先走图像路线：配方求出顶点纵坐标 k 与开口方向。
  3. 比较 t 与 k：按上面表格给出 0、1、2 个交点的结论。
  4. 需要具体交点时：解方程 ax²+bx+(c−t)=0。
  5. 含参时：把「有两个交点」翻译成 Δ(t) > 0 或 t 与 k 的不等式再解。

伍例题精讲

例1求 y = x² − 2x − 3 与水平直线 y = 5 的交点坐标。
展开完整解析

思路：联立后解一元二次方程，或先判断有没有。

  1. 联立：x² − 2x − 3 = 5 → x² − 2x − 8 = 0。
  2. Δ = 4 + 32 = 36 > 0，有两个解（顶点 −4 < 5，符合预期）。
  3. 因式分解：(x − 4)(x + 2) = 0 → x = 4 或 x = −2。
  4. 交点坐标为 (−2, 5) 与 (4, 5)。
  5. 验证：把 x=4 代入原式 y = 16 − 8 − 3 = 5 ✓。
答：交点坐标为 (−2, 5) 与 (4, 5)。
例2 · 含参若抛物线 y = x² − 2x − 3 与水平直线 y = k 有两个交点，求 k 的取值范围。
展开完整解析

思路：顶点纵坐标是 −4，开口向上，水平线要高于顶点才会穿过两次。

  1. 配方：y = (x − 1)² − 4，顶点纵坐标 k₀ = −4，开口向上。
  2. 开口向上的抛物线只在顶点之上才有「两支」，故水平线需满足 k > −4。
  3. 用判别式核对：Δ(k) = b² − 4a(c − k) = 4 − 4(−3 − k) = 4 + 12 + 4k = 16 + 4k > 0 → k > −4 ✓。
  4. 边界：k = −4 时直线恰好过顶点，只有一个交点，所以是严格大于。
答：k > −4。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 把「有两个交点」写成 Δ≥0：等于 0 时直线过顶点，只有一个交点。
  • 开口方向不看：a<0 时结论全部反过来，这是最典型的翻转错误。
  • 把 c−t 的符号搞错：方程是 ax²+bx+c = t，移项后常数项是 c − t。
  • 求了交点忘记写纵坐标：交点是一对坐标 (x, t)，别只写一个数。

柒它在生活里长什么样

🏀 从课本走到现实

  • 投篮与篮筐高度：篮筐是一条水平线，球能否入筐就是「水平线与抛物线有没有交点」。
  • 限高杆：车辆顶部高度是一条水平线，与拱桥曲线有无交点决定能否通过。
  • 水位警戒线：水位线（水平直线）与河床抛物线断面的交点就是水面宽度。

捌本节小结

✍️ 记住这几条就够了

  • 求交点 = 联立 = 解方程 = 数判别式。
  • 水平线 y=t 的情形：先看顶点纵坐标 k，直接与 t 比大小。
  • 开口向上要 t > k 才有两个交点；开口向下要 t < k。
  • 含参题把「有两个交点」翻译成不等式再解，注意严格不等号。
