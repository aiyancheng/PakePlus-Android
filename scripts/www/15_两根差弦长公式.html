两根差·弦长公式

|x₁−x₂| = √Δ / |a|，一行算出两根距离，不必求出根。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

抛物线与 x 轴的两个交点之间那段水平距离，行话叫弦长。它是几何题的高频量：跨度多宽、两点相距多远，全都指望它。

笨办法是先解方程求出两根再相减；聪明办法是直接套 √Δ/|a|——连根都不用求。这一讲把公式推导一遍，你就不会用错。

壹从原理上讲透

一、从求根公式直接相减

两根为 x₁ = (−b + √Δ)/(2a)、x₂ = (−b − √Δ)/(2a)，相减：

|x₁ − x₂| = |2√Δ / (2a)| = √Δ / |a|

二、用韦达定理也能推

不完全相信求根公式的话，还有一条路：(x₁ − x₂)² = (x₁ + x₂)² − 4x₁x₂。

代入第 5 讲的韦达关系 x₁+x₂ = −b/a、x₁x₂ = c/a：

(x₁ − x₂)² = b²/a² − 4c/a = (b² − 4ac)/a² = Δ/a² → |x₁ − x₂| = √Δ / |a|

两条路殊途同归，说明公式可靠。第二种方法在不知道根但知道和积时特别有用。

三、它还能做什么

求弦长
|x₁ − x₂| = √Δ/|a|，直接得到两交点距离
反求参数
已知弦长 d ⟹ Δ = a²d²，可解出参数
求对称轴
两零点中点是轴，配合弦长可得两根坐标：h ± d/2
垂直高度
弦长与顶点高度没有直接关系，别乱用
注意分母是 |a| 而不是 a：弦长是距离，永远非负。开口向上向下都一样。

贰图像里的逻辑

叁核心结论（要背的）

弦长公式
|x₁ − x₂| = √Δ / |a|
推导路径一
求根公式直接相减
推导路径二
(x₁−x₂)² = (x₁+x₂)² − 4x₁x₂ = Δ/a²
配合对称性
两根 = 对称轴 ± 弦长/2
前提
Δ ≥ 0（确有两个实根）

已知弦长反推时常用形式：Δ = a² · 弦长²。

弦长与对称轴搭配，可以在不求根的情况下定位两个交点。

肆解题步骤：拿到题怎么下手

  1. 确认有两个根：先算 Δ ≥ 0，否则弦长无从谈起。
  2. 套公式：|x₁ − x₂| = √Δ / |a|。
  3. 需要根的坐标时：先求对称轴 h = (x₁+x₂)/2，再写成 h ± d/2。
  4. 反求参数：已知弦长 d ⟹ Δ = a²d² ⟹ 解含参方程。
  5. 检验：把参数代回原式，算出实际两根核对距离。

伍例题精讲

例1求抛物线 y = x² − 2x − 3 与 x 轴两个交点之间的距离。
展开完整解析

思路：先确认有两个根，再套弦长公式。

  1. Δ = (−2)² − 4·1·(−3) = 4 + 12 = 16 > 0，确有两个交点。
  2. 弦长 = √Δ / |a| = √16 / 1 = 4。
  3. 验证：解方程 x²−2x−3=0 → (x−3)(x+1)=0 → x = 3 或 −1，距离 |3−(−1)| = 4 ✓。
  4. 附带信息：对称轴是两零点中点 x = (3+(−1))/2 = 1 ✓（与 −b/2a 一致）。
答：两个交点之间的距离为 4。
例2 · 反求参数已知抛物线 y = x² − 4x + c 与 x 轴两个交点的距离为 6，求 c 的值。
展开完整解析

思路：弦长已知，用 Δ = a²d² 反推，再解出 c。

  1. 弦长 d = 6，a = 1，故 Δ = a²·d² = 1·36 = 36。
  2. 另一方面 Δ = (−4)² − 4·1·c = 16 − 4c。
  3. 列方程：16 − 4c = 36 → −4c = 20 → c = −5。
  4. 此时函数为 y = x² − 4x − 5 = (x−5)(x+1)，两根 5 与 −1，距离 6 ✓。
  5. 顺带：对称轴 x = 2，两根可写成 2 ± 3 ✓。
答：c = −5。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 分母忘了绝对值：a 为负时 √Δ/a 会得到负数，必须取 |a|。
  • 不检查 Δ 就用：Δ<0 时没有实根，弦长不存在。
  • 与「顶点到 x 轴距离」混淆：那是 |k|，与弦长不是一回事。
  • 反求参数时忘了平方：关系是 Δ = a²d²，不是 Δ = ad。

柒它在生活里长什么样

🏀 从课本走到现实

  • 桥梁跨度：桥拱与水面两交点的水平距离就是跨度，工程上直接用弦长思路测算。
  • 喷泉覆盖范围：两个落水点之间的距离决定水柱覆盖范围。
  • 投篮起落点距离：出手点到落筐点的水平距离，正是抛物线的弦长。
