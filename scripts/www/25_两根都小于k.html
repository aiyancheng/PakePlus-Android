两根都小于k

概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

如果第 24 讲你已经彻底掌握，这一讲只需改一个不等号：把「两根都大于 k」里的「对称轴 > k」换成「对称轴 < k」，其余全部照抄。

但正因为太像，考场上最容易出错的就是把不等号写反。本讲用一个区分小技巧帮你彻底稳住。

壹从原理上讲透

一、模板完全相同，只改一处

① Δ > 0
保证有两个不同的实根（允许相等时 Δ ≥ 0）——不变
② 对称轴 < k
两根中点在 k 左侧——方向反过来
③ a·f(k) > 0
k 在两根之外——形式不变

注意第 ③ 条为什么也不用变？因为无论两根在 k 的左边还是右边，k 都在两根之外，而开口向上时两根之外的函数值都是正的，所以统一是 a·f(k)>0。

二、如何永远不写反不等号

技巧：在草稿上画一条数轴，把两根画在 k 的左侧（因为题目要求小于 k），然后看：

两根的中点（对称轴）自然也在 k 左侧 → 就是 <。画个图比背口诀可靠得多。

再强调一次：① 和 ③ 完全不变，只有 ② 的方向随题意翻转。把这条记牢，这一整类题就不会错。

贰图像里的逻辑

叁核心结论（要背的）

① Δ > 0
两个不同实根（不变）
② 对称轴 < k
−b/(2a) < k（方向翻转）
③ a·f(k) > 0
k 仍在两根之外（形式不变）
综合
三条取交集

只有第 ② 条翻转方向，① ③ 完全照抄。

不确定时先在草稿上画一条数轴，把两根摆在 k 的正确一侧，看图写不等号。

肆解题步骤：拿到题怎么下手

  1. 画数轴：在草稿上画出 k 的位置和两根应该落在的那一侧。
  2. 列①：写 Δ > 0（或 ≥0）并解出范围 A。
  3. 列②：按图写对称轴 < k（或 > k），解出范围 B。
  4. 列③：写 a·f(k) > 0，解出范围 C。
  5. 取交集，并代一个具体参数值回原方程检验两根位置。

伍例题精讲

例1判断方程 x² + 4x + 3 = 0 的两根是否都小于 0。
展开完整解析

思路：画数轴：两根应在 0 的左侧，逐条核对。

  1. 解方程：x²+4x+3 = (x+1)(x+3) → 两根 −1 与 −3，均小于 0 ✓。
  2. 条件①：Δ = 16 − 12 = 4 > 0 ✓。
  3. 条件②：对称轴 x = −4/2 = −2 < 0 ✓（小于 k=0，方向正确）。
  4. 条件③：a=1>0，f(0) = 3 > 0 ✓，即 a·f(0) > 0 成立。
  5. 三条同时满足，结论成立 ✓。
答：是，两根（−1 与 −3）都小于 0。
例2 · 含参若方程 x² − (m+4)x + 2m = 0 的两个实根都小于 3，求 m 的取值范围。
展开完整解析

思路：套模板：① Δ 条件，② 轴 < 3，③ a·f(3)>0，最后取交集。

  1. 条件①：Δ = (m+4)² − 8m = m² + 8m + 16 − 8m = m² + 16 > 0，对任意 m 恒成立 ✓。
  2. 条件②：对称轴 x = (m+4)/2 < 3 → m + 4 < 6 → m < 2。
  3. 条件③：a=1>0，需 f(3) > 0：f(3) = 9 − 3(m+4) + 2m = 9 − 3m − 12 + 2m = −m − 3 > 0 → m < −3。
  4. 取交集：m < 2 与 m < −3 → m < −3。
  5. 取 m = −4 检验：方程为 x² − 0·x − 8 = 0 → x = ±2√2 ≈ ±2.83，两根都 < 3 ✓；
  6. 再取 m = −3 检验：方程为 x² − x − 6 = 0 → 两根 3 与 −2，其中 3 不满足「小于 3」✗（边界排除正确）。
答：m < −3。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 对称轴的不等号写反：这是本讲唯一的陷阱，画数轴即可规避。
  • 把第 ③ 条也翻转：无论大于还是小于 k，k 都在两根之外，条件形式不变。
  • 混淆 Δ>0 与 Δ≥0：看题目有没有说「两个不同的实根」。
  • 忘记检验边界：取边界值代入，确认「恰好等于 k」的情形确实应被排除。
