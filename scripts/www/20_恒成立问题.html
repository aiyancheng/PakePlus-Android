恒成立问题

图像恒在上方 ⟺ 开口向上 + Δ<0：永远别忘了讨论 a=0。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

「不论 x 取什么值，这个式子都大于 0」——这类问法叫恒成立。它听起来抽象，翻译成图像却极其直白：整条抛物线必须全部待在 x 轴上方。

于是条件只有两个：开口必须向上（否则两头迟早掉下去），并且不能碰到 x 轴（Δ<0）。本讲还要补上那个最容易丢的坑：二次项系数可能为 0 的情形。

壹从原理上讲透

一、把恒成立翻译成图像

ax²+bx+c > 0 对任意实数 x 恒成立 ⟺ 抛物线整体在 x 轴上方。这需要同时满足：

① 开口向上
a > 0（否则两端终将下降至 −∞）
② 与 x 轴无交点
Δ < 0（碰到就算破功；若允许等于 0 则 Δ ≤ 0）

用顶点坐标也能得到同一结论：k = −Δ/(4a)。要求 k > 0 且 a > 0，等价于 Δ < 0 且 a > 0。两条路完全一致。

二、三种常见问法

f(x) > 0 恒成立
a > 0 且 Δ < 0
f(x) ≥ 0 恒成立
a > 0 且 Δ ≤ 0
f(x) < 0 恒成立
a < 0 且 Δ < 0

三、那个致命的坑：a 可能为 0

如果题目说的是「关于 x 的不等式」（没说二次），那么二次项系数可能为 0。此时函数退化成一次式 bx+c 或常数，必须单独讨论：

a = 0 且 b = 0
式子变成常数 c：c > 0 时恒成立
a = 0 且 b ≠ 0
变成一次式，值域覆盖全体实数，不可能恒大于 0
答题格式建议：先写「当二次项系数 = 0 时……」，再写「当二次项系数 ≠ 0 时……」，最后取并集。漏掉第一段是这类题最常见的扣分点。

贰图像里的逻辑

叁核心结论（要背的）

f(x) > 0 恒成立
a > 0 且 Δ < 0
f(x) ≥ 0 恒成立
a > 0 且 Δ ≤ 0
f(x) < 0 恒成立
a < 0 且 Δ < 0
等价说法
顶点纵坐标 k 与 a 同号，且 Δ 严格小于 0
必讨论
二次项系数可能为 0 时单独分类

开口向上 + 没有交点 = 恒在上方，一句话记牢。

Δ<0 与 Δ≤0 的区别只在是否允许「碰到」x 轴，看题目是 >0 还是 ≥0。

肆解题步骤：拿到题怎么下手

  1. 先讨论退化：题目没说「二次」时，先令二次项系数 = 0，看是否满足。
  2. 判开口：恒 >0 ⟹ a>0；恒 <0 ⟹ a<0。
  3. 列 Δ 条件：>0 用 Δ<0，≥0 用 Δ≤0。
  4. 解不等式组并取交集，再与第一段的结果取并集。
  5. 用顶点复核：算一下顶点纵坐标是否与 a 同号且不为 0。

伍例题精讲

例1若 x² + 2x + m > 0 对任意实数 x 恒成立，求 m 的取值范围。
展开完整解析

思路：开口系数 1>0 已满足，只需保证无交点。

  1. 二次项系数 a = 1 > 0，已满足第一个条件。
  2. 要求恒 >0 ⟹ Δ < 0：4 − 4m < 0 → m > 1。
  3. 顶点复核：y = (x+1)² + m − 1，顶点纵坐标 m−1，要求 >0 ⟹ m>1 ✓。
  4. 边界：m = 1 时顶点恰好在 x 轴上（触到 0），此时是 ≥0 而非 >0，必须排除。
答：m > 1。
例2 · 必须讨论退化若不等式 (m−1)x² + 2(m−1)x + 4 > 0 对任意实数 x 恒成立，求 m 的取值范围。
展开完整解析

思路：二次项系数含 m，可能为 0，必须先单独讨论。

  1. 情形一（退化）：m − 1 = 0 即 m = 1 时，式子变成 4 > 0，恒成立 ✓。
  2. 情形二（真正二次）：m ≠ 1 时需同时满足：
  3. 　① 开口向上：m − 1 > 0 → m > 1；
  4. 　② 无交点：Δ = 4(m−1)² − 16(m−1) = 4(m−1)(m−5) < 0。
  5. 因 m−1 > 0，故需 m − 5 < 0 → m < 5，于是 1 < m < 5。
  6. 合并两种情形：1 ≤ m < 5。
  7. 检验：m=1 时确实恒成立；m=5 时 Δ=0，顶点触及 x 轴，只能保证 ≥0 ✗ ✓。
答：1 ≤ m < 5。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 漏掉「二次项系数为 0」的讨论：含参题目必须分两类，这是本讲头号扣分点。
  • Δ 的等号处理错：>0 用 Δ<0（不能碰），≥0 才能用 Δ≤0。
  • 只写 Δ<0 忘了 a>0：开口向下时曲线两端必然掉下去，两个条件缺一不可。
  • 把「恒成立」与「有解」混淆：有解只需存在一个 x，恒成立要求所有 x。

柒它在生活里长什么样

🏀 从课本走到现实

  • 永不负亏的生意：利润曲线恒在零以上，意味着任何销量都赚钱——现实中对应「躺着也能赚」的商业模式。
  • 结构安全：桥梁承重冗余要求在最不利工况下仍大于 0，本质就是恒成立。
  • 药物安全剂量：要求在整个剂量区间内副作用指标恒低于阈值。

捌本节小结

✍️ 记住这几条就够了

  • 恒 >0 ⟺ a>0 且 Δ<0（恒 ≥0 则 Δ≤0）。
  • 等价于：顶点纵坐标与 a 同号且不为 0。
  • 含参时必须先讨论二次项系数等于 0 的退化情形。
  • 最后的答案区间注意开闭：能「碰到」就不算严格大于。
