区间内恰有一根

f(m)·f(n) < 0 秒杀主情形，端点与重根另做检验。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

只剩下最后一个场景：方程在区间 (m, n) 里恰好有一个根。这是整套课程里最综合的一讲——它用到了连续性、端点值、还有前 25 讲的全部直觉。

好消息是主情形一条式子就能秒杀：f(m)·f(n)<0。难的是那些容易被忽略的边界：端点恰好是根、以及重根的情况。本讲把它们一次讲清。

壹从原理上讲透

一、主条件为什么成立

二次函数图像是一条连续不断的曲线。若 f(m) 与 f(n) 异号（一个在 x 轴上方、一个在下方），那么从 x=m 走到 x=n 的过程必然穿过 x 轴奇数次。

而二次函数最多只有两个根，所以「奇数次」只能是 1 次 → 区间内恰好一个根。这就是：

f(m) · f(n) < 0 ⟹ (m,n) 内恰有一根

二、但它只是充分条件，不是全部

下面两种情形也可能导致「恰有一根」，必须单独检验：

① 端点恰是根
若 f(m)=0，需检查另一个根是否落在 (m,n) 内
② 重根落在区间内
Δ=0 时两根重合为一个值，若它落在 (m,n) 内，是否算「一根」取决于题目约定

三、完整的分类检查清单

主情形
f(m)·f(n) < 0 → 直接成立
补充 A
f(m) = 0 → 求另一根，看是否 ∈ (m,n)
补充 B
f(n) = 0 → 求另一根，看是否 ∈ (m,n)
补充 C
Δ = 0 → 重根 x = −b/(2a)，看是否 ∈ (m,n)
不同教材对「重根是否算一个根」的约定略有差别：按不同实数值计数时算一个，按「两个相等的实根」计数时不算。中考命题一般会明确写出「两个不相等的实根」来避免歧义，遇到含糊表述时按上述分类分别说明即可。

叁核心结论（要背的）

主条件
f(m)·f(n) < 0 ⟹ (m,n) 内恰有一根
补充 A
f(m)=0 时检查另一根是否在区间内
补充 B
f(n)=0 时检查另一根是否在区间内
补充 C
Δ=0 时检查重根 x=−b/(2a) 是否在区间内
原理
连续性保证异号必穿轴；二次式最多两根故只穿一次

主条件负责秒杀，三个补充负责兜漏。

闭区间 [m,n] 与开区间 (m,n) 的差别只在端点是否计入，读题务必看清。

肆解题步骤：拿到题怎么下手

  1. 看区间开闭：确认题目写的是 (m,n) 还是 [m,n]，决定端点是否计数。
  2. 算主条件：求 f(m)、f(n)，令乘积 < 0，解出参数范围（这是答案的主体）。
  3. 检验端点：分别令 f(m)=0、f(n)=0，看另一个根是否落在区间内，决定是否并入。
  4. 检验重根：令 Δ=0，看重根是否落在区间内，按题目约定决定是否并入。
  5. 汇总并回代检验：取边界值和典型值各一个代入原式核对。

伍例题精讲

例1判断 f(x) = x² − 2x − 3 在区间 (−2, 2) 内是否恰有一根。
展开完整解析

思路：直接算两端点函数值，看是否异号。

  1. f(−2) = 4 + 4 − 3 = 5 > 0；f(2) = 4 − 4 − 3 = −3 < 0。
  2. f(−2)·f(2) < 0 → 区间 (−2, 2) 内恰有一根。
  3. 核对：方程为 (x−3)(x+1)=0，两根 3 与 −1，只有 −1 落在 (−2,2) 内 ✓。
  4. 补充检查：端点值都不是 0，Δ=16>0 无重根，故无需额外并入。
答：是，区间 (−2, 2) 内恰有一根（x = −1）。
例2 · 含参 + 边界检验已知 x² − (m+1)x + 4 = 0 在区间 (0, 3) 内恰有一个实数根，求 m 的取值范围。
展开完整解析

思路：主条件 f(0)·f(3)<0 先解出主体范围，再逐项检验端点与重根。

  1. 主条件：f(0) = 4 > 0，f(3) = 9 − 3(m+1) + 4 = 10 − 3m。
  2. 要求 f(0)·f(3) < 0 ⟹ 10 − 3m < 0 ⟹ m > 10/3。
  3. 补充 A：f(0)=4≠0，x=0 永远不是根，无需处理。
  4. 补充 B：令 f(3)=0 得 m=10/3，此时一根为 3（在端点上），另一根由乘积为 4 得 4/3，落在 (0,3) 内 → 若按「区间内的不同实数值」计数，则应并入；是否并入最终取决于题目对端点与重根的约定。
  5. 补充 C：令 Δ=(m+1)²−16=0 得 m=3 或 m=−5；m=3 时重根 x=2 落在 (0,3)，m=−5 时重根 x=−5 在区间外。
  6. m=3 不在 m>10/3 的范围内，若题目允许把「重根也算一根」单独计入，则需把 m=3 作为孤立点并入；若要求两根不相等，则不计。
  7. 常规答案（不含重根）：m > 10/3。
答：常规解法为 m > 10/3；若把重根情形单独计入，还应并入 m = 3。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 只写主条件忘了补充检验：端点值和重根三种情况必须逐一过一遍。
  • 把主条件写成 ≤0：等于 0 时端点本身是根，不属于「穿过」，要单独判断。
  • 忽略区间开闭：开区间不算端点、闭区间算端点，结论可能不同。
  • 忘记二次函数最多两个根这一前提：正因为如此，「跨奇数次」才等价于「恰好一次」。

柒它在生活里长什么样

🏀 从课本走到现实

  • 温度窗口：要求在一段时间区间内恰好有一次达到警戒阈值，这在工业温控中很常见。
  • 投篮弧线：球在某段水平距离内恰好越过一次防守者手的高度。
  • 盈亏切换：在一个经营周期内，利润曲线恰好穿越一次盈亏平衡线。
