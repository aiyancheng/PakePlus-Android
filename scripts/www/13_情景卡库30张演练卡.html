模块 13 · 情景卡库（30 张演练卡）

这是模块09「角色扮演」的弹药箱。30 张卡＝30 个真实顾客，把门店最常遇到、也最容易讲砸的局面全部演一遍：顾客方照着卡演，视光师照着七步讲，旁观者照着卡打分。卡片可以直接打印裁剪，一卡一人一场，全员轮完再进压力题。

一、这套卡怎么用（演练四步法）

① 抽卡

从本模块抽 1 张（常规题优先，压力题需先通过常规题）。抽卡人只把「场景+顾客设定+参考数据」给顾客方看，视光师事先不看。

② 演

顾客方按卡上的设定提问、质疑、给压力，不得自由发挥加戏。视光师完整走一遍七步，允许查模块03判定表。

③ 评

第三人持《实操考评表》（模块09）打分，重点看本卡「考察重点」是否全部命中，出现「否决项」即整场不合格。

④ 复盘

当场给 3 条反馈：做对 1 条 / 可改 1 条 / 下次重点 1 条。不合格者一周内换同人群另一张卡重考，不得重复抽同一张。

使用的三条纪律：① 卡片数据均为演练用虚构数据，不得作为真实案例对外讲述，也不得写进宣传物料；② 演练中出现的错误话术（如"保证不涨"）必须在复盘时当场纠正并记录在《晨会演练记录本》；③ 卡片属于内部培训资料，不外借、不上传网络。

二、抽卡规则与评分标准

项目常规题（S-01 ~ S-21 中的常规卡）压力题（标注「压力」的 10 张）说明
通过线≥ 85 分≥ 80 分即可通过压力题的难点在"扛住"，不在"说服"
七步完整七步缺一步即扣 10 分允许简化第⑥⑦步，但第①②步不得跳过第②步异常值扫描是硬指标
回答顺序必须"先共情 → 再讲数据 → 后给方案"，先报价或先推产品扣 15 分顺序错误是最常见失分点
一票否决出现卡片「否决项」任一条 = 本场 0 分，记录在案否决项均涉及合规红线，无商量余地
重考不合格者 7 日内重考，换卡不换人群；连续两次不合格暂停独立解读，跟诊 2 周同人群换卡，避免背答案
抽考每周五晨会抽查 1 张，全员轮流；店长记录，月度汇总对接模块09 常态化训练

四、A 组 · 儿童青少年（11 张）

S-01儿童青少年常规题★★

场景：学校体检说视力有问题，家长带孩子来看，第一句话是"我们家没有近视的，是不是眼睛累了"。

顾客设定：7 岁男孩，母亲陪同，语气平和但明显不想接受"近视"这个结论，会反复问"能不能恢复"。

参考数据：OD −1.25D / OS −1.00D；裸眼视力 0.6 / 0.6，矫正 1.0；眼轴 23.85mm / 23.78mm；眼压正常；眼底未见异常。

考察重点：①共情开场（先接住家长情绪，不急着纠正）；②第①步四板块数据说全，眼轴要说"这是第一次记录，作为以后对比的起点"；③不在小瞳数据上给"假性近视"或"能恢复"的判断；④给出配镜与行为管理的分层方案，明确复查时间。

否决项：说"假性近视，休息休息就能好"；承诺"能恢复到 1.0"；未提出建档复查时间。

S-02儿童青少年常规题★★★

场景：一年后复查，家长拿着两次单子问"是不是涨了 100 度，怎么这么快"。

顾客设定：10 岁女孩，父亲陪同，工作忙、说话快，希望"一句话说清到底要不要紧"。

参考数据：本次 OD −3.50D；上次 −2.50D；眼轴 25.10mm（一年 +0.42mm）；角膜曲率稳定；矫正视力 1.0。

考察重点：①把"涨了 100 度"换算成年化增速再讲；②用眼轴增长佐证，指出"度数是结果，眼轴是原因"；③把目标说成"把速度降下来"，而不是"不涨"；④方案分三档（必做/建议做/可选），说清每档作用与复查节点。

否决项：出现"保证不涨""一定控制住"；只讲度数不讲眼轴；未给复查时间。

S-03儿童青少年常规题★★★

场景：学校筛查提示"远视储备不足"，家长第一次听到这个词，问"这是要近视了吗"。

顾客设定：6 岁男孩，母亲陪同，焦虑型家长，会追问"是不是现在就得配眼镜"。

参考数据：散瞳验光 OD +0.25D / OS +0.50D；眼轴 23.20mm / 23.15mm；裸眼视力 0.8 / 0.9。

考察重点：①用"存款"类比把储备讲明白；②强调这是筛查提示而非诊断，结论必须以散瞳验光与眼轴趋势为准；③给出今天就能做的三件事（户外 2 小时、阅读距离、光照）；④定下一次复查时间（3~6 个月），说明为什么不需要立刻配镜。

否决项：凭小瞳验光单下"储备不足"的结论；用"马上要近视了"制造恐慌促成下单。

S-04儿童青少年常规题★★

场景：家长听说某种滴眼液或调理方法能控制近视，问"你们这儿有没有，能不能不做别的"。

顾客设定：9 岁男孩，母亲陪同，明显已经打听过多家机构，对"行为管理"兴趣不高，想要一个"省事的方法"。

参考数据：OD −2.50D / OS −2.25D；眼轴 24.60mm（半年 +0.22mm）；其余正常。

考察重点：①明确门店不碰药品、不做疗效评价，涉及用药一律建议到爱眼城眼科评估；②不贬低顾客听到的方法，只说明"门店能提供的部分"是检查、镜片方案与行为管理；③把"省事"翻译成可实现的小动作（每天户外 2 小时怎么拆分、读写距离怎么量）；④给出可量化的半年目标与复查节点。

否决项：推荐、代购或评价任何药品；承诺任何方法的效果。

S-05儿童青少年常规题★★

场景：孩子明确说不想戴眼镜，理由是"同学会笑我"，家长在旁边催"你别管他，你就说配哪种"。

顾客设定：11 岁男孩，低头、话少、回避眼神；母亲强势，替孩子做决定。

参考数据：OD −1.50D / OS −1.75D；矫正视力 1.0 / 1.0；眼轴 24.30mm / 24.42mm。

考察重点：①先对孩子说话，把孩子当决策参与者而不是旁听者；②把戴镜的意义落在生活场景（看得清黑板、体育课、看路），不落在"度数会涨"的恐吓上；③给出降低心理负担的具体办法（镜架选择、上课戴与运动摘的规则）；④请孩子复述一句关键结论。

否决项：当着孩子的面贬低他（如"不戴就是学习差"）；全程只对家长讲、无视孩子。

S-06儿童青少年常规题★★★★

场景：家长直接问"要不要配角膜塑形镜，还是配那个离焦的"，并在手机里存好了几个产品名。

顾客设定：12 岁男孩，母亲陪同，做过功课、术语能说对一半，会追问"哪个效果更好、能差多少"。

参考数据：OD −4.00D / OS −3.75D；眼轴 26.00mm / 25.92mm；角膜曲率 43.2D / 43.0D；眼压正常；泪膜正常。

考察重点：①先做前置条件说明（角膜地形图、泪膜、卫生条件、家长操作能力、复查依从性）；②只讲适用条件与检查项目，不做"效果更好"的比较性承诺；③讲清安全与复查要求，指明角膜塑形镜属于医疗机构验配范畴这一边界；④给出到爱眼城眼科评估与门店可选方案的两条路径。

否决项：承诺控制效果或"多少度以内都没问题"；在门店自行承诺验配角膜塑形镜。

S-07儿童青少年常规题★★★★

场景：家长说"度数配够了，孩子还是说看近累、看书跳行、写作业半小时就趴下"。

顾客设定：8 岁女孩，母亲陪同，已经换过两次镜仍不满意，带着情绪，怀疑"是不是你们验得不准"。

参考数据：OD −2.00D / OS −2.00D，矫正视力 1.0；集合近点 14cm；调节幅度低于同龄参考值；看近隐斜偏大；立体视正常。

考察重点：①先接住"换过两次还不行"的情绪，再解释"度数只是其中一项"；②用生活语言解释调节与集合（"眼睛的对焦和两只眼的配合"）；③明确先排除斜视、弱视等需就医的情况，再谈训练；④讲清训练是周期性的、需要复查对比，不给"几个月恢复到 1.0"的承诺。

否决项：承诺训练效果或恢复时间；未提排除斜视、弱视；把问题全部归结为"用眼习惯差"。

S-08儿童青少年压力题★★★★

场景：讲到方案时，家长打断："你就直说，保证不涨我就买，不保证我不做，回头涨了你退款吗？"

顾客设定：母亲，教师，逻辑清晰，会把你的每一句话是否许诺都记下来，语气强硬但并非恶意。

参考数据：10 岁男孩，OD −3.25D / OS −3.00D；眼轴 24.10mm（一年 +0.45mm）；其余正常。

考察重点：①明确说明没有任何方法能保证不涨，门店不做疗效承诺；②把话题转到"可控的部分"：增长速度、复查节奏、行为管理，给出可核对的数据目标；③理解并承接家长的焦虑，不因对方强势而失态或松口；④主动提出书面建议书，把"做什么、多久复查、怎么判断是否有效"写清楚。

否决项：任何形式的承诺或变相承诺（如"基本不会涨""我们做过的都没涨"）；为留客答应退费承诺。

S-09儿童青少年压力题★★★

场景：外婆陪孩子来，全程一句"现在别配那么认真，长大做个手术就行了，我邻居家孩子就是"。母亲在旁边犹豫。

顾客设定：外婆，60 多岁，说话多、爱举例，不接受被"教育"；母亲中间派。

参考数据：9 岁女孩，OD −2.75D / OS −2.50D；眼轴 24.85mm / 24.70mm；眼底正常。

考察重点：①不反驳长辈，先承认"手术确实能解决度数"这一事实；②再说明手术解决的是"要不要戴眼镜"，不解决高度近视带来的眼底风险，而眼底风险与眼轴长度相关；③用今天的数据说话，不讲空道理；④把结论落到具体行动，让孩子母亲成为决策者而非旁观者。

否决项：与长辈争执、使用"你不懂""别听人乱说"等否定性话语；宣称手术有害或效果不佳。

S-10儿童青少年压力题★★★★

场景：家长掏手机读一段网上文章："说眼轴检查没必要，孩子长个子眼轴也会变长，你们是不是多收钱？"

顾客设定：父亲，工程师，习惯用资料说话，语气不算冲但明显在考验专业度。

参考数据：孩子 11 岁，两次检查间隔一年，眼轴 24.95mm → 25.38mm；同期身高中等增长；屈光度 −3.00D → −3.50D。

考察重点：①先认可文章里"眼轴随发育增长"这句是对的，不与顾客对立；②用自家两次数据说明：单纯看长度不够，要看增长速度与是否伴随屈光度改变，这正是复查的价值；③说明门店设备用于筛查与随访参考，诊断以医疗机构为准；④不因被质疑而缩短流程，第②步异常值扫描照做。

否决项：贬低顾客的信息来源或用"你不懂"打发；为迎合顾客而承诺减免指标检查。

S-11儿童青少年压力题★★★★

场景：家长一进门就打开手机录像，说"上次你们也是这么讲的，最后就是让我买贵的，今天我自己留个记录"。

顾客设定：母亲，有过不愉快经历，全程防备，每讲一个方案就问"这个多少钱、是不是必须买"。

参考数据：12 岁男孩，OD −5.00D / OS −4.75D；眼轴 26.40mm / 26.28mm；眼底未见异常；矫正视力 1.0。

顾客设定：61 岁男性，无明显不适，对"去医院"有强烈抵触，情绪开始不耐烦。

参考数据：眼压 25mmHg / 24mmHg（复测）；中央角膜厚度偏薄；杯盘比偏大（提示）；矫正视力 0.9 / 0.9；视野未做（门店无此设备）。

考察重点：①不使用"青光眼"等诊断名词，只说明"眼压测量值高于一般参考范围，需要专业机构进一步检查"；②说明眼压偏高早期常常没有感觉，这正是需要检查的原因；③给出明确的建议就诊科室与时间（尽快、近期），并提供书面提示；④配镜需求照常安排，但不得用眼压问题捆绑销售，也不得推销任何"降眼压"产品；⑤记录并安排回访，确认顾客是否已就诊。

否决项：说出"青光眼"等诊断名词；推荐任何所谓降眼压的药品或器械；因顾客抵触而放弃提示或不留痕。

S-29中老年压力题★★★★★

场景：眼底照相提示可疑改变，你建议到爱眼城眼科就诊。顾客说"去医院排队一整天，不用了，你给我配就行，我自己负责"。

顾客设定：64 岁女性，行动不便、子女不在身边，怕麻烦、怕花钱，态度坚决但并非不信任门店。

参考数据：矫正视力 0.6 / 0.5；眼底可见黄斑区可疑改变（提示）；屈光度变化明显；眼压正常。

考察重点：①坚持转诊建议，不因为顾客"自己负责"就改口；②理解顾客的实际困难，给出可执行的帮忙方式（就诊科室、就近机构、家属沟通、陪同协助），把障碍解决掉而不是只给结论；③本次不出具任何产品方案，只出转诊提示型建议书（模块12 模板 F）；④留痕并明确回访时间，若顾客坚持不就诊，记录顾客的知情选择。

否决项：因顾客坚持而配镜并出具常规方案；在疑似眼底病变情况下推荐高单价产品。

S-30中老年压力题★★★★

场景：子女陪着来，坚持要给父亲配渐进镜，"钱我出"。老人全程说"我不用、我看得见"。

顾客设定：老人 70 岁，抗拒戴镜，对陌生事物有抵触；女儿 40 岁，主导沟通，明显着急。

参考数据：远用 OD +1.00D / OS +0.75D；近加光 +2.50D；矫正视力 0.7 / 0.8；眼压正常；眼底未见明显异常提示项；晶体轻度混浊（提示）。

考察重点：①把老人作为主要沟通对象，先问他的实际困扰，不跳过本人意愿；②向女儿说明配镜的需求判断以老人的用眼习惯与实际需求为准，避免替顾客做决定；③若老人有需求但担心操作复杂，给出降低使用门槛的方案与适应支持；④明确知情选择与签字留痕，说清"可先配、可用后再调整"的处理方式。

否决项：只与家属谈、无视本人意愿；用"子女孝顺你就得配"这类话语施压；将不情愿的顾客当作成交对象。

压力题使用提醒：标注「压力题」的 10 张（S-08、S-09、S-10、S-11、S-19、S-20、S-21、S-28、S-29、S-30）必须在员工通过常规题之后才可抽取。压力题评分时，"拒绝了不合理要求"与"坚持了转诊建议"得分高于"说服了顾客"；如果员工为了成交而放弃转诊或做出承诺，即使顾客当场满意也判不合格。

七、组合扩题法（30 张怎么变成 90 张）

卡片数量不必固定。把下面四个变量各换一档，同一张卡就能变成新题，抽卡时不容易被"背答案"。

可替换变量可选档位换档后考察重点怎么变
随行人角色父母 / 祖辈 / 配偶 / 朋友 / 同事 / 独自前来决策人变了，能否识别"谁做决定"就成了新考点
数据档位轻度（≤−2.00D）/ 中度（−2.00~−6.00D）/ 高度（＞−6.00D）；眼轴年增 0.2 / 0.35 / 0.5mm 以上方案层级、转诊判断、复查间隔随之调整
异常项眼压偏高 / 眼底可疑 / 眼底正常 / 双眼视功能异常 / 泪膜异常第②步异常值扫描的重点不同，压力题集中在下半段
顾客态度配合 / 焦虑 / 抗拒 / 已就诊过 / 已被其他机构推销过共情难度升级，考察情绪处理与边界守持
换档规则：每次只换一档，保持卡片结构不变；换档后的卡片应重新登记编号（如 S-07-2），并在卡片右下角注明"由 S-07 换档生成"，避免演练内容反复使用。门店也可根据当季实际客群，把真实高频问题（去掉可识别信息后）写成新卡，报区域督导审核后入库。

八、印制、保管与更新

  • 印制：A4 双面、157g 以上铜版纸或卡纸，按本模块打印后沿卡片边框裁剪；建议按人群分色装订——儿童青少年（蓝边）、成年人（绿边）、中老年（橙边），压力题在正面右上角盖红色"压力题"章。
  • 配套：每套卡配一本《演练记录本》、一张《实操考评表》（模块09），三者同放一个卡盒，盒面写明门店名与卡片版本号。
  • 编号唯一：全连锁统一使用 S-01 ~ S-30 编号，门店自建卡片从 S-31 起顺序编号，不得复用已有编号。
  • 保管：卡盒由店长保管，晨会与演练时发放，用后当场收回，不得由员工个人带走；卡片属于内部培训资料，不得拍摄外传、不得用于对外宣传或短视频素材。
  • 更新：每半年（1 月、7 月）由区域督导组织复核一次：淘汰已不符合当前流程的卡、把门店高频新问题补入、把被误用的卡（顾客方加戏过多）重写。每次复核后更新版本号与修订日期，旧版收回销毁。
  • 与考核挂钩：每季度至少完成 6 张卡的演练（其中儿童青少年 3 张、成人 2 张、中老年 1 张），记录在《演练记录本》，纳入 L1/L2/L3 认证的实操分（模块09）。
内容一致性要求：调整卡片数据时，必须同步检查三处——① 判定结论是否符合模块03《指标参考区间与异常判定表》；② 应对对策是否符合模块04《异常值对照表》；③ 是否触及模块11《医疗边界与合规红线》的 12 类转诊情形。三者不一致时，以模块03、04、12 为准，先改卡片再演练。
