模块07 · 眼科与眼视光常见异常：诊断说明与三层解决方案

模块03 回答"这项数值算不算异常"，本模块回答更进一步的问题：这类异常到底是什么、解决路径分成哪几层、门店站在哪一层。全篇分两半——上半是诊断说明（识别要点、可看信号、常见原因与风险），下半是三层解决方案（L1 预防与基础干预 → L2 常规诊疗手段 → L3 进阶或综合干预）。按"异常类型"分类，随查随用；数值与档位一律以模块03 为准。

先看边界（三条硬线）：① 本模块出现的所有异常名称都是给员工看的识别用语，不得作为诊断结论对顾客讲；② 门店只执行 L1，L2 / L3 一律由医疗机构完成，门店只做识别、转介与随访；③ 不推荐、不销售药品，不验配医疗器械，不承诺疗效。完整合规清单见模块12《医疗边界与合规红线》。

一、这套内容怎么用（三条纪律）

与模块03 的分工：模块03 是"查表定档 + 现场怎么说"，本模块是"这类问题怎么解"。两者配合——数值区间、异常阈值、四档判定一律查模块03；本模块不重复建账，只在必要时提示关键阈值，避免同一数值出现两种口径。

纪律一 · 只识别，不下诊断

本模块的异常名称是内部识别用语。对顾客只说两件事：看到了什么现象、建议去哪里进一步查。禁止出现"您这是×××"这类结论式表达。

纪律二 · 数值只认模块03

参考区间、异常阈值、四档档位以模块03 为唯一来源；本模块给的是判读逻辑（看趋势、看双眼差、看同设备复测），两者冲突时以模块03 为准并上报修订。

纪律三 · 门店只执行 L1

三层阶梯中，门店的战场只有最下面一层。看到 L2 / L3 的手段，动作只有三个：识别、转介、随访——不验配、不处方、不销售、不承诺。

与模块02 第⑤步「必做 / 建议 / 可选」的区别（务必分清）：第⑤步的"三层结构"讲的是方案包怎么分层给顾客报价（必做 = 安全底线、建议 = 效果优化、可选 = 体验提升）；本模块的"三层干预阶梯"讲的是医学干预的强度分级（L1 → L2 → L3）。两者互相独立、不互相替代：一项 L1 手段（例如每天两小时户外）在方案书里可能落在"必做"，也不会因为它不花钱就被降级为"可选"。

三、三层干预阶梯：L1 / L2 / L3 统一框架

同一类异常，"谁来做、做到什么程度"差别很大。本模块把所有干预动作归入三个层级，每层都有明确的执行主体与门店角色。看方案时先问一句："这一步是谁在做？"

L1 · 预防与基础干预

目的：把"有效、安全、几乎不额外花钱"的事先做到位，降低发生与进展风险。

典型手段：足矫配镜与正确戴镜、户外活动、用眼行为与环境、健康宣教、定期复查与建档随访。

门店角色：主导执行——这是门店唯一的"主战场"。

L2 · 常规诊疗手段

目的：对已经发生的异常做规范化诊疗，控制进展或改善功能。

典型手段：药物类（须医师处方）、角膜塑形镜与离焦软镜验配、棱镜与近用附加处方、视功能训练、常规手术评估。

门店角色：识别 + 转介 + 依从性随访——不验配、不处方、不销售。

L3 · 进阶或综合干预

目的：处理进展快、单一手段控制不佳、合并多因素或需要特殊器械 / 手术的情况。

典型手段：联合方案（光学 + 药物 + 行为）、器械类干预（如重复低强度红光）、斜视矫正等手术、疑难会诊。

门店角色：转介 + 记录 + 配合随访——不参与方案决策。

层级谁主导典型手段门店角色不可触碰的红线
L1门店足矫配镜、户外活动、用眼行为与环境、宣教与复查、建档随访主导执行不承诺疗效；不下诊断性结论
L2医疗机构药物、角膜塑形镜 / 离焦软镜验配、棱镜与近用附加、视功能训练、常规手术评估识别 / 转介 / 随访不验配医疗器械、不处方、不推荐或销售药品
L3医疗机构（专科 / 综合）联合方案、器械类干预、手术、疑难会诊转介 / 记录 / 配合不解释病因、不比较机构优劣、不参与方案决策

四、逐类异常：诊断说明与三层方案

以下每个小节结构固定：诊断要点（识别与判读）→ 门店可识别信号 → 常见原因与风险 → 三层解决方案 → 转诊与随访。数值区间一律见模块03，此处只给判读逻辑与关键阈值提示。

4.1 屈光不正（近视 / 远视 / 散光 / 屈光参差）

诊断要点（识别与判读）：屈光不正的本质是眼的总屈光力与眼轴长度不匹配，平行光线不能准确聚焦在视网膜上。门店判读的关键不是"这一次是多少度"，而是"两次之间变了多少"和"双眼之间差多少"——单次度数只说明现状，趋势才决定方案。青少年必须同时看屈光度与眼轴两条线；若度数方向与眼轴方向明显矛盾，先按模块02 第②步的"数据验真三红线"复核数据，不要急着下结论。

亚型核心识别信号关键阈值提示（详见模块03 §二 / §三）门店动作
近视裸眼视力下降、看远模糊、度数逐年增加等效球镜 ≤ -0.50D 即为近视；年增长 > 0.50D/年 判为进展偏快足矫验配 + 建档，按复查节奏随访
近视前期尚未达到近视，但远视储备消耗快、眼轴增速偏快等效球镜在 +0.75D ~ -0.50D 之间强化 L1（户外 + 用眼行为），缩短复查间隔
远视低龄儿童散瞳后明显正度数；可能伴内斜、看远也易累结合年龄判断是否属"远视储备不足"全屈光矫正；疑似伴斜视立即转诊
散光看远看近都不够清、有重影感、歪头或眯眼柱镜 ≥ 1.00D 需关注；短期内明显增加提示角膜形态变化足矫；短期快速增加转诊
屈光参差双眼度数相差大、遮盖时单眼视力明显更差双眼等效球镜差 ≥ 1.00D 需关注；伴双眼视力差 ≥ 2 行提示弱视风险足矫；伴弱视风险转小儿眼科

常见原因与风险：遗传背景与长时间近距离用眼负荷叠加，是近视发生与进展的两条主线；户外光照不足会明显放大风险。屈光不正本身不可怕，真正的风险是"没管住的进展"——度数快速上涨伴随眼轴拉长，成年后眼健康风险随之上升。所以判读时不能只报度数，必须把趋势讲清楚。

三层解决方案

层级具体手段适用条件门店口径
L1足矫框架眼镜（含离焦设计）+ 正确戴镜 + 每天户外 ≥2 小时 + 用眼间歇与环境调整所有屈光不正人群；离焦设计适用于 6~18 岁进展期儿童青少年门店主导：验配、宣教、建档、随访
L1用眼行为与环境：读写姿势、光照与屏幕距离、睡眠、近距离用眼分段所有人群，无门槛门店宣教（素材见模块05）
L2角膜塑形镜（OK 镜）验配近视进展期儿童青少年；具体适用条件（年龄、度数、散光、角膜曲率、依从性）见第五章门店不验配，转具备资质的医疗机构
L2离焦软镜（日抛）不适合或不接受夜间佩戴者，手卫生与使用条件达标同上，只识别与转介
L2低浓度阿托品进展快、年龄偏小者，须由眼科医师处方并随访不处方、不销售、不主动推荐；家长问及则转介
L3联合方案（光学 + 药物 + 行为）进展快、单一手段控制不佳配合随访，不参与方案决策
L3重复低强度红光等器械类干预进展快、单一手段控制不佳者；禁用情形见第五章须先完成评估；不承诺疗效，做好知情同意
转诊与随访：矫正视力不达标、度数短期内大幅变化、屈光参差伴双眼视力差、青少年眼轴年增超红线 → 转爱眼城眼科（小儿眼科）评估。一般近视 3~6 个月复查一次；进展偏快者缩短至 3 个月。

4.2 双眼视功能异常（调节、聚散、隐斜失代偿）

诊断要点（识别与判读）：双眼视功能异常＝眼睛"对得准、跟得上、看得久"这三件事出了问题，典型特征是症状重、单项指标看着不重——顾客主诉很多，单看度数却"没大问题"。判读分两条线：调节线看调节幅度、调节灵活度（翻转拍）、调节反应（BCC）与 NRA / PRA；聚散线看隐斜量、融像范围（破裂 / 恢复值）、集合近点（NPC）与聚散灵敏度。两条线分别与参考值对照，且必须以同设备、同方法复测的结果为准。

维度核心识别信号关键阈值提示（详见模块03 §四 / §五）门店动作
调节不足看近易累、字发虚、看近转看远要"缓一下"、阅读易串行调节幅度低于同龄期望（期望值 ≈ 15 − 0.25 × 年龄）；单眼翻转拍 < 11 cpm、双眼 < 8 cpm；BCC 滞后 > +0.75D先全屈光矫正，症状持续转诊评估
调节过度看远模糊、眼胀头痛、看近后抬头看不清BCC 超前（低于 +0.25D）、NRA 偏低宣教用眼节奏，症状持续转诊
集合不足阅读久了眼胀、重影感、注意力涣散集合近点 ≥ 6cm 为参考（< 5cm 提示集合过度倾向）；近距外隐斜量大于远距；近距 BI 破裂值偏低、聚散灵敏度低于 15 cpm筛查 + 转诊；训练由医疗机构执行
集合过度 / 内隐斜看近头痛、看近后视远模糊AC/A 参考 3~5△/D，> 5△/D 提示偏高；远距内隐斜筛查 + 转诊
隐斜失代偿间歇性复视、长时间用眼后眼位"发飘"融像范围不足（远距 / 近距 BI 或 BO 破裂值低于参考）出现复视或眼位异常即转诊

常见原因与风险：屈光未全矫正（尤其是散光与屈光参差）、长时间近距离用眼、睡眠不足与视疲劳是主要诱因。风险不在眼睛"坏掉"，而在长期带症状学习与工作——儿童可能出现阅读困难、注意力差，被误解为"不认真"；成人则直接影响驾驶安全与工作效率。

三层解决方案

层级具体手段适用条件门店口径
L1全屈光矫正（足矫，散光与参差一并矫正）+ 用眼间歇与远眺 + 阅读姿势与照明所有人群门店主导：验配 + 宣教
L1用眼节奏：20-20-20 法则、单次近距离用眼 ≤ 30~40 分钟所有人群门店宣教与随访提醒
L2视功能训练（调节、聚散、融像，含家庭训练）须先明确诊断；由具备资质的人员执行，一般 12 次为一疗程门店不自行开展；转医疗机构，或按公司合作项目规范执行
L2棱镜处方 / 近用附加（ADD）内隐斜、集合过度、高 AC/A 等须由医师或高级视光师处方，门店不自行开方
L3斜视矫正手术、综合视功能康复显性斜视、训练无效或症状持续影响生活转爱眼城眼科
转诊与随访：复核后指标仍明显偏低、出现复视或眼位异常、症状持续影响学习工作 → 转诊。训练 / 遮盖类复查建议每 6 周一次，且必须同设备同方法，否则趋势不可比。

4.3 眼表与泪膜异常（干眼倾向、睑板腺功能异常、接触镜相关）

诊断要点（识别与判读）：眼表与泪膜问题最容易被"只查度数"漏掉。判读要抓住三点：症状（干涩、异物感、烧灼、畏光、视力波动、越到下午越明显）、泪膜稳定性（泪膜破裂时间、泪河高度）、睑缘与睑板腺（睑缘充血、开口堵塞、分泌物性状）。要点是症状与体征未必一致——有症状无体征、或有体征无症状都存在，必须"症状 + 体征"合并判断，不能只凭一项下结论。

检查项正常参考与分档异常提示什么门店动作
泪膜破裂时间> 10 秒为正常；5~10 秒为干眼倾向；≤ 5 秒为明显异常泪膜不稳定，泪液"留不住"宣教 + 复查；≤ 5 秒且有症状转诊
泪液分泌（Schirmer I）10~45mm/5min；< 10mm/5min 提示分泌不足泪液"产得少"宣教 + 复查；明显偏低转诊
泪河高度0.3~0.5mm；变窄提示泪液不足泪液量下降结合症状判断，异常转诊
睑板腺功能睑缘无充血、开口通畅、挤压分泌物清亮睑板腺功能异常（睑酯质量或排出障碍）可指导物理护理；明显异常转诊
接触镜相关眼表结膜无充血、角膜上皮完整、无新生血管缺氧或机械刺激反应立即停戴并建议转诊评估

常见原因与风险：长时间看屏幕导致眨眼频率与完整性下降、空调与干燥环境、睡眠不足、长期佩戴角膜接触镜、睑缘清洁不到位是主要诱因。风险在于症状持续影响视觉质量，并让配镜与训练的适应性变差；角膜接触镜佩戴者若出现角膜上皮损伤或角膜新生血管，属于必须停戴并评估的情形。

三层解决方案

层级具体手段适用条件门店口径
L1用眼行为（有意识完整眨眼、分段用眼）+ 环境调整（湿度、避开风与空调直吹）+ 保证睡眠 + 缩短接触镜佩戴时长所有人群门店主导：宣教与随访
L1睑缘热敷与清洁护理（物理护理，不涉及药品）睑缘或睑板腺功能异常倾向者门店可指导动作，不销售、不推荐任何药品或保健品
L2人工泪液、抗炎等药物须由医师指导使用门店不推荐、不销售药品，只做转介
L2睑板腺理疗、泪点栓塞评估等中重度、物理护理效果不佳者转诊
L3强脉冲光等综合干眼管理难治性或合并多种因素转诊，门店只配合随访
转诊与随访：泪膜破裂时间 ≤ 5 秒且症状明显、角膜上皮点状着色、角膜接触镜相关角膜新生血管、视力明显波动 → 转诊。护理类措施建议 2~4 周后复评一次，观察症状与泪膜指标是否改善。

4.4 儿童视觉发育异常（弱视、斜视、眼球运动障碍）

诊断要点（识别与判读）：儿童期异常的核心判断依据是"和同龄比"而不是"和 1.0 比"。视力发育有年龄台阶：3 岁起逐步提升，学龄前后趋于稳定，因此低龄儿童不能用成人标准衡量。门店要做的是三件事：查得出（视力 + 屈光 + 眼位 + 眼球运动）、记得住（建档留基线）、送得走（疑似即转小儿眼科）。这类问题存在关键期，越早处理越好，门店任何"再等等看"的建议都可能造成不可逆的后果。

异常核心识别信号关键阈值提示（详见模块03 §一）门店动作
弱视戴镜后视力仍达不到同龄水平；双眼视力差别明显；有斜视、屈光参差或高度屈光不正史最佳矫正视力低于同龄下限（3~5 岁 < 0.5、6 岁以上 < 0.7）或双眼视力差 ≥ 2 行不判断、不训练，直接转爱眼城眼科（小儿眼科）
斜视遮盖试验见显斜、角膜映光点明显偏斜、孩子阳光下常闭一只眼遮盖试验与角膜映光法所见（无"正常值"可套，看到即报）转诊；不承诺配镜可解决
眼球运动障碍 / 震颤眼球不自主摆动、习惯性歪头视物、注视不稳、跟随移动目标困难观察所见 + 头位异常转诊，注明观察到的现象与出现时机
屈光参差性弱视风险双眼度数差距大且未完全矫正；单眼遮盖时视力和配合明显更差屈光参差判定同 4.1；核心看是否已出现双眼视力差 ≥ 2 行全屈光矫正 + 转小儿眼科评估

常见原因与风险：未矫正的高度屈光不正与屈光参差、斜视、先天性因素都可能影响视觉发育；近视的遗传倾向也较明显（父母双方近视时孩子风险更高）。风险是错过关键期后视觉功能难以完全追回，所以儿童异常的第一原则是"早发现、早转诊、早建档"。

三层解决方案

层级具体手段适用条件门店口径
L1早期筛查（3 岁起建立屈光发育档案、配合幼儿园视力筛查）+ 全屈光矫正（戴镜是基础）+ 依从性管理所有儿童青少年门店主导：筛查、建档、宣教、提醒复查
L1户外活动与用眼行为干预所有儿童青少年门店宣教 + 家庭打卡
L2遮盖 / 压抑疗法 + 屈光矫正 + 在医生指导下的视觉训练明确诊断后执行；一般每 6 周复评一次门店只做配合与随访提醒，不执行训练方案
L2斜视相关的非手术方案评估间歇性斜视、小角度斜视等转诊评估，不自行判断适用性
L3斜视矫正手术、复杂弱视综合治疗显性斜视、难治性弱视转诊，门店只配合随访
转诊与随访（儿童一律升级处理）：视力低于同龄下限、双眼视力差 ≥ 2 行、眼位偏斜、歪头视物、眼球摆动 → 转爱眼城眼科（小儿眼科），并强调"越早处理越好"，提醒家长带齐已有检查资料与既往病历。门店在建议书中写明转诊项目与紧迫程度，3 日内回访。

4.5 眼前节与角膜形态异常（角膜形态不规则、晶状体混浊、前房偏浅）

诊断要点（识别与判读）：这一类属于门店只做发现、必须立即转诊的情形。判读要点是"变化速度 + 形态"：角膜曲率偏高本身不一定是问题，但曲率偏高且形态不规则、或散光在短期内明显增加，就提示角膜形态可能出现改变；晶状体混浊要看是否与年龄性早期改变相称；前房偏浅要结合症状（眼胀痛、看灯有彩虹圈）判断。门店纪律：只描述所见现象，不用病名下结论，不自行处理。

所见核心识别信号关键阈值提示（详见模块03 §三 / §五）门店动作
角膜形态不规则角膜曲率偏高且形态不规则；散光短期内明显增加；戴镜视力反复不稳角膜曲率 > 47D 且形态不规则 → 明确转诊停止验配流程，出具书面转诊提示
晶状体混浊裂隙灯可见明显混浊；主诉看东西发朦、眩光、夜间视物差混浊程度与年龄性早期改变不相称不解释病因、不推荐任何"改善"产品，转诊评估
前房偏浅裂隙灯估计前房偏浅，伴眼胀痛、看灯有彩虹圈出现上述症状组合即为急症倾向急转诊，且不得自行散瞳
角膜接触镜相关损伤角膜上皮点状着色、角膜新生血管、眼红疼痛畏光戴镜后出现任一表现立即停戴并转诊

常见原因与风险：角膜形态改变可能与先天因素、长期揉眼习惯、角膜接触镜使用不当等有关；晶状体混浊与年龄、代谢及用眼环境相关。风险在于这些问题拖延会直接影响视力与安全，且部分属于不可逆改变，因此门店的处理不是"下次复查再看"，而是当场说清、当天建议就医。

三层解决方案

层级具体手段适用条件门店口径
L1（门店唯一动作）识别现象 → 停止验配流程 → 口头说清 + 书面写明转诊提示 → 3 日内回访发现任一上述现象门店主导：不做任何处置性操作
L2角膜地形图随访、专科评估（是否需器械或用药）须由眼科评估后决定转诊，门店不参与判断
L3专科治疗或手术须由眼科评估后决定转诊，门店只配合随访
转诊与随访：本类情形一律即时转诊，不给"观察一段时间"的选项。前房偏浅伴眼胀痛与虹视属于急症倾向，应当场协助联系家属，24 小时内回访。

4.6 需即刻转诊的危险信号（急性类）

诊断要点（识别与判读）：这一类不需要"判读"，只需要"认得、敢停、快送"。特点是突然发生、进展快、可能威胁视功能。门店遇到下列任一情形，立即停止一切产品推荐，转入转诊提醒流程。

现象（顾客主诉或门店所见）紧迫程度门店动作
突发视力下降、眼红剧痛伴头痛恶心立即停止推荐，当场协助联系家属，指引尽快就医
闪光感 + 飞蚊突然增多、视野某一区域缺损立即同上；提醒顾客不要自己开车前往
新发复视 / 眼球向某方向转动受限尽快（当天）转爱眼城眼科，说明出现时间与方向
瞳孔异常：双眼不等大、对光反应迟钝、RAPD 阳性尽快（当天）转爱眼城眼科，记录观察方法与结果
浅前房伴眼胀痛、看灯有彩虹圈尽快（当天）不得自行散瞳，指引就医
眼外伤、化学物品入眼立即协助冲洗（如适用）并立即就医，不留店观察
完整红线清单见模块12 §三「必须转诊的 12 类情况」，本表是其中的急性部分。转诊三步动作缺一不可：①口头说清楚（哪一项、为什么、多久之内去）→ ②书面写明白（建议书"转诊提示"栏写明项目与紧迫程度）→ ③事后有跟进（3 日内回访；急性症状当场协助，不留到回访）。

五、专项：青少年近视的三层解决方案（重点）

青少年近视是门店最高频的场景，也是"手段最多、家长最容易被带偏"的场景。下表把五类主要手段放回三层阶梯里，一眼看清每类手段由谁做、门店能做什么、边界在哪。讲给家长时的总原则：只讲适用条件与注意事项，不比较谁最好、不承诺效果，最终由家长在知情后选择。

手段层级适用条件关键参数与口径门店能做什么
验光配镜（单光 / 多点离焦）L1任何年龄；离焦设计适用于 6~18 岁、进展期、能全天佩戴（建议 ≥12h/天）以足矫为原则；镜架稳定性与瞳高定位直接影响效果；复查 1 / 3 / 6 个月验配、宣教、建档、随访——门店核心动作
角膜塑形镜（OK 镜）L2≥8 岁、-0.75 ~ -6.00D、顺规散光 ≤ 1.50D、角膜曲率 40~46D、卫生与复查依从性好；眼表或角膜条件不佳、卫生习惯差者不适用属严格管理的医疗器械；戴后 1 天 / 1 周 / 1 个月复查，之后每 3 个月随访门店不验配；只识别、转介；出现眼红、疼痛、畏光、视力下降，立即提醒停戴并就医
视觉训练L2明确存在调节或聚散功能异常；不能替代光学矫正与户外干预一般 12 次为一疗程，疗程结束后评估；评估须同设备同方法门店不自行开展；转医疗机构，或按公司合作项目规范执行
重复低强度红光（器械类干预）L3进展快且眼表与角膜检查正常；有眼部疾病史、光敏性疾病、癫痫史或正在使用光敏药物者禁用须按规范时长使用；使用期间按规范定期查眼表、角膜与视力须先完成评估；不承诺疗效，做好知情同意与规范记录
大户外活动L1所有儿童青少年，无门槛——是最基础也最重要的一项每天 ≥2 小时（每周 ≥14 小时）；关键在户外光照，不在运动形式宣教 + 家庭打卡，每次复查回顾执行情况

组合使用原则（四条）

  • 顺序原则：先把 L1 做到位（足矫 + 户外 + 用眼行为），再根据进展速度与风险叠加 L2 / L3。跳过 L1 直接上器械，效果常被依从性拖垮。
  • 叠加原则：任何单一手段都有天花板。进展快、年龄小、父母高度近视等高危因素叠积时，通常需要联合方案，由医疗机构评估后决定。
  • 评价周期：以 3~6 个月的趋势（屈光度变化 + 眼轴变化）判断效果，不用单次数据下结论，也不因一次"没涨"就放松随访。
  • 承诺红线：所有手段都不能承诺"度数不涨"。效果因人而异，对家长要说的是"大概率能减速度、要按周期看数据"，不是"保证见效"。

五个常见误区（对家长要主动纠正）

家长常见说法纠正口径
"配了离焦镜就不用管了"镜片只是其中一个变量；户外与用眼行为做不好，效果会被抵消。
"训练可以把度数练没"训练解决的是调节与聚散这类功能问题，不改变屈光状态，不能替代配镜与户外。
"红光 / 理疗能降度数"门店没有任何"降度数"的口径，也不承诺疗效；是否适用由医疗机构评估后决定。
"成年了度数就不会涨了"多数人成年后趋于稳定，但快速进展者与高度近视者仍需要持续随访。
"先让孩子玩手机，长大做手术就行"近视管理的目的不只是"看清"，还在于控制进展；手术解决的是屈光，不改变已经拉长的眼轴。

下面这张表是本模块的"操作总闸"：涉及哪类内容，门店能做什么、绝不能做什么、往哪里去。与模块12《医疗边界与合规红线》配套使用——本表管"动作"，模块12 管"红线与话术"。

本模块内容门店可做（L1）门店不得做去向

儿童视觉发育异常视力筛查、建档、依从性提醒不下判断、不做训练方案、不承诺"配镜就能好"爱眼城眼科（小儿眼科），越早越好

七、随访与复查节奏统一口径

复查日期不是"下次再来"，而是写进系统、写进建议书、到期有提醒的确定动作。下表是全站统一的复查口径，各模块引用同一套，不另立标准。

情形复查间隔复查项目判定依据
未近视儿童（已建档）6 个月视力、屈光、眼轴与角膜曲率同龄安全增长值（见模块03 §三）
已近视（进展一般）3~6 个月视力、屈光、眼轴、镜片与镜架适配屈光度与眼轴的趋势（见模块03 §三）
控制不佳或进展偏快3 个月上述项目 + 依从性评估（户外、戴镜时长）模块03 的三档判定

弱视遮盖 / 训练每 6 周视力、眼位、依从性由医疗机构执行，门店只做提醒
干眼护理 / 视功能训练2~4 周后复评；训练 12 次一疗程后评估同设备同方法复测（泪膜、调节、聚散）模块03 §四 / §五
铁律：复查必须同一设备、同一方法、同一条件，否则趋势不可比，不要拿两次不同方法的结果去对比。复查后无论结果好坏，都要留档并给出下一步动作。

八、使用纪律

  • 数值唯一来源：参考区间、异常阈值与档位一律以模块03 为准；本模块只讲判读逻辑，不另立数值。
  • 只描述、不下结论：对顾客只说"看到了什么现象 + 建议去哪里查"，不用异常名称下结论，不说"您这是×××"。
  • 不碰药品与医疗器械：不推荐、不销售药品与保健品；不验配角膜塑形镜等医疗器械；不做医疗处置。
  • 不承诺疗效、不做比较：不说"保证不涨""一定能好"；不贬低医院与其他机构；不给疗效排序。
  • 转诊统一口径：去向统一为"爱眼城眼科"，儿童项目为"爱眼城眼科（小儿眼科）"，完整红线见模块12 §三。
  • 儿童特别提示：儿童异常一律升级处理，不设"再等等看"；涉及未成年人须家长在场并签字确认。
本模块在生产培训中的用法建议：新员工先记"六大类总览表 + 三层阶梯"两页；在岗员工按客诉场景查对应小节；会诊专家把关时重点用第 4.5 / 4.6 两节（该停就停、该转就转）。配合模块03 的四档判定与模块12 的红线清单，三份合起来即为"识别—处置—边界"的完整闭环。
