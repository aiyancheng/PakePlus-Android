穿针引线法

化正 → 标根 → 从右上起笔 → 奇穿偶不穿。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

第 18 讲的一元二次不等式只是开胃菜。到了三次、四次不等式，展开后根本没法看——但只要你把它因式分解后画一条「穿行」的曲线，答案五秒钟就出来了。这就是穿针引线法（也叫数轴标根法）。

它的强大之处在于：不管多少次、多少个因式，规则完全一样。学会了它，高中三年的整式不等式基本通吃。

壹从原理上讲透

一、五步流程

① 化正
把最高次项的系数化为正（乘 −1 则不等号反向）
② 分解
因式分解，求出每个根并标明重数
③ 标根
把根按从小到大标到数轴上
④ 穿线
从右上方起笔，向左依次穿过每个根：奇次根穿过中心线、偶次根从同侧弹回
⑤ 定解
看曲线在数轴上方（>0）还是下方（<0），写出对应区间

二、为什么「右上起笔」？

最高次项系数为正时，当 x → +∞，整式的值趋向 +∞，也就是正数。所以最右边的区间一定是「正」，曲线从上方开始往左走。

三、为什么「奇穿偶不穿」？

越过一个根时，只有这一个因式改变符号（其他因式在根附近符号几乎不变）。

若该因式是奇次幂（如 (x−2)¹），符号会改变 → 曲线穿过数轴；若是偶次幂（如 (x−2)²），它恒 ≥0，符号不变 → 曲线在同侧弹回（碰到但不穿过）。

奇重数（1、3、5…）
符号翻转 → 穿过数轴
偶重数（2、4、6…）
符号不变 → 同侧弹回（不穿过）
最后一步别忘了检查：取到的端点是否应该挖掉。原式是严格不等号时，所有根都不包含在解集中；若式子出现在分母位置，该根即使由偶次「弹回」也一定要挖掉。

贰图像里的逻辑

叁核心结论（要背的）

第 1 步
化正：最高次项系数变正（不等号随之反向）
第 2 步
因式分解，标出所有根及其重数
第 3 步
从小到大标根，从右上角起笔
第 4 步
奇重数穿过数轴，偶重数同侧弹回
第 5 步
取「正」区间或「负」区间，挖掉不该含的端点

奇穿偶不穿，右上起笔，这八个字就是全部口诀。

它与第 18 讲的二次不等式完全兼容：两根都是奇重时就是「大于取两边、小于取中间」。

肆解题步骤：拿到题怎么下手

  1. 整理：移项使右边为 0，左边因式分解。
  2. 化正：若最高次项系数为负，两边乘 −1 并翻转不等号。
  3. 标根：把所有根（含重数）标到数轴上，按大小排列。
  4. 穿线：从右上方开始，奇穿偶不穿地画到最左边。
  5. 读数：>0 取曲线在轴上方的区间，<0 取下方的区间；注意分母的根必须挖去。

伍例题精讲

例1解不等式 (x + 1)(x − 2)(x − 3) > 0。
展开完整解析

思路：已经分解好了，最高次项系数为正，直接标根穿线。

  1. 最高次项系数为正（三次项系数为 +1），无需化正。
  2. 三个根：−1、2、3，重数都是 1（奇重），全部穿过。
  3. 从右上方起笔：x>3 为正 → 穿 3 → (2,3) 为负 → 穿 2 → (−1,2) 为正 → 穿 −1 → x<−1 为负。
  4. >0 取正区间：−1 < x < 2 或 x > 3。
  5. 取点验证：x=0 得 (1)(−2)(−3)=6>0 ✓；x=2.5 得 (3.5)(0.5)(−0.5)<0 ✓。
答：−1 < x < 2 或 x > 3。
例2 · 偶重根解不等式 (x − 1)²(x + 2) < 0。
展开完整解析

思路：x=1 是平方项，属于偶重根，穿到这里会「弹回」而不穿过。

  1. 最高次项系数为正，无需化正。
  2. 根为 −2（重数 1，奇）与 1（重数 2，偶）。
  3. 从右上方起笔：x>1 为正 → 到 x=1 因是偶重，弹回不穿，仍是正 → 过 (−2,1) 保持正 → 到 x=−2 为奇重，穿轴变负 → x<−2 为负。
  4. <0 取负区间：x < −2。
  5. 取点验证：x=0 时 (1)(2)=2>0（落在正区间）✓；x=−3 时 16·(−1)=−16<0 ✓。
答：x < −2。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 忘记化正：最高次项系数为负时右端不是「+,必须从右上起笔。
  • 偶重根照样穿过：这是最常见的失误，记住「碰到就弹回」。
  • 端点没挖掉：分母中的根、以及严格不等号下的所有根都不能包含在解集里。
  • 没分解就穿线：必须先化成若干一次（或不可再分）因式的乘积。

柒它在生活里长什么样

🏀 从课本走到现实

  • 多因素区间分析：把复杂条件拆成若干开关（因式），逐个判正负，得到整体可用的参数区间。
  • 多因素决策：几个因素各自独立影响结果的正负，正是「各个因式独立变号」的现实版。
  • 电路分析：多个开关串联时，总通断由各段的奇偶状态决定。

捌本节小结

✍️ 记住这几条就够了

  • 化正 → 标根 → 右上起笔 → 奇穿偶不穿 → 定解集。
  • 偶重根时不翻转符号，奇重根时翻转——这是整套方法的灵魂。
  • 它与一元二次不等式的口诀完全兼容。
  • 分母中的根、严格不等号下的端点，一定要挖掉。
