一、瞳距（PD）——眼镜配制的"灵魂参数"

瞳距（Pupillary Distance, PD）是两瞳孔中心之间的距离，它是配镜时光学中心定位的核心依据。瞳距测量不准，会导致光学中心与视轴不重合，产生棱镜效应，引发视疲劳、头晕甚至斜视。在眼镜行业，PD测量错误是导致顾客投诉的"头号原因"。

1. 瞳距的两种类型

类型定义测量场景典型数值
远用瞳距（Distant PD）看远方时双眼瞳孔中心距看远用镜（单光、渐进多焦点远用区）成人54-74mm，平均62mm
近用瞳距（Near PD）看33cm近方时双眼瞳孔中心距看近用镜（老花镜、渐进近用区、抗疲劳镜）比远用PD小2-4mm

2. 瞳距不准的后果

  • 产生基底向内的棱镜效应：PD偏大（光学中心内移不足）→ 看远时产生BI棱镜 → 眼外肌过度集合 → 视疲劳
  • 产生基底向外的棱镜效应：PD偏小（光学中心过度内移）→ 看近时产生BO棱镜 → 集合不足者症状加重
  • 渐进镜片瞳距偏差：渐进镜片对瞳距精度要求最高，偏差>2mm即可出现明显的像散和畸变区干扰
经验法则：PD测量宁可"偏小不可偏大"？错！正确做法是"宁准确不可凑整"。将PD四舍五入到整数（如61.5mm记为62mm）是常见但错误的做法，应保留两位小数（61.5mm）。

二、瞳距仪（PD仪）的使用规范

瞳距仪是专门用于精确测量PD的仪器，比用尺子量准确得多，是专业门店的标配设备。

1. 瞳距仪的结构

  • 目镜：验光师通过观察目镜观察顾客瞳孔
  • 测量臂：可左右移动，对准左/右瞳孔中心
  • PD显示窗：数字显示当前测量的PD值（mm）
  • 远/近切换旋钮：切换远用（∞）或近用（如33cm）测量模式
  • 瞳高测量功能：部分高端PD仪可同步测量瞳高（瞳孔中心到镜框下缘的距离）

2. 远用PD标准测量步骤

  1. 顾客准备：坐在PD仪前，调整座椅高度使眼睛与仪器目镜平齐
  2. 仪器归零：确认PD仪显示"0.00"或上次测量已清零
  3. 右眼定位：让顾客看仪器内的远固视视标（房子/热气球），移动右测量臂使十字线对准右瞳孔中心
  4. 左眼定位：移动左测量臂使十字线对准左瞳孔中心
  5. 读数记录：读取PD显示值，记录（精确到0.5mm），注明"远用PD"
  6. 双眼定位：用"双眼定位模式"（部分PD仪有）验证双眼PD与分别测量值一致

3. 近用PD测量步骤（33cm）

  1. 将PD仪切换到"近用"模式（通常标识为"33cm"或"N"）
  2. 嘱顾客看仪器内的近用视标（通常在仪器中部）
  3. 按远用相同方法分别对准两眼瞳孔中心
  4. 读取近用PD值，记录（通常比远用小2-4mm）
注意：渐进镜片PD测量必须用"单眼瞳距"（右眼PD和左眼PD分别对鼻梁中线的距离），而非双眼总PD。许多PD仪有"单眼PD模式"，务必使用此模式！

三、瞳距测量的特殊情况处理

实际工作中会遇到各种"非标准"情况，验光师需要灵活应对：

1. 瞳孔大小不对称

若顾客一眼瞳孔明显大于另一眼（如白内障术后散大），以正常大小瞳孔为准，或取两眼瞳孔中心距的平均值。切忌以散大瞳孔为准。

2. 高度近视/高度远视的PD修正

  • 高度近视：镜片有棱镜效应，实际PD应略小于测量PD（移心量计算时需考虑）
  • 高度远视：同理，实际PD应略大于测量PD
  • 修正公式：实际PD = 测量PD × (1 - 镜眼距效应修正系数)，具体由加工师根据镜片参数计算

3. 儿童PD测量

  • 儿童PD偏小（3岁约43-47mm，6岁约48-52mm，12岁接近成人）
  • 儿童配合度差：可用瞳距尺（PD尺）快速估测，再上PD仪确认
  • 幼儿PD异常小（<40mm）：警惕内斜视可能，需转诊眼科

4. 单眼PD vs 双眼PD的取舍

镜片类型PD精度要求推荐测量方式
单光镜（低度）±1-2mm可接受双眼总PD
单光镜（高度>6D）±1mm单眼PD
渐进多焦点±0.5mm单眼PD + 瞳高
双光镜±1mm单眼PD + 瞳高
抗疲劳镜±1mm单眼PD（推荐）
📝 今日小结
  • 瞳距（PD）是配镜光学中心定位的灵魂参数，偏差>2mm渐进镜片即产生明显像散干扰
  • 远用PD（看远）vs 近用PD（看33cm）：近用PD比远用PD小2-4mm
  • PD仪标准操作：归零→右眼定位→左眼定位→读数（精确到0.5mm）→记录（远用/近用）
