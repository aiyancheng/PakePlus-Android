抛物线与任意直线

联立二元二次，Δ 定交点个数：相切、相交、相离三种情况。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

把第 16 讲的水平线扶正一点点斜起来，就来到了中考压轴真正爱考的地方：抛物线与任意直线 y = kx + b 的交点。拱桥的斜拉索、投篮轨迹与篮板、光线入射，全都是这个模型。

好消息是：做法和第 16 讲完全一样——联立、消元、看 Δ。唯一的难点是消元后的系数会带上参数，书写要更仔细。

壹从原理上讲透

一、联立消元

设抛物线 y = ax² + bx + c 与直线 y = kx + d，交点处两者相等：

ax² + bx + c = kx + d ⟹ ax² + (b − k)x + (c − d) = 0

因为 a≠0，这仍是一元二次方程，判别式：

Δ' = (b − k)² − 4a(c − d)

二、三种情况

Δ' > 0
两个不同交点（直线穿过抛物线）
Δ' = 0
一个交点（直线与抛物线相切）
Δ' < 0
无交点（直线与抛物线相离）

三、切点在哪里

Δ'=0 时，二次方程有重根 x = −(b−k)/(2a)，代入直线即得切点坐标。这个 x 也等于「抛物线在该点处的切线斜率等于 k」的位置，高中用导数求切线，初中就用 Δ'=0 求——方法不同，答案一致。

如果消元后二次项系数为 0（即 a=0，或题目给的两条曲线之一退化为一次），方程就变成一次方程，此时只有唯一解，不能再用 Δ 讨论——先看二次项系数是否为 0 是第一步。

三步不变：联立 → 消元 → 数 Δ，与第 16 讲一脉相承。

「直线与抛物线相切」 ⟺ Δ' = 0，这是压轴题最常见的设问方式。

肆解题步骤：拿到题怎么下手

  1. 联立：令两个 y 相等，移项整理成 Ax² + Bx + C = 0。
  2. 确认次数：若 A=0 则退化成一次方程，单独处理（唯一交点）。
  3. 写 Δ'：Δ' = B² − 4AC，注意 B、C 里含有 k、d 等参数。
  4. 按题意列式：相交 Δ'>0，相切 Δ'=0，无交点 Δ'<0。
  5. 解出参数：解关于 k 或 d 的不等式 / 方程，并求切点（若需要）。

伍例题精讲

例1判断直线 y = 2x − 1 与抛物线 y = x² 的位置关系，若有交点求出交点。
展开完整解析

思路：联立后看判别式，Δ'=0 就说明相切。

  1. 联立：x² = 2x − 1 → x² − 2x + 1 = 0。
  2. 判别式 Δ' = 4 − 4 = 0 → 相切，只有一个公共点。
  3. 解方程：(x − 1)² = 0 → x = 1。
  4. 代回 y = x² 得 y = 1，切点为 (1, 1)。
  5. 验证：直线在 x=1 处 y = 2−1 = 1 ✓。
答：直线与抛物线相切，唯一交点为 (1, 1)。
例2 · 含参若直线 y = x + m 与抛物线 y = x² − 2x − 3 有两个不同交点，求 m 的取值范围。
展开完整解析

思路：联立得到含 m 的二次方程，用 Δ'>0 解。

  1. 联立：x² − 2x − 3 = x + m → x² − 3x − (3 + m) = 0。
  2. 二次项系数 1 ≠ 0，可用判别式：Δ' = 9 + 4(3 + m) = 21 + 4m。
  3. 有两个不同交点 ⟺ Δ' > 0 → 21 + 4m > 0 → m > −21/4。
  4. 边界检查：m = −21/4 时 Δ'=0，直线与抛物线相切（切点横坐标 3/2），不满足「两个不同交点」。
  5. 取 m = −5 检验：Δ' = 21 − 20 = 1 > 0 ✓（−5 > −5.25）。
答：m > −21/4。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 消元后忘了移项成标准形式：必须整理成 Ax²+Bx+C=0 再套判别式。
  • 把 k 的符号弄错：一次项系数是 b − k（直线斜率是加到右边的），不是 b + k。
  • 不讨论 A=0：若一次项也可能使式子退化，需要单独说明。
  • 相切写成 Δ'≤0：等于 0 才是相切，小于 0 是没有交点的相离。

柒它在生活里长什么样

🏀 从课本走到现实

  • 斜拉桥的拉索：拉索是直线，桥面曲线是抛物线，二者的连接点就是联立方程的解。
  • 灯光入射角度：平行光（一束直线）打到抛物面反射面上，反射后汇聚到焦点。
  • 投篮球与篮板：球的抛物线轨迹与篮板平面的交点决定撞击位置。

捌本节小结

✍️ 记住这几条就够了

  • 直线与抛物线：联立 → 消元 → Δ' 判三种情况。
  • Δ'>0 相交两点、Δ'=0 相切、Δ'<0 相离。
  • 消元后一次项系数是 b − k，常数项是 c − d。
  • 先检查退化情况（二次项系数为 0）再讨论 Δ。
