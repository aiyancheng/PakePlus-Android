一、为什么要了解生活场景

配眼镜不是买"标准品"，而是配"个性化解决方案"。同一个度数，不同的生活场景，推荐的产品完全不同。因此，了解顾客的生活场景是精准推荐的前提。

场景不同，需求不同：

  • 工作场景：长时间看电脑 → 需要防蓝光、抗疲劳镜片
  • 娱乐场景：经常看电影、玩游戏 → 需要高清晰度镜片
  • 运动场景：跑步、健身 → 需要防滑、耐冲击的眼镜

不了解场景的后果：

  • 推荐错误产品 → 顾客不满意，退货或投诉
  • 错失销售机会 → 顾客有其他场景需求，但你没问出来
  • 专业度受质疑 → 顾客觉得你"不专业"、"不理解我"
专业提示：询问生活场景时，不要只问"您是做什么工作的？"，而要问"您工作时主要看什么？电脑、文件还是人？"——这样才能了解到真正的用眼需求。

二、工作场景：长时间用眼是关键词

工作场景的核心问题是：顾客工作中最主要的用眼活动是什么？持续时间有多长？

常见工作场景及需求：

  • 办公室白领：长时间看电脑、手机 → 防蓝光、抗疲劳镜片
  • 设计师/摄影师：对色彩敏感 → 高阿贝数镜片（色散小）
  • 司机/外卖员：经常看路面、导航 → 偏光镜片、夜视镜片
  • 医生/厨师：需要看清细节 → 高精度镜片，防雾功能
  • 教师/培训师：需要看远处黑板和近处教案 → 渐进多焦点镜片

询问话术：

  • "您工作时主要看什么？电脑、文件、还是人？"
  • "您一天工作几个小时？其中看电脑/手机的时间大概有多长？"
  • "您工作时会觉得眼睛累吗？特别是下午或晚上？"
注意：有些顾客的工作是"多场景"的，例如销售需要开车拜访客户+办公室写方案。这时要问"您工作中最费眼睛的是哪个场景？"——优先解决最痛的点。

三、娱乐场景：了解顾客的"第二生活"

娱乐场景是指工作之外的生活，包括 hobbies、休闲活动等。这部分时间虽然不长，但对生活质量和心情影响很大。

常见娱乐场景及需求：

  • 追剧/看电影：需要高清晰度，暗光环境下也能看清
  • 打游戏：需要快速聚焦，减少眩光
  • 刷手机/社交媒体：需要防蓝光，减少眼疲劳
  • 旅游/摄影：需要变色镜片或太阳镜，户外防护
  • 阅读/学习：需要看近清晰，可能需要老花镜或抗疲劳镜片

询问话术：

  • "工作之外，您平时喜欢做什么？追剧、打游戏还是旅游？"
  • "您周末或者下班后，会不会长时间看手机或者看书？"
  • "您有没有什么爱好，需要比较好的视力才能享受的？比如摄影、画画？"
实战经验：很多顾客会忽略自己的娱乐场景，因为觉得"那不是正事"。你需要主动引导，让顾客意识到"娱乐时间也需要好的视力"。

四、运动场景：安全第一

运动场景对眼镜的要求是：安全第一、佩戴稳定、视野清晰。普通眼镜在运动时可能不够安全或不够稳定。

常见运动场景及需求：

  • 跑步/健身：眼镜容易滑落 → 需要防滑镜腿、运动镜框
  • 球类运动（篮球/羽毛球）：容易碰撞 → 需要耐冲击镜片（PC片）、护目镜
  • 游泳：水下看不清 → 需要近视泳镜
  • 骑行/摩托车：风沙、紫外线 → 需要防风镜、偏光太阳镜
  • 滑雪：雪地反光 → 需要偏光镜、防紫外线 goggles

询问话术：

  • "您平时运动吗？跑步、健身还是打球？"
  • "您运动时戴眼镜吗？会不会觉得眼镜滑或者不安全？"
  • "您有没有因为视力问题而影响运动表现？比如看不清球？"
安全提醒：对于高强度运动（如篮球、足球），要特别提醒顾客"运动时最好戴护目镜，普通眼镜容易碎裂伤眼"。这是专业且负责任的表现。
📝 今日小结
  • 了解生活场景是精准推荐的前提，不同场景需求不同
  • 工作场景：关注用眼时长和主要活动（电脑/驾驶/精细工作）
  • 娱乐场景：了解顾客的"第二生活"（追剧/游戏/旅游/阅读）
  • 运动场景：安全第一，防滑、耐冲击、护目镜
  • 多场景顾客：优先解决最痛的点，或推荐"一镜多用"方案
