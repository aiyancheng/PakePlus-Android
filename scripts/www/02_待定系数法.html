待定系数法

已知什么设什么：三点用一般式、顶点用顶点式、两交点用交点式。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

给你三个点，能不能画出唯一一条抛物线？答案是能——因为 y=ax²+bx+c 里恰好三个未知数 a、b、c，三个点列出三个方程正好解出来。这就是待定系数法：先把系数当作待定的符号设出来，再用条件把它们一个个钉死。

但聪明的做法不是每次都死列三元一次方程组。题目给的信息不同，选择的「起手式」就不同——选对了设的方式，别人算三分钟你算三十秒。这一讲就是把四种常见题型和它们的起手式讲透。

壹从原理上讲透

一、为什么「三个条件定一条抛物线」

二次函数的一般式是 y=ax²+bx+c（a≠0），里面有三个待定的数。一个点在图像上，就意味着把这个点的 x、y 代入后等式成立，也就是给出一个方程。所以要确定三个未知数，需要三个独立条件。

换句话说：条件数与未知数个数必须相等，多了可能无解，少了就有无穷多条抛物线都符合（可以自己动手试：只给两个点，能画出无数条抛物线）。

二、四种起手式怎么选

同样是三个未知数，我们可以换一种「包装」，让未知数直接等于题目给出的量，方程就变得极简单。

① 一般式 y=ax²+bx+c

适用：任意三个点（尤其里面有 y 轴上的点，直接给出 c）

② 顶点式 y=a(x−h)²+k

适用：已知顶点 (h,k) + 另一点，未知数只剩 1 个

③ 交点式 y=a(x−x₁)(x−x₂)

适用：已知与 x 轴的两个交点 + 另一点，只剩 1 个未知数

④ 对称轴/最值型

已知对称轴 x=h 或最值 k，本质上等价于给了顶点的一半信息

对比一下：用一般式求三点需要解三元一次方程组；如果那三个点里有两个是 x 轴上的交点，改用交点式只需一步除法就能算出 a。选对形式是从根本上减少计算量。

三、交点式为什么长这样

如果抛物线与 x 轴交于 (x₁,0) 和 (x₂,0)，说明 x₁、x₂ 是方程 ax²+bx+c=0 的两根。由因式定理，ax²+bx+c = a(x−x₁)(x−x₂)，于是函数就写成 y=a(x−x₁)(x−x₂)。这个形式第 5 讲还会深挖。

注意：顶点式只剩 1 个未知数、交点式也只剩 1 个未知数，而它们是等价的。只要题目出现了「顶点」或「两个 x 轴交点」的字样，优先选它们，别再硬套一般式。

计算顺序建议：先看有没有「顶点」或「两个交点」，有就跳过一般式。

算出结果后务必代入未使用的那个条件检验一遍——这是满分保险栓。

肆解题步骤：拿到题怎么下手

  1. 读条件：数一数题目给了几个独立条件（点、交点、顶点、对称轴、最值都算）。
  2. 选形式：看到顶点/对称轴/最值 → 顶点式；看到两个 x 轴交点 → 交点式；只有散点 → 一般式。
  3. 设未知数并代入：把已知条件代进去，通常能一步解出一个系数。
  4. 求其余系数：顶点式、交点式解完 a 之后，展开即可得到一般式。
  5. 回代检验 + 化成题目要求的形式。

伍例题精讲

例1已知抛物线经过 A(−1,0)、B(3,0)、C(1,−4) 三点，求它的解析式。
展开完整解析

思路：出现了两个 x 轴交点 (−1,0) 与 (3,0)，直接上交点式。

  1. 设 y = a(x+1)(x−3)（因为两交点横坐标为 −1 和 3）。
  2. 代入 C(1,−4)：−4 = a(1+1)(1−3) = a·2·(−2) = −4a，解得 a = 1。
  3. 于是 y = (x+1)(x−3) = x²−2x−3。
  4. 检验：x=0 时 y=−3，即 c=−3；顶点横坐标 = −b/2a = 1，代入得 y=−4，与 C 点吻合 ✓。
答：y = x² − 2x − 3。
例2 · 顶点型已知抛物线的顶点为 (−1, 2)，且经过点 (1, 6)，求它的解析式。
展开完整解析

思路：给了顶点，只剩一个未知数 a，一定要用顶点式。

  1. 设顶点式 y = a(x + 1)² + 2（顶点横坐标 h=−1，所以括号里是 x+1）。
  2. 代入 (1,6)：6 = a(1+1)² + 2 = 4a + 2，解得 a = 1。
  3. 于是 y = (x+1)² + 2 = x² + 2x + 3。
  4. 检验：x=−1 时 y=2 是最小值（a=1>0 开口向上），顶点成立 ✓。
答：y = x² + 2x + 3。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 不加括号导致符号全错：顶点 (−1,2) 应写成 a(x+1)²+2，写成 a(x−1)²+2 就把顶点放到了 (1,2)。
  • 忘记 a≠0 的隐含条件：解出 a=0 说明题目条件有问题或设式出错，必须回头检查。
  • 交点式忘了前提条件：只有抛物线与 x 轴确实有交点时才能用交点式；Δ<0 时这条路是死的。
  • 条件不满足就用：只给两个点却要求唯一解析式，标准答案通常是「不能唯一确定，缺一个条件」。
  • 算完不检验：回代一个没用过的点，十秒钟能救回五分。

柒它在生活里长什么样

🏀 从课本走到现实

  • 拱桥测绘：测量队测出桥拱的三个测点坐标，就能用三点拟合出整条桥拱的方程，进而算出各处高度。
  • 喷泉水柱建模：知道喷嘴位置（顶点）和落水点（x 轴交点），立刻确定水柱轨迹。
  • 商品定价试算：知道最高利润点（顶点）和某一销量下的利润，就能反推出整条利润曲线。

捌本节小结

✍️ 记住这几条就够了

  • 三个独立条件确定一条抛物线；不足则有无穷多解。
  • 看到顶点用顶点式，看到两个交点用交点式，其余才用一般式。
  • 顶点式、交点式都只剩一个未知数 a，计算量远小于一般式。
  • 隐藏条件要会用：过 y 轴的点给 c，对称轴给 h，最值给 k。
