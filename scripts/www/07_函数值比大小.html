函数值比大小

开口向上，离轴越远值越大；开口向下，离轴越远值越小。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

给你三个 x，不用求值就排出 f(x) 的大小，这听起来像作弊，其实是看图的本事。第 3 讲我们已经用过一次这个结论（判断哪个端点更远），现在把它单独拿出来讲透。

核心只有一句：函数值大小由「到对称轴的距离」决定，而不是由 x 本身的大小决定。

壹从原理上讲透

一、为什么是「距离」而不是「坐标」

把函数写成顶点式 y = a(x−h)² + k。注意 (x−h)² 就是 |x−h|²，也就是到对称轴距离的平方。

当 a > 0 时，y − k = a(x−h)² ≥ 0，距离 |x−h| 越大，(x−h)² 越大，y 就越大。

当 a < 0 时，y − k = a(x−h)² ≤ 0，距离越大，(x−h)² 越大但前面乘了负数，y 反而越小。

二、结论与用法

a > 0（开口向上）
|x−h| 越大 ⟹ y 越大
a < 0（开口向下）
|x−h| 越大 ⟹ y 越小
距相等
函数值相等（第 6 讲的对称性）

所以比大小的步骤永远是：先找轴，再算距离，最后看开口。完全不需要代入计算。

一个常见误区：以为「x 越大 y 越大」。这只在一侧的单调区间内成立，跨过对称轴就不成立了。第 3 讲的例子里 f(0)=−3 < f(4)=5，但 f(2)=−3 又小于 f(0)... 一定要按距离判断。

贰图像里的逻辑

叁核心结论（要背的）

a > 0
开口向上：到对称轴距离越远，函数值越大
a < 0
开口向下：到对称轴距离越远，函数值越小
距离相等
函数值相等
比较公式
f(x) = a(x−h)² + k，比较 |x−h| 即可

三步流程：找轴 → 算距离 → 看开口。

本结论与第 3 讲（哪个端点更极端）、第 6 讲（等高点）是同一件事的三种用法。

肆解题步骤：拿到题怎么下手

  1. 求轴：x = h = −b/(2a)，或从顶点式、两零点中点直接读出。
  2. 列表：把每个待比较的 x 列出来，算出 d = |x − h|。
  3. 判开口：看 a 的正负，决定「距离大 → 值大」还是「距离大 → 值小」。
  4. 排序：按 d 的大小排序，再翻译成 y 的大小顺序。
  5. 检验（可选）：代一个点进去验证方向没搞反。

伍例题精讲

例1已知 y = (x − 1)² − 4，比较 f(0)、f(2.5)、f(4) 的大小。
展开完整解析

思路：顶点式已经给出了对称轴 x=1，直接算距离。

  1. 开口：a=1>0，向上 → 距离越远，函数值越大。
  2. 对称轴 x = 1。
  3. 距离：|0−1| = 1，|2.5−1| = 1.5，|4−1| = 3。
  4. 距离从小到大：0 < 2.5 < 4，所以 f(0) < f(2.5) < f(4)。
  5. 实际计算核对：f(0)=−3，f(2.5)=−1.75，f(4)=5 ✓。
答：f(0) < f(2.5) < f(4)。
例2 · 开口向下已知 y = −2x² + 8x − 5，比较 f(1)、f(2)、f(5) 的大小。
展开完整解析

思路：a=−2<0，方向要反过来；先把轴求出来。

  1. 对称轴：x = −8/(2·(−2)) = 2。
  2. 开口向下 → 距离越远，函数值越小。
  3. 距离：|1−2| = 1，|2−2| = 0，|5−2| = 3。
  4. 距离从大到小：5 > 1 > 2，方向反过：f(5) < f(1) < f(2)。
  5. 验证：f(2) = 3（顶点，最大），f(1) = 1，f(5) = −15 ✓。
答：f(5) < f(1) < f(2)。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 把「x 越大 y 越大」当普遍规律：跨过对称轴就失效，必须按距离判断。
  • 开口方向看反：a<0 时距离越大值越小，这是最经典的丢分点。
  • 轴求错：−b/2a 里 b 带原符号代入，分母是 2a 而不是 2。
  • 把括号里的 h 符号读反：y=a(x+3)²+k 的轴是 x=−3 不是 x=3。

柒它在生活里长什么样

🏀 从课本走到现实

  • 投篮：球在出手点与落点（等高）之间的中点最高，越靠近两端越低——这正是距离决定高度的直观版本。
  • 灯光：灯的中心轴（对称轴）处最亮，偏离越远照度越低。
  • 利润曲线：偏离最优定价越远利润越低（开口向下），所以促销打折幅度要控制在合理区间。

捌本节小结

✍️ 记住这几条就够了

  • 比大小看的是 到对称轴的距离，不是 x 的大小。
  • a>0：距离越大值越大；a<0：距离越大值越小。
  • 距离相等 ⟹ 值相等（与第 6 讲统一）。
  • 三步流程：找轴 → 算距离 → 看开口。
比大小不算值　先找轴再比距离 开口向上远者大　开口向下远者小
