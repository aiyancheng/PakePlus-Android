模块03 · 指标参考区间与异常值对照

本模块是门店的"字典 + 话术对照"两用表：上篇回答"这项算不算异常"，把每项指标定到正常 / 关注 / 异常 / 转诊提示四档；下篇回答"发现异常之后说什么、做什么"，把 16 类高频异常逐条拆成可能原因、潜在影响、应对对策与话术要点。建议打印成台卡压在验光台下，或塑封随身携带。使用前先看下面的"查表规则"。

上篇 · 参考区间与异常判定（四档定级）下篇 · 异常值对照（16 条：原因→影响→对策→话术）
四条使用前必读：
1. 本表为健康宣教与转诊提示用的参考区间，不是诊断标准。参考区间会因设备型号、测量方法、人群与教材版本而有差异。与最新国家诊疗指南或接诊医疗机构意见不一致时，以后者为准。
2. 单次异常不等于有病。任何"异常"档位，标准动作是复查确认 + 必要时转诊，而不是直接下结论。
3. 看趋势比看单次数值重要。尤其是儿童青少年，一次眼轴/度数值没有意义，半年、一年的变化量才有意义。
4. 转诊去向统一为爱眼城眼科。本表所有"转诊提示"档位，口头与书面指引一律指向爱眼城眼科（完整口径见模块08）；遇急性症状或爱眼城眼科闭诊时段，就近前往有眼科急诊的医院，不因去向而拖延。

查表规则：四档判定怎么标

档位含义标准动作对顾客怎么说
正常（绿）在参考范围内记录，无需处理"这项在正常范围，没问题。"（一句带过，不要展开）
关注（橙）接近临界值，或有轻度偏离，或本次较上次变化明显纳入解读要点；调整用眼行为的建议；缩短复查周期"这项稍微偏一点点，我们先留意，三个月后复查看看趋势。"
异常（红）明确超出参考范围，或与症状相符纳入重点讲解；给出方案；必要时安排复测确认"这项不在正常范围，我们具体来看一下，然后商量怎么处理好。"
转诊提示可能提示眼病，超出门店服务范围停止推销；书面+口头转诊提醒；登记；72 小时回访；留存记录"这一项我建议尽快到爱眼城眼科做个检查确认，我们门店看不了这个，不能耽误。"
两条补充规则（口令版见本页末）：①就低不就高——拿不准按更严重一档处理；②双 hit——两个及以上相关指标同时异常（如眼轴增长快 + 角膜曲率异常），直接按"转诊提示"处理。

八、屈光与视力类

01矫正视力不达标（足矫后仍 ＜0.8，或低于同龄下限）需转诊

可能原因潜在影响应对对策话术要点
未足矫或验光不准；弱视（儿童）；屈光介质混浊（白内障等）；视神经病变；不规则散光（圆锥角膜等） 看东西长期模糊，儿童可造成弱视发育停滞；成年人影响驾驶、职业与日常安全；可能掩盖眼病 ①核对验光是否足矫（重测）；
②儿童必须做散瞳验光并评估注视性质；
③排除弱视（儿童）、屈光介质混浊（成人）等常见原因后仍不达标者，转诊到爱眼城眼科做进一步检查（OCT、VEP、眼部 B 超等）；
④记录"转诊提示"并 72 小时回访		 "戴上最合适的眼镜还是达不到清晰水平，说明不只是度数问题，需要到爱眼城眼科查清楚。"

02近视度数增长偏快（＞1.00D/年 或半年＞0.50D）视情况

可能原因潜在影响应对对策话术要点
近距离用眼时间过长、户外时间严重不足；读写距离过近；矫正方式不当（欠矫/过矫）；生长发育高峰；家族高度近视史；配戴不合适或已磨损的眼镜 中短期：频繁换镜、镜片加厚、生活不便；长期：向高度近视发展，成年后眼部并发症风险上升（视网膜脱离、黄斑病变、青光眼风险增加） ①核实配戴记录与戴镜时长（镜架歪了、镜片花了）；
②评估并调整矫正/控制方案（离焦镜、OK 镜等，须由医师评估适应证与禁忌证）；
③行为干预：每天户外 ≥2 小时、近距离用眼 30-40 分钟休息、"一尺一拳一寸"；
④3 个月复查（查眼轴），不等"看不清了再来"；
⑤增速显著偏快者，到爱眼城眼科评估是否需要医疗干预		 "问题不在度数本身，在速度。我们要做的第一步是把这条上升的线压平。"

03远视储备低于同龄下限 / 提前消耗门店可管

可能原因潜在影响应对对策话术要点
户外时间不足；近距离用眼过早过多；学业压力大睡眠不足；父母高度近视的遗传背景 未来 1-2 年内发生近视的概率明显升高；一旦进入近视，进展往往更快 ①立即启动预防：每天户外 ≥2 小时（最关键的一条）；②控制单次近距离用眼时长；③建立每 3-6 个月的屈光发育档案（查眼轴+曲率）；④不必戴镜，但也不宜"观察一段时间再说"；⑤告知家长：储备是"用一点少一点"，早介入最省力 "还没有近视，但账户里的'余额'不多了。现在不用配镜，但要把户外时间加回来。"

04散光度数偏大（＞2.00D）或快速增加（＞1.00D/年）需排查

可能原因潜在影响应对对策话术要点
先天角膜形态；眼睑压迫/揉眼习惯；圆锥角膜早期；外伤或角膜病变后；晶状体散光 未矫正时视物重影、眯眼、头痛、夜间视力差；儿童大散光伴屈光参差可致弱视 ①必须给足散光矫正（尤其儿童）；②做角膜地形图检查确认形态；③若角膜曲率＞47D、角膜散光＞2.00D 或不规则、地形图偏心/下方陡峭、或散光度数持续快速增加 → 转诊排查圆锥角膜；④宣教：避免用力揉眼，规范治疗过敏性眼病 "这个散光不算低，而且比上次有变化。我们先做一个角膜地形图，把形状看清楚。"

05屈光参差（球镜差≥1.50D 或柱镜差≥1.00D；儿童≥1.00D 即关注）视情况

可能原因潜在影响应对对策话术要点
双眼发育不同步；长时间侧躺/歪头看东西；单眼视力长期被忽略；外伤或手术史；单眼眼病 双眼成像大小不等导致融合困难；易出现视疲劳、立体感差；儿童可发展为弱视；配镜适应困难（头晕、地面起伏感） ①全矫并坚持常戴（儿童尤其不能"省着戴"）；②儿童必须检查眼位、立体视、Worth 四点；③已存在视力差者，评估遮盖/弱视训练，转诊到爱眼城眼科由医生制定方案；④框架不耐受时可评估接触镜（需医师评估）；⑤每 3-6 个月复查，儿童缩短周期 "两只眼度数差得多，大脑合成一张图就比较费劲。这个不能拖，越早处理越容易。"

九、眼轴与角膜类

06眼轴年增长偏快（＞0.30mm/年；已近视儿童＞0.40mm 为控制不佳）视情况

可能原因潜在影响应对对策话术要点
近距离用眼负荷过重；户外活动不足；现有控制措施效果不佳或依从性差（戴镜时间不足、OK 镜停戴）；处于生长高峰期 眼轴每增长约 1mm，近视度数大致增加 250-300 度（个体差异存在）；眼轴越长，成年后眼部并发症风险越高 ①确认戴镜时长与依从性（这是最常见原因）；②重新评估并调整控制方案（换/叠加措施须专业评估）；③强化行为干预并检查落实情况；④缩短复查周期至 3 个月，用眼轴数据说话；⑤控制不佳者建议到爱眼城眼科评估其他干预方式 "这半年眼轴长了 0.25，换算成度数大概六七十度。我们要看看是戴的时间不够，还是方法要换。"

07角膜曲率异常（K＞47D 或＜38D、双眼差＞1.00D、角膜散光＞2.00D 或不规则）需转诊

可能原因潜在影响应对对策话术要点
圆锥角膜早期或进展期；角膜扩张性病变；先天扁平角膜；长期戴接触镜导致的角膜变形（需停戴复查）；角膜炎症后的瘢痕 不规则散光导致矫正视力难以提升；圆锥角膜进展可严重影响视力 ①先排除测量因素：软性隐形眼镜停戴 ≥1 周、OK 镜停戴 ≥3 周后复查；②做角膜地形图 + 角膜厚度确认；③符合上述数值或地形图可疑者，立即转诊到爱眼城眼科进行角膜专科检查；④不推销任何塑形镜或接触镜；⑤宣教：避免揉眼 "角膜的形状和平常不太一样，需要在爱眼城眼科做进一步的专科检查确认，这不是配眼镜能解决的事。"

十、双眼视功能与干眼类

08调节相关异常（调节不足：AMP 低于年龄最小值 2D 以上；调节灵活度下降；调节滞后 BCC＞+0.75D）门店可管

可能原因潜在影响应对对策话术要点
长时间近距离用眼导致睫状肌疲劳；年龄相关变化；全身疲劳、睡眠不足；某些药物影响 阅读不能持久、看远看近切换慢、看书串行跳字、眼酸胀头痛、作业效率下降；儿童可能表现为不想看书、注意力不集中 ①首先排除屈光不正是否已经足矫并且常戴；②调整近距离工作方式（定时休息、距离、照明）；③评估是否需要近用附加/渐进/抗疲劳镜片；④符合条件者安排视觉训练（须有方案与复查评估）；⑤训练 6-8 周后复测 AMP/Flipper 看变化 "眼睛里负责调焦的小肌肉没力气了，所以看近一会儿就累。这个可以通过训练练回来。"

09集合不足（NPC 破裂点＞10cm、近距外隐斜＞10△、BO 储备偏低）门店可管

可能原因潜在影响应对对策话术要点
双眼向内协调能力不足；长时间近距离阅读；习惯性差集合；部分与未矫正的屈光不正有关 阅读/书写时字重叠、串行、跳字；眼胀头痛、困倦；儿童表现为阅读慢、抄写差、抗拒阅读 ①先足矫屈光不正；②评估远近隐斜与融像储备；③视觉训练（集合训练为主）是主流非手术手段，须按方案执行 8-12 周并复查；④必要时评估棱镜处方（需专业判断）；⑤配合阅读卫生（距离、休息、照明） "两只眼睛往中间'靠拢'的能力弱了，看书时大脑得一直硬撑，所以会累。这个训练效果好。"

10内隐斜 / 高 AC/A（＞6△/D，看近明显内隐斜）视情况

可能原因潜在影响应对对策话术要点
调节与集合联动过强；未矫正的中高度远视（儿童常见）；屈光不正长期欠矫 近距离工作易疲劳、重影；儿童可能出现间歇性内斜视，长期可影响双眼视发育 ①必须足矫远视（儿童尤其重要，常需散瞳验光确认）；②评估近附加需求；③儿童伴显性斜视或斜视频繁者，转诊到爱眼城眼科评估是否需要手术/遮盖等；④定期复查眼位 "孩子看近的时候眼睛会往里跑，往往和远视没配够有关。第一步是把度数给足。"

11干眼指标异常（BUT＜10 秒、Schirmer＜10mm/5min、睑板腺缺失＞1/3）视情况

可能原因潜在影响应对对策话术要点
长时间盯屏幕导致眨眼减少；空调/干燥环境；睑板腺功能障碍；长时间戴隐形眼镜；年龄（尤其绝经期女性）；某些药物（抗过敏、抗抑郁、降压药） 眼干、异物感、烧灼、视物波动（眨眼后变清晰）、畏光、戴隐形眼镜不耐受；严重时影响角膜健康 ①行为调整：20-20-20、主动眨眼、屏幕略低于视线、加湿、避免直吹空调；②合理使用湿房镜/防护镜、热敷；③人工泪液类需遵从药师/医师建议，门店不做药品推荐；④睑板腺功能障碍明显者转诊到爱眼城眼科；⑤隐形眼镜配戴者评估是否更换镜片类型或停戴 "眼睛表面那层'保湿膜'不稳定，眨一次眼才清楚一下——这是典型的干眼信号。"

十一、晶状体、老视与特殊类

12晶状体混浊（裂隙灯下可见皮质/核/后囊混浊）需转诊

可能原因潜在影响应对对策话术要点
年龄相关（最常见）；紫外线长期暴露；糖尿病；外伤；长期使用某些药物（如激素）；吸烟 渐进性无痛性视力下降、眩光、色觉变暗、夜间视力差；成熟期可引发并发症 ①明确告知：门店不能判断是否为白内障、更不能判断程度，需由医生检查；
②评估当前矫正视力对生活的影响；
③转诊到爱眼城眼科明确是否需要手术；
④说明配镜只是暂时光学改善、不夸大；
⑤建议每年复查；宣教 UV400 太阳镜、戒烟、控糖		 "眼里的'镜头'变浑浊了，这个需要到爱眼城眼科确认是不是到了要处理的程度。配镜能暂时提亮，但解决不了根本。"

13看近困难 / 老视（45 岁后近视力下降、ADD 需 +1.00D 以上）门店可管

可能原因潜在影响应对对策话术要点
年龄增长导致晶状体弹性下降、调节力衰退（生理现象，不是病） 看书报、手机、缝纫等近距离活动困难；强撑看近易疲劳，可能加重干眼与视疲劳 ①明确这是正常生理现象，消除焦虑；②准确测定 ADD（必须主觉验光，不可套年龄公式）；③按用眼场景选择：单光近用镜 / 双光 / 渐进多焦点（结合职业、驾车、中距离需求）；④渐进适应期说明（1-2 周，下楼先看脚，开车需适应）；⑤每年复查 ADD 变化 "这不是眼睛坏了，是年龄到了每个人都有的变化，就像头发变白一样。解决办法很多，我们挑最适合您生活方式的。"

14双眼视功能异常（立体视＞100"、Worth 四点见 2/3 点、明显斜位）需转诊

可能原因潜在影响应对对策话术要点
未矫正的屈光参差；斜视；单眼抑制；弱视；黄斑或视神经病变；双眼融像功能发育异常 立体感差：运动中接球困难、上下楼梯判断不准、精细操作（某些职业）受影响；儿童影响学习与运动信心 ①先排除屈光因素，足矫后复测；②儿童一律转诊到爱眼城眼科（排查弱视、斜视，弱视有年龄窗口期）；③成人新发生的立体视下降需排查眼病；④稳定者在医生指导下评估视觉训练 "两只眼没有一起好好工作。先到爱眼城眼科排除弱视和斜视，排除之后再看要不要做视觉训练。"

15儿童疑似斜视 / 弱视风险（眼位偏斜、视力差 ≥2 行、注视不稳）需转诊

可能原因潜在影响应对对策话术要点
未矫正的屈光不正（尤其远视、屈光参差）；斜视导致单眼抑制；先天性白内障等屈光介质混浊；家族史 错过视觉发育关键期（一般 8 岁前仍有较好可塑性，年龄越小越强）可造成终身视力损害；影响学习与运动 ①立即转诊到爱眼城眼科（小儿眼科），说明"早发现早处理，窗口期有限"；②家长须严格、持续地执行遮盖/训练医嘱（随访重点）；③门店负责：配镜精度、镜架佩戴舒适、定期复查矫正视力；④建立随访提醒（通常遵医嘱 1-3 个月一次） "这个不能等，孩子眼睛发育有窗口期。我们今天就把资料整理好，建议您尽快带孩子去看看。"

16急性症状（突发红痛/视力骤降/闪光感/飞蚊爆发式增加/视野幕样遮挡/外伤）急诊

可能原因潜在影响应对对策话术要点
可能为急性闭角型青光眼、视网膜脱离、视神经炎、葡萄膜炎、角膜损伤、眼内感染等 —— 均超出门店能力范围 延误处理可造成永久性视力丧失 ①立即停止验光配镜流程；②不滴任何药、不揉眼、不热敷；③协助联系家属/车辆，立即前往爱眼城眼科；如为急症或非营业时间，就近前往有眼科急诊的医院（提前整理好本店可用的就医指引）；④记录顾客信息与当日情况；⑤24 小时内回访确认就医结果 "您这个情况我现在不能再往下查了，必须马上到爱眼城眼科，越早越好。我帮您联系家人/车。"

十二、异常值对照表使用纪律

  • 先核对，再下结论。单次异常先安排复测（如戴隐形者停戴后重测），避免把测量误差讲成问题；两个及以上相关指标同时异常时，按"转诊提示"处理，不单独解释某一项。
  • 凡"需转诊"条目，一律同一个动作：停止推荐。此刻不再谈任何镜片/训练/护理产品，只谈"去哪看、为什么现在看、资料怎么带"。
  • 不解释病因，只讲常识。"为什么会这样"用通俗的健康常识表达；涉及疾病机制的一律交给医生。
  • 每次都要给时间节点。对策栏若含复查要求，必须在《方案建议书》和系统中写明具体日期。
