学习内容

一、为什么要了解用眼习惯

每个人的用眼习惯不同，对眼镜的需求也不同。了解顾客的用眼习惯，可以帮你推荐更"个性化"的产品，而不是"千人一面"的标准方案。

用眼习惯三大关键维度：

  • 时长：每次用眼多长时间？一天累计多长时间？
  • 距离：看东西时眼睛距离目标多远？是否有近距离用眼习惯？
  • 光线：在什么光线下用眼？光线是否充足？
专业提示：很多顾客的视力问题（如近视加深、眼疲劳）都与不良的用眼习惯有关。了解习惯后，你不仅可以推荐产品，还可以给出"改善习惯"的建议——这会让顾客觉得你非常专业和负责！

二、时长习惯：累计时长比连续时长更重要

询问时长习惯时，要区分连续时长（一次不看断多长时间）和累计时长（一天总共看多长时间）。累计时长更能反映眼睛的总负担。

常见时长习惯及影响：

  • 轻度用眼：一天累计2-4小时 → 眼疲劳风险较低
  • 中度用眼：一天累计4-8小时 → 眼疲劳风险中等，建议防蓝光
  • 重度用眼：一天累计8小时以上 → 眼疲劳风险高，建议抗疲劳+防蓝光

询问话术：

  • "您一天大概看电脑或手机多长时间？是断断续续看，还是连续看好几个小时？"
  • "您会不会从早到晚都对着屏幕？中间有休息吗？"
  • "您觉得一天下来，眼睛最累的是什么时候？下午还是晚上？"
注意：有些顾客会说"我不怎么看电脑"，但实际一天看手机3-4小时——手机的蓝光伤害不比电脑小！要问清楚"电脑+手机"的总时长。

三、距离习惯：近距离用眼是近视加深的主因

距离习惯是指顾客看东西时，眼睛与目标之间的距离。距离越近，眼睛调节负担越重，越容易导致近视加深或眼疲劳。

安全距离参考：

  • 看电脑：50-70cm（一臂距离）
  • 看手机：30-40cm（不要贴太近）
  • 看书：30-35cm（不要趴太近）
  • 看电视：3米以上（屏幕对角线的5-7倍）

不良距离习惯及风险：

  • 手机贴脸看：距离<20cm → 高度近视风险
  • 趴着看书：距离<20cm → 近视加深快
  • 关灯看手机：瞳孔散大+蓝光直射 → 黄斑损伤风险

询问话术：

  • "您看手机或看书时，会不会贴得很近？大概多远？"
  • "您有没有躺着看手机或者趴着看书的习惯？"
  • "您孩子写作业时，眼睛离桌面近不近？要不要配个坐姿矫正器？"
实战经验：如果发现顾客有不良距离习惯，可以顺势推荐"防蓝光镜片"或"抗疲劳镜片"，并提醒"改善用眼距离比换眼镜更重要"。这样的建议会让顾客觉得你非常专业。

四、光线习惯：光线不足或过强都伤眼

光线习惯是指顾客在什么光线下用眼。光线不足会导致眼睛过度调节，光线过强（特别是蓝光）会损伤视网膜。

常见光线问题及影响：

  • 光线不足：在昏暗环境下看书/看手机 → 眼睛过度调节，近视加深
  • 光线过强：在强光下不戴太阳镜 → 紫外线损伤晶状体（白内障风险）
  • 蓝光过量：长时间在LED灯光下或用电子设备 → 视网膜损伤、眼疲劳
  • 频闪：使用劣质LED灯（有频闪） → 眼睛容易疲劳、头痛

询问话术：

  • "您平时在什么样光线下看手机或看书？灯光够亮吗？"
  • "您会不会关灯看手机？或者晚上只开小夜灯？"
  • "您户外运动时，有没有戴太阳镜的习惯？"
重要提醒：关灯看手机是非常伤眼的习惯！不仅伤黄斑，还可能导致青光眼（暗环境下瞳孔散大，房角关闭）。一定要提醒顾客改掉这个习惯。
📝 今日小结
  • 时长：累计时长比连续时长更重要，一天8小时以上建议抗疲劳+防蓝光
  • 距离：安全距离（电脑50-70cm，手机30-40cm），不良距离习惯加速近视加深
  • 光线：光线不足（过度调节）和过强（紫外线损伤）都伤眼，关灯看手机最伤眼
  • 了解习惯后，不仅推荐产品，还要给改善建议 → 体现专业度
