顶点式

配方成顶点式，顶点、对称轴、最值一口读出。
概念讲透型 · 原理推导 + 图像逻辑 + 生活场景 + 自测反馈
🌱 生活引子：为什么要学这一讲

第 1 讲我们说过 y=a(x−h)²+k 一眼就能看出顶点在 (h,k)。但试卷上发下来的往往不是这个样子，而是乱糟糟的 y=2x²−8x+5。怎么把它变回「一眼看穿」的样子？答案是配方。

配方不是新东西，它来自完全平方公式 (x±p)² = x² ± 2px + p²。把它倒过来用，就能把任意二次函数改写成顶点式。这一讲把它练到不用思考的程度。

壹从原理上讲透

一、从完全平方公式倒着用

我们知道 (x − 2)² = x² − 4x + 4。反过来，看到 x² − 4x 就应该想到它是 (x−2)² 缺了那个 4。于是：

x² − 4x + 5 = (x² − 4x + 4) − 4 + 5 = (x − 2)² + 1。

配方的关键动作是：加上一次项系数一半的平方，再减掉同样的量，保证式子等值。

二、一般化的配方流程

对于 y = ax² + bx + c：

y = a(x² + (b/a)x) + c = a[(x + b/2a)² − b²/4a²] + c = a(x + b/2a)² + c − b²/4a

整理成 y = a(x − h)² + k 的形式，其中 h = −b/2a，k = (4ac − b²)/4a。这就是顶点坐标公式的来源，不需要死记，配方时自然就出来了。

三、顶点式能带来什么

顶点坐标

直接读出 (h, k)，不必套公式

对称轴

直接读出 x = h

最值

a>0 时最小值 k；a<0 时最大值 k

平移来源

由 y=ax² 平移而来，与第 1 讲闭环

二次项系数 a≠1 时最容易出错：必须先把 a 提出来（连同 bx 一起），只对被提取后的括号内部配方，配完再把乘出去的部分补回常数项。

贰图像里的逻辑

叁核心结论（要背的）

顶点式
y = a(x − h)² + k，顶点 (h, k)
对称轴
x = h = −b/(2a)
顶点纵坐标
k = (4ac − b²)/(4a)　（也可把 x=h 代回原式）
最值
a>0 时 y最小 = k；a<0 时 y最大 = k
配方要诀
加一次项系数一半的平方，再减去同一个量

配方的中间变形可以写成 y = a(x + b/2a)² + (4ac−b²)/4a，不必硬背，用两次就熟。

顶点式同时是第 1 讲平移的第 4 步——它在整套专题里是枢纽。

肆解题步骤：拿到题怎么下手

  1. 提取：把 a 从 ax²、bx 两项中提出来 → a(x² + (b/a)x) + c。
  2. 配方：括号内加上并减去 (b/2a)²（即一次项系数一半的平方）。
  3. 写成平方：把括号内的三项合成为完全平方 (x + b/2a)²。
  4. 化简常数：把多减的量乘 a 移出括号，与 c 合并成 k。
  5. 读出结论：顶点 (h,k)、对称轴 x=h、最值 k。

伍例题精讲

例1把 y = 2x² − 8x + 5 化为顶点式，并写出它的顶点、对称轴和最值。
展开完整解析

思路：a=2 不是 1，第一步必须把 2 提出来。

  1. 提 a：y = 2(x² − 4x) + 5。
  2. 配方：括号内加 4 再减 4 → 2[(x² − 4x + 4) − 4] + 5。
  3. 写成完全平方：2[(x − 2)² − 4] + 5。
  4. 化简：2(x − 2)² − 8 + 5 = 2(x − 2)² − 3。
  5. 读出：顶点 (2, −3)，对称轴 x=2，因 a=2>0，最小值为 −3。
答：y = 2(x−2)² − 3；顶点 (2,−3)，对称轴 x=2，最小值 −3。
例2 · 系数为负把 y = −3x² + 6x + 1 化为顶点式，并指出它的最大值。
展开完整解析

思路：a=−3 为负，开口向下，顶点给的是最大值；提取时负号容易漏。

  1. 提 a：y = −3(x² − 2x) + 1。
  2. 配方：括号内加 1 减 1 → −3[(x² − 2x + 1) − 1] + 1。
  3. 写成完全平方：−3[(x − 1)² − 1] + 1。
  4. 化简：−3(x − 1)² + 3 + 1 = −3(x − 1)² + 4。
  5. 读出：顶点 (1, 4)，a=−3<0 开口向下，所以最大值是 4。
答：y = −3(x−1)² + 4；顶点 (1,4)，对称轴 x=1，最大值 4。

陆易错陷阱

⚠️ 这一讲最容易丢分的地方

  • 忘记把 b 一起提出来：2x²−8x 提取后应是 2(x²−4x)，写成 2(x²−8x) 是最常见的低级错误。
  • 加了忘记减：配方必须「加一个数、再减同一个数」，只加不减就改变了原函数。
  • 负号漏乘：−3(x−1)² 展开时外面的 −3 要乘到里面每一项，包括常数。
  • 把顶点横坐标符号写反：y=a(x−2)²+k 的顶点是 (2,k) 不是 (−2,k)。
  • 最值方向搞反：开口向下时 k 是最大值，不是最小值。

柒它在生活里长什么样

🏀 从课本走到现实

  • 建筑拱顶：把桥拱方程配方后，顶点就是最高承重点的位置与高度。
  • 利润模型：利润 = −a(销量−h)² + k，配方后立刻知道最优销量 h 与最高利润 k。
  • 投篮最高点：球的轨迹配方后，顶点横坐标是到达最高点的时间，纵坐标是最高高度。

捌本节小结

✍️ 记住这几条就够了

  • 配方的本质是 加一半系数的平方再减回来，式子等值不变。
  • 顶点式 y=a(x−h)²+k 一眼给出：顶点、对称轴、最值、平移来源。
  • a≠1 时必须先把 a 提出来，再对括号内部配方。
  • 顶点坐标公式 (−b/2a, (4ac−b²)/4a) 是配方的必然结果，理解即可不必死记。
